中考试卷结构（咸宁卷）

命题依据

数与代数：实数与代数式

基础必考
01实数
  • 有理数、无理数、实数分类；数轴、相反数、绝对值、倒数。
  • 平方根与立方根：√a 有意义的条件 a≥0；√(a²)=|a|。
  • 科学记数法 a×10ⁿ（1≤|a|<10）；有效数字。
  • 实数的运算：零指数 a⁰=1(a≠0)、负整数指数 a⁻ⁿ=1/aⁿ。
  • 比较大小：作差法、平方法、数轴法、估算法。
02整式·分式·二次根式
  • 幂的运算：aᵐ·aⁿ=aᵐ⁺ⁿ、(aᵐ)ⁿ=aᵐⁿ、(ab)ⁿ=aⁿbⁿ、aᵐ÷aⁿ=aᵐ⁻ⁿ(a≠0)。
  • 乘法公式：平方差 (a+b)(a−b)=a²−b²；完全平方 (a±b)²=a²±2ab+b²。
  • 因式分解：提公因式 → 公式法 → 十字相乘；必须分解到不能再分。
  • 分式：值为 0 需分子=0 且分母≠0；分式方程必验根。
  • 二次根式：√(ab)=√a·√b(a,b≥0)；化简结果分母不含根号、被开方数不含分母。
⚠
分式方程不验根直接扣该题全分，这是中考最常见的「冤枉分」。
3

方程与不等式

解法核心
03一元二次方程 ax²+bx+c=0
  • 求根公式：x = [−b ± √(b²−4ac)] / (2a)。
  • 判别式：Δ=b²−4ac ＞0 两不等实根；=0 两相等实根；＜0 无实根。
  • 韦达定理：x₁+x₂ = −b/a，x₁·x₂ = c/a。
  • 解法优先级：直接开平方 → 因式分解 → 配方法 → 公式法。
  • 应用题模型：增长率 a(1+x)²=b、面积问题、销售利润问题。
04不等式（组）
  • 不等式两边同乘（除以）负数，不等号方向改变——最高频失分点。
  • 数轴表示解集：实心点「≥、≤」，空心圈「＞、＜」。
  • 解集取法口诀：「同大取大，同小取小，大小小大中间找，大大小小无解了」。
💡
解不等式组最后一定要画数轴，公共部分一目了然。

函数：一次函数·反比例·二次函数

重头戏
05一次函数 y=kx+b
  • k＞0 时 y 随 x 增大而增大；k＜0 时减小。
  • 图象与 y 轴交于 (0, b)，与 x 轴交于 (−b/k, 0)。
  • 待定系数法：设解析式 → 代入两点 → 解方程组。
06反比例函数 y=k/x
  • k＞0：图象在一、三象限，每支上 y 随 x 增大而减小。
  • k＜0：图象在二、四象限。
  • |k| 的几何意义：图象上任意点向两轴作垂线，与坐标轴围成矩形面积为 |k|。
07二次函数 y=ax²+bx+c
  • 开口方向由 a 决定；对称轴 x=−b/(2a)；顶点 (−b/(2a), (4ac−b²)/(4a))。
  • 顶点式 y=a(x−h)²+k；交点式 y=a(x−x₁)(x−x₂)。
  • 平移规律：左加右减（对 x），上加下减（对 k）。
  • 与 x 轴交点个数由 Δ 决定；最值问题：a＞0 有最小值，a＜0 有最大值。
  • 实际应用：面积最大、利润最大、抛物线运动、拱桥问题。
★
二次函数是压轴题的绝对主角，必须熟练「配方法求顶点＋分类讨论（对称轴与区间位置）」。

几何：三角形与四边形

推理基础
08三角形
  • 内角和 180°；外角等于不相邻两内角和。
  • 三边关系：任意两边之和大于第三边，之差小于第三边。
  • 全等判定：SSS、SAS、ASA、AAS、HL（直角三角形）。
  • 等腰三角形：等边对等角；三线合一（顶角平分线、底边中线、底边高）。
  • 直角三角形：勾股定理 a²+b²=c²；斜边中线等于斜边一半；30° 角所对直角边等于斜边一半。
09相似三角形
  • 判定：两角对应相等（AA）、两边成比例且夹角相等、三边成比例。
  • 性质：周长比=相似比；面积比=相似比的平方。
  • 常见模型：A 型、X 型、母子型、一线三等角。
10特殊四边形
  • 平行四边形：对边平行且相等，对角线互相平分。
  • 矩形：四个直角，对角线相等；菱形：四边相等，对角线互相垂直且平分内角；正方形兼具两者性质。
  • 中位线：三角形中位线平行于第三边且等于其一半；梯形中位线等于上下底和的一半。

圆

必考大题
11核心定理
  • 垂径定理：垂直于弦的直径平分弦及弦所对的弧。
  • 圆周角定理：同弧所对圆周角等于圆心角的一半；直径所对圆周角是 90°。
  • 切线的判定与性质：过半径外端且垂直于该半径的直线是切线；切线垂直于过切点的半径。
  • 切线长定理：从圆外一点引两条切线长相等，且该点与圆心连线平分两切线夹角。
  • 弧长 l = nπR/180；扇形面积 S = nπR²/360 = ½lR。
  • 圆锥侧面展开为扇形，底面周长 = 扇形弧长。
★
圆的证明题标准套路：连半径 → 证垂直（或证垂直 → 得切线）；辅助线「有弦作弦心距，有切点连半径」。

统计与概率

送分题
12统计
  • 平均数（算术、加权）、中位数（排序后中间数）、众数（出现次数最多）、方差。
  • 方差公式 s² = [(x₁−x̄)²+…+(xₙ−x̄)²]/n；方差越小越稳定。
  • 统计图：条形图、折线图、扇形图、频数分布直方图。
13概率
  • 一步试验：简单概率 P = 目标数 / 总数。
  • 两步试验：列表法或树状图法求所有等可能结果。
  • 必然事件 P=1，不可能事件 P=0，随机事件 0＜P＜1。
💡
树状图要写全每一种等可能结果，不重不漏；「同时抛两枚硬币」与「先后抛两次」结果数不同。

锐角三角函数与图形变换

工具应用
14锐角三角函数
  • sinA=对边/斜边，cosA=邻边/斜边，tanA=对边/邻边。
  • 特殊值：sin30°=1/2、sin45°=√2/2、sin60°=√3/2；cos 反之；tan30°=√3/3、tan45°=1、tan60°=√3。
  • 解直角三角形应用：仰角俯角、坡度坡角、方位角问题。
  • 常用技巧：作高构造直角三角形，遇到 30°、45°、60° 设未知数。
15图形变换
  • 平移：坐标「上加下减，左减右加」（对点坐标而言）。
  • 轴对称：关于 x 轴对称 y 变号；关于 y 轴对称 x 变号；关于原点对称两者都变号。
  • 旋转：对应点到旋转中心距离相等，对应点与中心连线夹角等于旋转角。
  • 位似：对应边成比例，对应点连线交于一点。
