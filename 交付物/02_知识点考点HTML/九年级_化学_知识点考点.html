中考化学试卷结构（咸宁卷）

命题依据
考点题型与分值
  • 满分 100 分（与物理合堂 130 分中的化学部分约 60 分折算），时间 120 分钟合堂。
  • 一、选择题：约 10 小题，约 20 分。
  • 二、非选择题：填空题、实验探究题、计算题，约 40—80 分。
  • 必考主线：化学用语（符号、化学式、方程式）＋实验探究＋基础计算。
  • 金属、酸碱盐占分最高，约 45%。
★
化学方程式书写是「一错带一片」的考点，配平与条件、气体沉淀符号必须齐全。

走进化学世界与基础实验

入门基础
01物质的变化与性质
  • 物理变化：无新物质生成（状态、形状改变）；化学变化：有新物质生成（燃烧、生锈、变质）。
  • 化学性质：可燃性、还原性、氧化性、酸性、碱性、稳定性。
  • 蜡烛燃烧产物检验：干冷烧杯内壁出现水雾（有水）；澄清石灰水变浑浊（有二氧化碳）。
02基本实验操作
  • 药品取用：固体用药匙或镊子；液体「一倒二向三斜靠」，取液量未说明时取 1—2 mL。
  • 给液体加热：不超过试管容积的 1/3，试管口向着无人处，外焰加热。
  • 量筒读数：视线与凹液面最低处水平相切（俯大仰小）。
  • 过滤：「一贴二低三靠」，玻璃棒起引流作用。
  • 装置气密性检查：手握试管外壁，管口有气泡冒出，松手后形成一段水柱。
  • 氧气验满：带火星的木条放集气瓶口复燃；二氧化碳验满：燃着的木条放瓶口熄灭。
⚠
量筒读数「俯大仰小」：俯视时读数偏大，实际取液偏少——选择题常考陷阱。

我们周围的空气与氧气

物质性质
03空气组成与测定
  • 空气成分（体积分数）：氮气约 78%、氧气约 21%、稀有气体 0.94%、二氧化碳 0.03%、其他 0.03%。
  • 测定空气中氧气含量（红磷燃烧法）：现象——产生大量白烟、放热、冷却后水位上升约 1/5 体积。
  • 误差分析：红磷不足、装置漏气、未冷却就打开弹簧夹 → 进水偏少。
04氧气的性质与制取
  • 物理性质：无色无味气体，不易溶于水，密度比空气略大。
  • 化学性质：助燃性（氧化性）；硫燃烧（蓝紫色火焰，生成刺激性气体 SO₂）；铁丝在氧气中燃烧（火星四射，生成黑色固体 Fe₃O₄，瓶底放水或细沙）。
  • 实验室制取氧气三法：①分解过氧化氢（MnO₂ 催化）；②加热高锰酸钾；③加热氯酸钾（MnO₂ 催化）。
  • 催化作用：改变反应速率而自身质量和化学性质在反应前后均不变。
  • 收集方法：排水法（不易溶于水）、向上排空气法（密度比空气大）。
💡
高锰酸钾制氧气时试管口要放一团棉花，防止粉末堵塞导管——铁架台、酒精灯、棉花是三大细节分。

物质构成的奥秘

微观世界
05分子、原子、离子
  • 分子是保持物质化学性质的最小粒子；原子是化学变化中的最小粒子。
  • 原子结构：质子数 = 核电荷数 = 核外电子数（原子不带电）；相对原子质量 ≈ 质子数 + 中子数。
  • 离子：带电荷的原子或原子团；阳离子（失电子，带正电）、阴离子（得电子，带负电）。
  • 元素：具有相同质子数（核电荷数）的一类原子的总称。
  • 地壳中元素含量前四位：氧、硅、铝、铁。
06化学式与化合价
  • 常见化合价：H +1、O −2、Na +1、Mg +2、Al +3、Cl −1、S −2、Ca +2、Fe +2/+3、Cu +2。
  • 化合物中正负化合价代数和为零；单质中元素化合价为 0。
  • 化学式意义：表示一种物质、一个分子、构成原子的种类与个数比。
  • 相对分子质量 = 各原子相对原子质量之和。
★
抓住「正价在前、负价在后，代数和为零」和「十字交叉法」即可快速书写化学式。
5

化学方程式与质量守恒

核心工具
07质量守恒定律
  • 内容：参加化学反应的各物质质量总和等于反应后生成的各物质质量总和。
  • 微观解释：反应前后原子的种类、数目、质量均不变。
  • 常考推论：反应前后元素种类不变、元素质量不变。
  • 适用范围：只适用于化学变化，不适用于物理变化。
08方程式书写与配平
  • 书写三步：写（正确写反应物与生成物）→ 配（配平，使两边原子个数相等）→ 标（标条件、气体↑、沉淀↓）。
  • 常见条件：点燃、加热（Δ）、高温、催化剂。
  • 配平方法：最小公倍数法、观察法、奇偶配平法。
⚠
「Fe + O₂ 点燃 → Fe₃O₄」是化合反应，不要写「Fe₂O₃」；生成物状态符号只在溶液中反应时才标。

碳和碳的氧化物

重点物质
09碳单质与二氧化碳
  • 金刚石（最硬）、石墨（导电、润滑）、C₆₀（分子）。
  • CO₂ 性质：不燃烧不支持燃烧、不与水反应？——错！CO₂ + H₂O = H₂CO₃（使紫色石蕊变红）。
  • CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O（检验二氧化碳）。
  • CO₂ 用途：灭火、干冰人工降雨、温室气体肥料。
  • 温室效应：主要气体 CO₂，来源是化石燃料燃烧。
10一氧化碳与还原反应
  • CO 性质：无色无味、有毒（与血红蛋白结合）、有还原性和可燃性。
  • CO 还原氧化铜：CO + CuO Δ→ Cu + CO₂（黑色变红色，尾气要处理）。
  • C 还原氧化铜：C + 2CuO 高温→ 2Cu + CO₂↑。
  • CO 燃烧：2CO + O₂ 点燃→ 2CO₂（蓝色火焰）。
💡
「先通 CO 后加热，先停止加热后停通 CO」——这是 CO 还原实验的安全顺序，必考。
11实验室制取二氧化碳
  • 药品：大理石或石灰石与稀盐酸（不能用稀硫酸，因生成微溶的硫酸钙覆盖表面阻止反应；不能用碳酸钠，反应太快）。
  • 方程式：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑。
  • 装置：固液常温型；收集：向上排空气法（密度比空气大且能溶于水）。

金属和金属材料

高频大题
12金属活动性顺序
  • K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au。
  • 排在氢前的金属能与稀盐酸/稀硫酸反应放出氢气；越靠前越活泼。
  • 排在前面的金属能把排在后面的金属从其盐溶液中置换出来。
  • 金属与酸反应：Mg、Al、Zn、Fe 都能与稀盐酸反应，产氢速率 Mg＞Al＞Zn＞Fe。
★
判断置换反应能否发生：前者活动性必须强于后者且后者非 K/Ca/Na（太活泼会先与水反应）。
13金属的化学性质
  • 金属 + 氧气 → 金属氧化物（铁生锈、铜变黑）。
  • 金属 + 酸 → 盐 + 氢气（置换反应）。
  • 金属 + 盐溶液 → 新金属 + 新盐。
  • 铁生锈条件：与氧气和水同时接触；防锈方法：刷漆、涂油、镀锌、制成不锈钢。
14金属资源的利用
  • 炼铁原理：3CO + Fe₂O₃ 高温→ 2Fe + 3CO₂。
  • 铁矿石：赤铁矿（Fe₂O₃）、磁铁矿（Fe₃O₄）。
  • 保护金属资源：防止腐蚀、回收利用、合理开采、寻找替代品。

溶液与酸碱盐

必考主线
15溶液与溶解度
  • 溶液特征：均一、稳定的混合物。
  • 饱和溶液与不饱和溶液的相互转化：加溶质、蒸发溶剂、降温（对多数固体）。
  • 溶解度：一定温度下 100 g 溶剂中溶解溶质的最大质量。
  • 多数固体溶解度随温度升高而增大（KNO₃ 显著）；Ca(OH)₂ 随温度升高而减小。
  • 溶质质量分数 = 溶质质量/溶液质量 × 100%。
16常见的酸与碱
  • 盐酸 HCl、硫酸 H₂SO₄ 是常见酸；氢氧化钠 NaOH、氢氧化钙 Ca(OH)₂ 是常见碱。
  • 酸的通性（5 条）：与指示剂、活泼金属、金属氧化物、碱、盐反应。
  • 碱的通性（4 条）：与指示剂、非金属氧化物、酸、盐反应。
  • 浓硫酸稀释：把浓硫酸沿器壁慢慢注入水中并不断搅拌（不能反过来）。
  • NaOH 固体易潮解，可作干燥剂；强腐蚀性，须密封保存。
⚠
「酸中不一定有酸根，碱中不一定有金属离子」（如 NH₃·H₂O）——判断题里常见的陷阱。
17中和反应与 pH
  • 中和反应：酸 + 碱 → 盐 + 水（是复分解反应的特例）。
  • NaOH + HCl = NaCl + H₂O；Ca(OH)₂ + 2HCl = CaCl₂ + 2H₂O。
  • pH＜7 为酸性，＝7 为中性，＞7 为碱性；pH 越小酸性越强。
  • 测定 pH：用玻璃棒蘸取待测液滴在 pH 试纸上，与标准比色卡对照（不能把试纸伸入溶液中）。
  • 应用：改良酸性土壤、处理废水、治疗胃酸过多（Al(OH)₃）。
18盐与复分解反应
  • 常见盐：NaCl、Na₂CO₃、NaHCO₃、CaCO₃、CuSO₄。
  • 复分解反应条件：生成沉淀、气体或水，反应才能发生。
  • 常见沉淀：AgCl、BaSO₄（不溶于酸）、CaCO₃、BaCO₃、Cu(OH)₂ 蓝色、Fe(OH)₃ 红褐色。
  • 检验：CO₃²⁻ 用稀盐酸 + 澄清石灰水；Cl⁻ 用 AgNO₃ + 稀硝酸；SO₄²⁻ 用 BaCl₂ + 稀硝酸；NH₄⁺ 用 NaOH 加热产生刺激性气体。
  • 化学肥料：氮肥（尿素、硫酸铵）、磷肥、钾肥、复合肥。
★
「离子的检验」是实验探究题的绝对主角，答题套路：取样 → 加试剂 → 描述现象 → 得出结论。
9

实验探究与计算

拿分技巧
19综合实验探究
  • 常见探究主题：物质的成分、变质情况（NaOH 是否变质为 Na₂CO₃）、反应后溶液中溶质、气体的制取与净化。
  • 实验方案评价：从「是否可行、是否严密、是否环保、是否简便」四方面评价。
  • 气体制备思路：制气（选药品）→ 净化（除杂）→ 干燥 → 收集 → 尾气处理。
20化学计算解题规范
  • 步骤：①设未知量；②写出正确的化学方程式；③写出相关物质的相对分子质量与已知量；④列比例式求解；⑤简明作答。
  • 关键：只有纯净物的质量才能代入方程式计算；溶液质量要换算成溶质质量。
  • 质量分数计算：溶质质量分数 = 溶质质量 ÷ 溶液质量 × 100%。
💡
计算题「解、设、写、列、算、答」六字诀，即使最后算错，正确的方程式和比例式也能拿步骤分。
