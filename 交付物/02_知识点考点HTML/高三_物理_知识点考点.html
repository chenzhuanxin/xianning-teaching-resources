1

力学主干

高考必考 · 约40分
1运动学与牛顿运动定律
  • 匀变速直线运动：①v = v₀ + at；②x = v₀t + ½at²；③v² − v₀² = 2ax；④x = (v₀+v)/2 · t。
  • 重要推论：①中间时刻速度 v(t/2) = (v₀+v)/2 = 平均速度；②连续相等时间间隔位移差 Δx = aT²（逐差法求加速度）。
  • 自由落体：v = gt，h = ½gt²，v² = 2gh。
  • 牛顿三定律：①惯性定律；②F = ma（核心）；③作用力与反作用力。
  • 超重与失重：①加速度向上（或有向上分量）→ 超重，N > mg；②加速度向下 → 失重，N < mg；③完全失重 a = g，N = 0。
  • 连接体：①整体法求加速度（外力/总质量）；②隔离法求内力。
🔑
「整体法 + 隔离法」是连接体问题的黄金组合：先用整体法求系统加速度（前提是各物体加速度相同），再用隔离法对单个物体受力分析求内力。反用也行：已知内力求外力。
2曲线运动、万有引力与机械能
  • 运动的合成与分解：①小船渡河（最短时间：船头垂直河岸；最短位移：合速度垂直河岸）；②绳（杆）末端速度分解（沿绳方向速度相等）。
  • 平抛运动：水平匀速 x=v₀t；竖直自由落体 y=½gt²；合速度 v=√(v₀²+vy²)；tan θ = vy/v₀ = gt/v₀。
  • 圆周运动：①v=ωr；②a=v²/r=ω²r；③向心力 F=mv²/r=mω²r；④竖直平面内圆周运动临界条件——最高点 v ≥ √(gr)（绳模型）或 v ≥ 0（杆模型）。
  • 万有引力：①F = GMm/r²；②GMm/r² = mv²/r = mω²r = m(4π²/T²)r；③黄金代换 GM = gR²。
  • 三个宇宙速度：v₁=7.9 km/s（第一，最小发射速度、最大环绕速度）；v₂=11.2 km/s；v₃=16.7 km/s。
  • 机械能守恒：条件——只有重力（或弹力）做功。E₁ = E₂（动能+势能守恒）。
  • 动能定理：W合 = ΔEk = ½mv² − ½mv₀²（适用于任何过程，是解题首选）。
⚠️
动能定理与机械能守恒的选择原则：有摩擦力、有外力做功 → 用动能定理（万能）；只有重力/弹力做功 → 用机械能守恒（简便）。搞错适用条件会得出错误结论。
3动量与碰撞
  • 冲量：I = Ft，矢量。动量：p = mv，矢量。
  • 动量定理：I合 = Δp = mv₂ − mv₁（可求平均力、求时间、求冲量）。
  • 动量守恒定律：条件——系统不受外力或所受外力之和为零（或内力远大于外力，如碰撞、爆炸）。
  • 碰撞类型：①弹性碰撞（动量守恒 + 动能守恒）；②非弹性碰撞（动量守恒，动能减少）；③完全非弹性碰撞（碰后共速，动能损失最大）。
  • 弹性碰撞结论（一动碰一静）：v₁′ = (m₁−m₂)v₀/(m₁+m₂)；v₂′ = 2m₁v₀/(m₁+m₂)。
  • 反冲与爆炸：①人船模型（m₁x₁ = m₂x₂）；②爆炸过程动量守恒、动能增加。
💡
「人船模型」结论必背：系统初动量为零，则 m₁x₁ = m₂x₂（位移与质量成反比）。这个结论在滑块-滑板、人走船退、气球上升等题型中反复出现，是压轴常客。
2

电磁学主干

高考必考 · 约45分
1电场与电路
  • 电场强度：①定义式 E = F/q（普适）；②点电荷 E = kQ/r²（只适用点电荷）；③匀强电场 E = U/d。
  • 电势与电势差：φ = Ep/q；U(AB) = φA − φB = W(AB)/q。沿电场线方向电势降低。
  • 带电粒子在电场中运动：①加速——qU = ½mv²；②偏转（类平抛）——侧移 y = qUL²/(2mdv₀²)，偏转角 tan θ = qUL/(mdv₀²)。
  • 闭合电路欧姆定律：E = U外 + U内 = I(R+r)。
  • 路端电压：U = E − Ir，随外电阻 R 增大而增大。
  • 电功率：①P总 = EI；②P出 = UI = I²R；③P内 = I²r；④输出功率最大条件 R = r。
🔑
「R = r 时电源输出功率最大」是电路动态分析的核心结论，此时 η = 50%。注意区分：「输出功率最大」和「效率最高」（η 随 R 增大而升高）是两个不同的追求。
2磁场、电磁感应与交流电
  • 安培力：F = BIL（L 垂直于 B）。方向用左手定则（磁感线穿手心，四指指向电流，拇指指向安培力）。
  • 洛伦兹力：f = qvB（v 垂直于 B）。方向用左手定则。洛伦兹力永远不做功。
  • 带电粒子在磁场中运动：①半径 r = mv/(qB)；②周期 T = 2πm/(qB)（与速度无关）；③几何关系——弦的中垂线过圆心。
  • 法拉第电磁感应定律：E = nΔΦ/Δt。
  • 导体切割磁感线：E = BLv（B、L、v 两两垂直）。
  • 楞次定律：感应电流的磁场总要阻碍引起感应电流的磁通量的变化（「增反减同」）。
  • 自感现象：①通电自感——灯泡逐渐变亮；②断电自感——灯泡闪亮后熄灭。
  • 交变电流：①e = Em·sin ωt（Em = NBAω）；②有效值 E = Em/√2；③变压器 U₁/U₂ = n₁/n₂，I₁/I₂ = n₂/n₁（理想变压器功率不变）。
⚠️
有效值不是峰值的一半，也不是平均值。正弦交流电的有效值 = 峰值 / √2 ≈ 0.707 × 峰值。而非正弦（如方波、半波）的有效值必须用「有效值定义」——热效应等效法求解。
3电磁学压轴专题
  • 组合场问题：①粒子依次经过电场、磁场；②在电场中做类平抛/匀变速直线；③在磁场中做匀速圆周；④抓「衔接点」的速度大小与方向。
  • 叠加场问题：①速度选择器（qE = qvB ⟹ v = E/B，与电荷量、质量无关）；②磁流体发电机；③电磁流量计；④霍尔效应。
  • 电磁感应中的动力学：①单杆切割——F − B²L²v/R = ma（加速度随速度增大而减小）；②最终做匀速运动（a=0），最大速度 vmax = FR/(B²L²)。
  • 电磁感应中的能量：W克服安培力 = 产生的电能 = 焦耳热（能量守恒）。
  • 电磁感应中的图像：①i-t、U-t、F-t 图像；②注意转折点（进出磁场）与斜率变化。
💡
「单杆切割」的终极结论：加速度随速度增大而减小，最终 a=0 时速度最大 vmax = FR/(B²L²)；若为电源驱动，则最终电流为零、杆匀速。理解这个「动态收敛」过程，所有变式都能推出来。

选修模块（热学、机械波、光学、近代物理）

高考必考 · 约15分
1热学
  • 分子动理论：①物体由大量分子组成；②分子永不停息做无规则热运动；③分子间存在引力和斥力。
  • 分子力：r = r₀ 时分子力为零（此时分子势能最小）；r < r₀ 表现为斥力；r > r₀ 表现为引力。
  • 温度：是分子平均动能的标志。T = t + 273.15 K。
  • 气体实验定律：①玻意耳定律（等温）p₁V₁=p₂V₂；②查理定律（等容）p₁/T₁=p₂/T₂；③盖-吕萨克定律（等压）V₁/T₁=V₂/T₂。
  • 理想气体状态方程：pV/T = 恒量（p₁V₁/T₁ = p₂V₂/T₂）。
  • 热力学定律：①第一定律 ΔU = Q + W（吸热 Q>0、外界做功 W>0）；②第二定律——热现象有方向性，效率不可能达 100%。
🔑
热力学第一定律的符号规则最容易错：「系统吸热 Q>0、放热 Q<0；外界对系统做功 W>0、系统对外做功 W<0」。判断ΔU 时先看 Q，再看 W，最后相加减。
2机械振动与机械波
  • 简谐运动：①回复力 F = −kx；②位移 x = A sin(ωt+φ)；③周期 T = 2π√(m/k)（弹簧振子）、T = 2π√(L/g)（单摆）。
  • 振动图像：横轴为时间。注意振幅、周期、某时刻的速度与加速度方向。
  • 机械波：①波速 v = λf = λ/T；②波传播的是振动形式和能量，质点不随波迁移；③各质点起振方向与波源相同。
  • 波动图像：横轴为位置。注意波长、振幅、传播方向。
  • 波的干涉：①条件——频率相同；②加强点（路程差 = nλ）；③减弱点（路程差 = (n+½)λ）。
  • 波的衍射：障碍物或孔的尺寸比波长小或与波长差不多时，波明显绕射。
  • 多普勒效应：波源与观察者相互接近，接收频率变高；相互远离，接收频率变低。
⚠️
「振动图像」与「波动图像」极易混淆：振动图像描述一个质点随时间的变化（横轴 t）；波动图像描述某一时刻各质点的位移（横轴 x）。看图先确认横轴是什么。
3光学与近代物理
  • 光的折射：①n = sin i / sin r；②n = c/v；③光在介质中的速度 v = c/n。
  • 全反射：①条件——光从光密介质射向光疏介质，且入射角大于等于临界角；②临界角 sin C = 1/n。
  • 光的干涉：双缝干涉——Δy = Lλ/d（条纹间距）。
  • 光的衍射：单缝衍射——中央条纹最亮最宽。
  • 光电效应：①Ek(max) = hν − W₀（爱因斯坦光电方程）；②截止频率 ν₀ = W₀/h；③光电子最大初动能与光强无关，只与频率有关。
  • 光子说：E = hν（h = 6.63×10⁻³⁴ J·s）。
  • 原子结构：①玻尔模型——轨道量子化、能量量子化；②能级跃迁 hν = Eₘ − Eₙ；③氢原子能级 Eₙ = −13.6/n² eV。
  • 原子核：①衰变（α衰变、β衰变）；②半衰期；③核反应方程质量数与电荷数守恒；④质能方程 E = mc²。
💡
光电效应的「两个无关」必须牢记：①光电子最大初动能与光强无关（只与频率有关）；②能否发生光电效应取决于频率是否达到截止频率（与光强、光照时间无关）。这是选择题的经典陷阱。
