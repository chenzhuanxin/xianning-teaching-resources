1

函数与导数

高考必考 · 约22分
1函数性质综合
  • 单调性：①定义法（取值—作差—变形—定号）；②导数法（f′(x)>0 递增，f′(x)<0 递减）；③复合函数「同增异减」。
  • 奇偶性：①奇函数 f(−x)=−f(x)，图像关于原点对称；②偶函数 f(−x)=f(x)，图像关于y轴对称；③奇函数若在 x=0 处有定义，则 f(0)=0。
  • 周期性：①f(x+T)=f(x)；②若 f(x+a)=−f(x)，则 T=2a；③若 f(x+a)=1/f(x)，则 T=2a。
  • 对称性：①f(a+x)=f(a−x) ⟺ 关于 x=a 对称；②f(a+x)+f(a−x)=2b ⟺ 关于点(a,b)中心对称。
  • 零点：①零点存在定理（连续函数 f(a)·f(b)<0 则 (a,b) 内有零点）；②数形结合求零点个数。
🔑
函数性质「对称 + 周期」联动的黄金结论：若函数有两条对称轴 x=a、x=b（a≠b），则 T=2|b−a|；若有一条对称轴 x=a 和一个对称中心 (b,0)，则 T=4|b−a|。这是压轴题的常用突破口。
2基本初等函数与图像变换
  • 指对幂：①指数 a^x（a>0,a≠1）：a>1 增，0。
  • 对数运算：①log_a(MN)=log_a M + log_a N；②log_a(M/N)=log_a M − log_a N；③log_a M^n = n·log_a M；④换底公式 log_a b = log_c b / log_c a。
  • 图像变换：①平移（左加右减、上加下减）；②伸缩（横向 1/ω，纵向 A）；③对称（关于x轴、y轴、原点、y=x）；④翻折（|f(x)| 下翻上、f(|x|) 右翻左）。
  • 比大小：①同底用单调性；②同指用图像；③引入中间量（0、1）；④构造函数用导数。
💡
指对数比大小「三个中间量」：0、1、以及题目中的特殊值。先把每个数定位在哪两个整数之间，往往就能排除大半选项。近几年新高考偏爱「构造函数 + 导数」的比大小题。
3导数及其应用
  • 导数公式：①(x^n)′=nx^(n−1)；②(e^x)′=e^x；③(a^x)′=a^x·ln a；④(ln x)′=1/x；⑤(log_a x)′=1/(x ln a)；⑥(sin x)′=cos x；⑦(cos x)′=−sin x。
  • 运算法则：①(uv)′=u′v+uv′；②(u/v)′=(u′v−uv′)/v²；③复合函数 y=f(g(x)) 的导数 y′=f′(g(x))·g′(x)。
  • 切线方程：①「在点 P 处」→ P 是切点，k=f′(x₀)；②「过点 P」→ P 不一定是切点，需设切点 (t, f(t)) 求解。
  • 单调性与极值：①f′(x)>0 递增，f′(x)<0 递减；②极值点处 f′(x)=0（且左右变号）；③最值需比较极值与端点值。
  • 恒成立问题：①f(x)≥a 恒成立 ⟺ f(x)min ≥ a；②f(x)≤a 恒成立 ⟺ f(x)max ≤ a；③分离参数法（首选）。
⚠️
「在点处」与「过点」的切线问题是最高频陷阱：「在点 P 处」P 一定是切点；「过点 P」P 可能在曲线上也可能不在，必须设切点坐标 t 联立求解。这一步错了，整题零分。
2

三角、数列与立体几何

高考必考 · 约27分
1三角函数与解三角形
  • 诱导公式：「奇变偶不变，符号看象限」。
  • 同角关系：sin²α + cos²α = 1；tan α = sin α / cos α。
  • 和差倍角：①sin(α±β)=sinαcosβ ± cosαsinβ；②cos(α±β)=cosαcosβ ∓ sinαsinβ；③sin2α=2sinαcosα；④cos2α=cos²α−sin²α=2cos²α−1=1−2sin²α。
  • 辅助角公式：a sin x + b cos x = √(a²+b²)·sin(x+φ)。
  • 正弦定理：a/sin A = b/sin B = c/sin C = 2R。
  • 余弦定理：a² = b² + c² − 2bc·cos A。
  • 面积公式：S = ½ab·sin C。
🔑
解三角形「边角互化」是核心思路：①求角优先用余弦定理；②已知两边及对角（SSA）优先用正弦定理；③注意「大边对大角」判定解的个数。SSA 情形可能有两解，必须检验。
2数列
  • 等差：①aₙ = a₁ + (n−1)d；②Sₙ = n(a₁+aₙ)/2 = na₁ + n(n−1)d/2；③中项 2aₙ = aₙ₋₁ + aₙ₊₁。
  • 等比：①aₙ = a₁q^(n−1)；②Sₙ = a₁(1−q^n)/(1−q)（q≠1）；③中项 aₙ² = aₙ₋₁·aₙ₊₁。
  • 求通项方法：①公式法；②累加法（aₙ₊₁−aₙ=f(n)）；③累乘法（aₙ₊₁/aₙ=f(n)）；④构造法（aₙ₊₁=paₙ+q 型构造等比）；⑤已知 Sₙ 求 aₙ（aₙ=Sₙ−Sₙ₋₁，n≥2）。
  • 求和方法：①公式法；②错位相减（等差×等比型）；③裂项相消（1/[n(n+1)] 型）；④分组求和；⑤倒序相加。
💡
错位相减与裂项相消是数列大题的「两大得分引擎」。识别口诀：看到「等差×等比」就错位相减；看到「分式且分母是乘积」就裂项相消。用错方法，整题全废。
3立体几何
  • 平行判定：①线面平行（平面外一条直线与平面内一条直线平行 ⟹ 线面平行）；②面面平行（一个平面内两条相交直线分别平行于另一平面 ⟹ 面面平行）。
  • 垂直判定：①线面垂直（一条直线垂直于平面内两条相交直线 ⟹ 线面垂直）；②面面垂直（一个平面过另一个平面的垂线 ⟹ 面面垂直）。
  • 空间向量法：①建系（找三条两两垂直的直线）；②求法向量 n；③线面角 sinθ=|cos⟨a,n⟩|；④面面角 |cos⟨n₁,n₂⟩|；⑤点到面距离 d=|AP·n|/|n|。
  • 外接球常见模型：①长方体（正方体）型 → 2R=√(a²+b²+c²)；②正三棱柱型；③对棱相等型；④侧棱垂直底面型。
  • 体积公式：V(柱)=Sh；V(锥)=⅓Sh；V(球)=4/3πR³；S(球)=4πR²。
⚠️
立体几何大题「几何法」与「向量法」要会选：证明平行垂直用几何定理（简洁、得分快）；求角度和距离用空间向量（不用找辅助线，稳妥）。新高考更推荐向量法求角。

解析几何、概率统计与压轴专题

高考必考 · 约41分
1平面解析几何
  • 直线：①斜率 k=(y₂−y₁)/(x₂−x₁)；②点斜式 y−y₁=k(x−x₁)；③点到直线距离 d=|Ax₀+By₀+C|/√(A²+B²)；④平行 k₁=k₂，垂直 k₁k₂=−1。
  • 圆：①标准方程 (x−a)²+(y−b)²=r²；②一般方程 x²+y²+Dx+Ey+F=0（D²+E²−4F>0）；③直线与圆位置关系用圆心到直线距离 d 与 r 比较。
  • 椭圆：①x²/a²+y²/b²=1（a>b>0）；②c²=a²−b²；③e=c/a∈(0,1)；④焦点弦、通径 2b²/a。
  • 双曲线：①x²/a²−y²/b²=1；②c²=a²+b²；③e=c/a>1；④渐近线 y=±(b/a)x。
  • 抛物线：①y²=2px（焦点(p/2,0)，准线 x=−p/2）；②焦半径 |PF|=x₀+p/2。
  • 弦长公式：|AB|=√(1+k²)·|x₁−x₂| = √(1+k²)·√[(x₁+x₂)²−4x₁x₂]。
🔑
圆锥曲线大题标准套路：①设直线方程（注意讨论斜率不存在的情况！）；②联立曲线方程得二次方程；③用韦达定理求 x₁+x₂、x₁x₂；④代入目标式化简。「联立 + 韦达」是永恒不变的第一步。
2概率与统计
  • 排列组合：①A(n,m)=n!/(n−m)!（排列，有顺序）；②C(n,m)=n!/[m!(n−m)!]（组合，无顺序）；③二项式定理 (a+b)^n 展开式的通项 T(r+1)=C(n,r)a^(n−r)b^r。
  • 古典概型：P(A)=A包含的基本事件数 / 基本事件总数。
  • 条件概率：P(B|A)=P(AB)/P(A)。全概率公式：P(B)=ΣP(Aᵢ)P(B|Aᵢ)。
  • 独立性：P(AB)=P(A)P(B) ⟺ A、B 相互独立。
  • 分布列：①二项分布 X~B(n,p)：E(X)=np，D(X)=np(1−p)；②超几何分布；③正态分布 X~N(μ,σ²)：关于 x=μ 对称。
  • 期望方差：E(aX+b)=aE(X)+b；D(aX+b)=a²D(X)。
  • 统计：①平均数、方差、中位数、众数；②线性回归方程 ŷ=b̂x+â；③独立性检验 χ²；④相关系数 r。
💡
条件概率 vs 独立性的区分是选择题高频坑：P(B|A) 是「在 A 已发生的前提下 B 发生」；A、B 独立是 P(B|A)=P(B)。独立是条件概率的特殊情况，不要把两者混为一谈。
3高考压轴专题
  • 导数压轴：①含参讨论（分界点由 f′(x)=0 的根决定）；②零点的存在性与个数（构造 + 数形结合 + 零点定理）；③不等式证明（构造辅助函数求最值）；④双变量问题（极值点偏移、对数平均不等式）。
  • 解析几何压轴：①定点问题（设参数，证结果与参数无关）；②定值问题；③最值范围（判别式 + 韦达 + 基本不等式）；④存在性问题。
  • 数列压轴：①数列不等式（放缩法、数学归纳法）；②新定义数列；③数列与函数综合。
  • 新定义题型：①读懂定义（新概念、新运算）；②转化为已知模型；③验证边界情形。
  • 解题策略：①分步得分（第一问必拿，第二问尽量写步骤）；②特殊值探路；③数形结合；④时间分配（压轴题留 20 分钟）。
⚠️
压轴题「分步得分」是铁律：即使最后一问完全不会，也要把「设点、联立、韦达」这些固定步骤写出来——每一步都有分。空着不写是最大的浪费。
