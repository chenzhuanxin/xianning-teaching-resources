集合与常用逻辑用语

基础 · 必考
1集合的概念与运算
  • 元素与集合的关系：属于（∈）与不属于（∉）。集合三特性：确定性、互异性、无序性。
  • 常用数集符号：N（自然数集）、N*或N₊（正整数集）、Z（整数集）、Q（有理数集）、R（实数集）。
  • 集合间关系：子集（A⊆B）、真子集（A⊊B）、相等（A=B）、空集（∅）。
  • 空集是任何集合的子集，是任何非空集合的真子集——这是最容易漏解的地方。
  • 集合运算：交集（A∩B）、并集（A∪B）、补集（∁ᵤA）。
  • 含参集合问题务必分类讨论：先讨论集合是否为空集，再讨论元素关系。
⚠️
已知 A⊆B 求参数范围时，必须单独讨论 A=∅ 的情形。这是高一数学最容易丢分的第一坑。
2常用逻辑用语
  • 充分条件与必要条件：p⇒q 则 p 是 q 的充分条件，q 是 p 的必要条件。
  • 充要条件：p⇔q，即p 既是 q 的充分条件，也是 q 的必要条件。
  • 判断技巧：小范围能推出大范围（小⇒大），大范围不能推出小范围。集合视角：A⊆B 则 A 是 B 的充分条件。
  • 全称量词与存在量词：∀（任意）、∃（存在）。
  • 量词否定：∀x∈M, p(x) 的否定是 ∃x∈M, ¬p(x)；∃x∈M, p(x) 的否定是 ∀x∈M, ¬p(x)（量词互换，结论取反）。
💡
记忆口诀：「任意」的否定是「存在」，「存在」的否定是「任意」，同时把结论否定掉。

一元二次函数、方程和不等式

重点 · 高频
1不等式性质与基本不等式
  • 不等式基本性质：a>b ⇔ a+c>b+c；a>b, c>0 ⇒ ac>bc；a>b, c<0 ⇒ ac<bc。
  • 基本不等式：a+b ≥ 2√(ab)（a>0, b>0），当且仅当 a=b 时取等号。
  • 常用变形：ab ≤ ((a+b)/2)²；a²+b² ≥ 2ab。
  • 「一正二定三相等」：一正——各项为正；二定——和或积为定值；三相等——验证等号能否取到。
  • 常见配凑技巧：配系数、拆项、乘1法（已知 ax+by=1 求 1/x+1/y 最小值）。
🔑
用基本不等式求最值，三步缺一不可。尤其第三步「验证等号成立条件」常常被忽略，导致答案错误。
2一元二次不等式
  • 解法核心：「三个二次」的关系——二次函数图像、二次方程根、二次不等式解集。
  • 标准步骤：①二次项系数化为正；②求判别式 Δ=b²-4ac；③求根；④画图像写解集。
  • 口诀记忆：「大于取两边，小于取中间」（a>0 时）。
  • Δ<0 时：若 a>0，则不等式 >0 的解集为 R，<0 的解集为 ∅。
  • 分式不等式：移项通分化为整式，注意分母不为零（解集端点取不取要判断）。
  • 含参二次不等式必须讨论开口方向、判别式、根的大小三个层次。

函数概念与性质

核心 · 必考
1函数三要素与表示
  • 函数三要素：定义域、值域、对应关系。
  • 求定义域常见限制：分式分母≠0；偶次根式被开方数≥0；对数真数>0；零指数幂底数≠0；tanx 中 x≠π/2+kπ。
  • 求值域常用方法：配方法、分离常数法、换元法、单调性法、判别式法、基本不等式法。
  • 分段函数：不同区间对应不同解析式，求值时要先判断自变量落在哪个区间。
  • 抽象函数定义域：已知 f(x) 定义域为 [a,b]，求 f(g(x)) 定义域即解 a ≤ g(x) ≤ b。
💡
抽象函数定义域是「括号内整体范围一致」——这是解题的唯一依据，抓住这一点就不会乱。
2函数的单调性与奇偶性
  • 单调性定义：x₁<x₂ 时 f(x₁)<f(x₂) 为增函数；f(x₁)>f(x₂) 为减函数。
  • 判断方法：定义法（作差/作商）、图像法、复合函数同增异减、导数法。
  • 复合函数单调性口诀：「同增异减」——内外层单调性相同则复合后为增，相反则为减。
  • 奇偶性定义：f(-x)=-f(x) 为奇函数（图像关于原点对称）；f(-x)=f(x) 为偶函数（图像关于 y 轴对称）。
  • 前提条件：定义域必须关于原点对称，否则既非奇也非偶。
  • 奇函数若在 x=0 处有定义，则 f(0)=0。
3幂函数与函数图像
  • 五个常见幂函数：y=x、y=x²、y=x³、y=x^(1/2)、y=x⁻¹。
  • 幂函数性质：所有幂函数图像都过点 (1,1)；在 (0,+∞) 上，α>0 时递增，α<0 时递减。
  • 图像变换：平移（左加右减、上加下减）、对称（关于x轴/y轴/原点）、翻折（|f(x)| 与 f(|x|)）、伸缩。
  • y=|f(x)| 的图像：把 x 轴下方的部分翻折到上方。
  • y=f(|x|) 的图像：保留 y 轴右侧，左侧与右侧关于 y 轴对称。

指数函数与对数函数

重点 · 高频
1指数运算与指数函数
  • 指数运算法则：aᵐ·aⁿ=aᵐ⁺ⁿ；(aᵐ)ⁿ=aᵐⁿ；(ab)ⁿ=aⁿbⁿ；a^(-n)=1/aⁿ；a^(m/n)=ⁿ√(aᵐ)。
  • 指数函数 y=aˣ（a>0 且 a≠1）：定义域 R，值域 (0,+∞)，恒过定点 (0,1)。
  • 单调性：a>1 时单调递增；0<a<1 时单调递减。
  • 图像特征：x 轴是渐近线，图像永远在 x 轴上方。
2对数运算与对数函数
  • 对数定义：aᵇ=N ⇔ b=logₐN（a>0, a≠1, N>0）。
  • 对数运算法则：logₐ(MN)=logₐM+logₐN；logₐ(M/N)=logₐM-logₐN；logₐMⁿ=nlogₐM。
  • 两个重要恒等式：logₐ1=0；logₐa=1；a^(logₐN)=N。
  • 换底公式：logₐb = log_c b / log_c a。常用推论：logₐb·log_b a=1。
  • 对数函数 y=logₐx：定义域 (0,+∞)，值域 R，恒过定点 (1,0)。
  • 单调性：a>1 递增；0<a<1 递减。y 轴是渐近线。
🔑
对数运算三大易错点：①真数必须大于0；②logₐ(M+N) ≠ logₐM + logₐN（不能拆）；③底数范围限制 a>0 且 a≠1。
3函数零点与二分法
  • 零点定义：使 f(x)=0 的实数 x，即函数图像与 x 轴交点的横坐标。
  • 零点存在定理：若 f(x) 在 [a,b] 上连续，且 f(a)·f(b)<0，则 (a,b) 内至少存在一个零点。
  • 注意：该定理只能判断存在，不能确定个数；反之 f(a)·f(b)>0 也不能说明没有零点。
  • 二分法求近似解：不断取中点缩小区间，直到满足精度要求。适用于连续且单调的函数。
  • 零点个数问题转化为：两个函数图像交点个数。

三角函数

核心 · 必考
1任意角与弧度制
  • 任意角：按逆时针旋转为正角，顺时针为负角，不旋转为零角。
  • 终边相同的角：S={β | β=α+k·360°, k∈Z}。
  • 弧度制：1 rad = (180/π)° ≈ 57.3°；π rad = 180°。
  • 弧长公式：l = |α|·r；扇形面积公式：S = ½lr = ½|α|r²。
  • 象限角符号口诀：「一全正，二正弦，三正切，四余弦」。
💡
用弧度制时角度符号 ° 必须省略。写 sin30° 正确，写 sin30 就是错的（那是 sin(30 rad)）。
2三角函数定义与诱导公式
  • 任意角三角函数定义：设终边上一点 P(x,y)，r=√(x²+y²)，则 sinα=y/r，cosα=x/r，tanα=y/x。
  • 同角三角函数基本关系：sin²α+cos²α=1；tanα=sinα/cosα。
  • 诱导公式口诀：「奇变偶不变，符号看象限」。
  • 「奇变偶不变」：看 k·(π/2)±α 中的 k，k 为奇数则函数名改变（sin↔cos），k 为偶数则不变。
  • 「符号看象限」：把 α 视为锐角，判断原角所在象限的原函数符号。
🔑
诱导公式的关键是把「α」永远当锐角来定符号，不要纠结 α 的真实大小。这是口诀能生效的前提。
3三角函数图像与性质
  • y=sinx：定义域 R，值域 [-1,1]，周期 2π，奇函数，在 [-π/2+2kπ, π/2+2kπ] 递增。
  • y=cosx：定义域 R，值域 [-1,1]，周期 2π，偶函数，在 [-π+2kπ, 2kπ] 递增。
  • y=tanx：定义域 x≠π/2+kπ，值域 R，周期 π，奇函数，在 (-π/2+kπ, π/2+kπ) 递增。
  • y=Asin(ωx+φ) 的图像：A 决定振幅，ω 决定周期 T=2π/ω，φ 决定左右平移。
  • 图像变换顺序：先平移后伸缩，或先伸缩后平移（平移量不同，需除以 ω）。
  • y=Asin(ωx+φ)+B 的最值：最大值 A+B，最小值 -A+B。
4三角恒等变换
  • 两角和差公式：sin(α±β)=sinαcosβ±cosαsinβ；cos(α±β)=cosαcosβ∓sinαsinβ。
  • 正切和差公式：tan(α±β)=(tanα±tanβ)/(1∓tanαtanβ)。
  • 二倍角公式：sin2α=2sinαcosα；cos2α=cos²α-sin²α=2cos²α-1=1-2sin²α；tan2α=2tanα/(1-tan²α)。
  • 降幂公式：sin²α=(1-cos2α)/2；cos²α=(1+cos2α)/2。
  • 辅助角公式：asinx+bcosx = √(a²+b²)sin(x+φ)，其中 tanφ=b/a。
  • 解题策略：化异为同（统一角、统一函数名）、降幂扩角、辅助角合一。

平面向量与复数

重点 · 必考
1平面向量线性运算
  • 向量三要素：大小、方向、起点无关（自由向量）。
  • 线性运算：加法（首尾相接/平行四边形）、减法（共起点，指向被减）、数乘（λa，λ>0 同向，λ<0 反向）。
  • 共线定理：a∥b（b≠0）⇔ 存在唯一实数 λ 使 a=λb。
  • 坐标运算：若 a=(x₁,y₁)，b=(x₂,y₂)，则 a±b=(x₁±x₂, y₁±y₂)，λa=(λx₁, λy₁)。
  • 共线坐标条件：x₁y₂ - x₂y₁ = 0。
2平面向量数量积
  • 数量积定义：a·b = |a||b|cosθ（θ 为两向量夹角，范围 [0,π]）。
  • 坐标公式：a·b = x₁x₂ + y₁y₂。
  • 模的公式：|a| = √(a·a) = √(x₁²+y₁²)。
  • 夹角公式：cosθ = (a·b)/(|a||b|)。
  • 垂直条件：a⊥b ⇔ a·b=0 ⇔ x₁x₂+y₁y₂=0。
  • 投影：a 在 b 方向上的投影为 |a|cosθ = (a·b)/|b|。
⚠️
数量积不满足结合律：(a·b)·c ≠ a·(b·c)。因为左边是数与向量的乘积，方向与 c 同向；右边方向与 a 同向。
3复数
  • 复数代数形式：z = a + bi（a,b∈R），a 为实部，b 为虚部。
  • i 的幂周期：i¹=i，i²=-1，i³=-i，i⁴=1（周期 4）。
  • 共轭复数：z̄ = a - bi。
  • 复数相等：a+bi = c+di ⇔ a=c 且 b=d。
  • 复数模：|z| = √(a²+b²)。
  • 复平面：z=a+bi 对应点 (a,b)，实轴 x 轴，虚轴 y 轴（原点除外）。
  • 复数除法：分子分母同乘分母的共轭复数，实现分母实数化。

立体几何初步

重点 · 必考
1空间几何体
  • 柱体：V = S底·h（棱柱、圆柱）；S侧(圆柱) = 2πrh。
  • 锥体：V = ⅓S底·h（棱锥、圆锥）；S侧(圆锥) = πrl。
  • 台体：V = ⅓h(S + √(SS') + S')。
  • 球体：V = 4/3πR³；S表 = 4πR²。
  • 三视图：正视图、侧视图、俯视图，遵循「长对正、高平齐、宽相等」。
  • 直观图斜二测画法：水平方向不变，竖直方向减半，夹角 45°。
🔑
球的表面积和体积公式是必考内容，且常与内切球、外接球结合。牢记 S=4πR²、V=4/3πR³，并掌握「补形法」求外接球半径。
2点线面位置关系
  • 基本事实：①过不在一条直线上的三点，有且只有一个平面；②如果一条直线上的两点在一个平面内，那么这条直线在此平面内；③如果两个不重合的平面有一个公共点，那么它们有且只有一条过该点的公共直线。
  • 线面平行判定：平面外一条直线与此平面内的一条直线平行，则该直线与此平面平行。
  • 线面平行性质：一条直线与一个平面平行，则过这条直线的任一平面与此平面的交线与该直线平行。
  • 面面平行判定：一个平面内的两条相交直线与另一个平面平行，则这两个平面平行。
  • 线面垂直判定：一条直线与平面内的两条相交直线都垂直，则该直线与此平面垂直。
  • 面面垂直判定：一个平面过另一个平面的垂线，则这两个平面垂直。
💡
证明题写步骤要严格引用定理原文。平行、垂直的判定与性质共 8 个定理，必须逐一记准条件与结论。
3空间角与距离
  • 异面直线所成角：范围 (0°, 90°]，通过平移法构造。
  • 线面角：范围 [0°, 90°]，是斜线与它在平面内射影所成的角。
  • 二面角：范围 [0°, 180°]，需作出平面角。
  • 空间距离：点到平面的距离常用等体积法求解。

统计与概率

重点 · 必考
1统计
  • 抽样方法：简单随机抽样（抽签法、随机数法）、分层随机抽样。
  • 分层抽样比例：各层抽取数 : 各层总数 = 样本容量 : 总体容量。
  • 集中趋势：平均数、中位数、众数。
  • 离散程度：极差、方差、标准差。方差 s² = (1/n)Σ(xᵢ-x̄)²。
  • 百分位数：第 p 百分位数是将数据从小到大排列后，处于 p% 位置的数。
2概率
  • 古典概型：P(A) = A包含的基本事件数 / 基本事件总数，要求有限性和等可能性。
  • 对立事件：P(A) + P(Ā) = 1。
  • 互斥事件：若 A、B 互斥，则 P(A∪B)=P(A)+P(B)。
  • 相互独立事件：P(AB) = P(A)·P(B)。
  • 条件概率：P(B|A) = P(AB)/P(A)。
  • 全概率公式：P(B) = ΣP(Aᵢ)P(B|Aᵢ)。
⚠️
区分「互斥」与「独立」：互斥是两个事件不能同时发生，独立是一个事件发生不影响另一个的概率。互斥一般不独立（除非概率为0）。
