物质及其变化

基础 · 必考
1物质的分类
  • 树状分类法：按层次逐级分类，如物质→混合物/纯净物→单质/化合物→酸/碱/盐/氧化物。
  • 交叉分类法：对同一物质从不同角度分类，如 Na₂CO₃ 既是钠盐又是碳酸盐。
  • 分散系：把一种（或多种）物质分散在另一种（或多种）物质中所得到的体系。按分散质粒子直径分为溶液（<1nm）、胶体（1~100nm）、浊液（>100nm）。
  • 胶体的性质：丁达尔效应（区分胶体与溶液的方法）、布朗运动、电泳、聚沉。
  • Fe(OH)₃ 胶体的制备：向沸水中逐滴加入饱和 FeCl₃ 溶液，继续煮沸至液体呈红褐色，停止加热。
🔑
丁达尔效应是区分胶体和溶液的物理方法：让光束通过分散系，出现一条光亮的「通路」的是胶体。这是高考高频考查点。
2离子反应
  • 电解质：在水溶液里或熔融状态下能导电的化合物（酸、碱、盐、活泼金属氧化物）。
  • 非电解质：在水溶液里和熔融状态下都不导电的化合物（蔗糖、酒精、CO₂、SO₂ 等）。
  • 强电解质：完全电离（强酸、强碱、大部分盐）。弱电解质：部分电离（弱酸、弱碱、水）。
  • 离子方程式书写四步：写（写出化学方程式）→ 拆（把强电解质拆成离子）→ 删（删去两边相同的离子）→ 查（检查原子守恒和电荷守恒）。
  • 不能拆的物质：弱电解质、难溶物、气体、水、氧化物。
⚠️
离子方程式的两大守恒必须同时满足：质量守恒（原子个数相等）和电荷守恒（两边电荷总数相等）。答题后必须检查电荷是否平衡。
3氧化还原反应
  • 本质：电子的转移（得失或偏移）。
  • 特征：元素化合价发生升降。
  • 口诀：「升失氧还原剂，降得还氧化剂」——化合价升高、失去电子、被氧化、作还原剂；化合价降低、得到电子、被还原、作氧化剂。
  • 常见氧化剂：O₂、Cl₂、浓H₂SO₄、HNO₃、KMnO₄、FeCl₃。
  • 常见还原剂：金属单质、H₂、C、CO、SO₂、KI。
  • 电子守恒计算：氧化剂得电子总数 = 还原剂失电子总数。
🔑
氧化还原反应是高中化学的核心主线，贯穿元素化合物、电化学、化学实验全部内容。务必把「化合价升降 = 电子转移」这一逻辑刻进习惯里。

海水中的重要元素——钠和氯

重点 · 必考
1钠及其化合物
  • 钠（Na）：银白色金属，质软，密度比水小，熔点低。与氧气反应：常温生成 Na₂O，加热生成 Na₂O₂。
  • 钠与水反应：2Na + 2H₂O = 2NaOH + H₂↑。现象口诀：「浮、熔、游、响、红」（浮在水面、熔成小球、四处游动、发出响声、溶液变红）。
  • Na₂O₂：淡黄色固体，与 H₂O、CO₂ 反应均放出 O₂。可用于潜水艇和呼吸面具供氧。
  • Na₂CO₃ 与 NaHCO₃：前者俗称纯碱/苏打，后者俗称小苏打。热稳定性：Na₂CO₃ > NaHCO₃（NaHCO₃ 受热分解）。
💡
钠与水反应的现象「浮熔游响红」是必背内容。「熔」说明反应放热且钠熔点低，「浮」说明钠密度小于水。
2氯及其化合物
  • 氯气（Cl₂）：黄绿色、有刺激性气味的有毒气体。溶于水得氯水，呈浅黄绿色。
  • 氯水成分：Cl₂、HClO、H₂O、H⁺、Cl⁻、ClO⁻、少量 OH⁻。
  • 次氯酸（HClO）：弱酸，具有强氧化性和漂白性，不稳定，见光分解：2HClO →(光照) 2HCl + O₂↑。
  • 漂白粉：主要成分 Ca(ClO)₂ 和 CaCl₂，有效成分是 Ca(ClO)₂。
  • Cl⁻ 检验：加入 AgNO₃ 溶液产生白色沉淀，再加稀硝酸沉淀不溶解。
3物质的量
  • 物质的量（n）：表示含有一定数目粒子的集合体的物理量，单位摩尔（mol）。
  • 阿伏加德罗常数：NA ≈ 6.02×10²³ mol⁻¹。
  • 摩尔质量（M）：单位物质的量的物质所具有的质量，单位 g/mol。数值上等于相对分子（原子）质量。
  • 公式：n = m/M = N/NA = V/Vm（气体）。
  • 气体摩尔体积：标准状况（0℃，101kPa）下 Vm ≈ 22.4 L/mol。
  • 物质的量浓度：c = n/V（V 为溶液体积，单位 L）。
⚠️
22.4 L/mol 的使用有两个前提：①标准状况（0℃、101 kPa）；②物质必须是气体。常温常压、或物质是液体固体，都不能用这个数值。这是阿伏加德罗常数题最常设的陷阱。

铁 金属材料

重点
1铁及其化合物
  • 铁：能被磁铁吸引。与 Cl₂ 反应生成 FeCl₃（+3价），与稀盐酸反应生成 FeCl₂（+2价）。
  • Fe²⁺ 与 Fe³⁺ 的检验：Fe³⁺ 遇 KSCN 溶液变血红色；Fe²⁺ 需先加 KSCN 无现象，再加氯水变血红色。
  • Fe(OH)₂ → Fe(OH)₃ 的转化：白色沉淀迅速变灰绿色，最终变红褐色。
  • 铁的三角转化：Fe ⇌ Fe²⁺ ⇌ Fe³⁺，通过加入氧化剂或还原剂实现相互转化。
🔑
Fe³⁺ 与 Fe²⁺ 的鉴别是必考实验：KSCN 溶液是 Fe³⁺ 的特效试剂。检验 Fe²⁺ 时要注意——必须先证明无 Fe³⁺，再证明有 Fe²⁺，两步缺一不可。
2金属材料与合金
  • 合金：由两种或两种以上的金属（或金属与非金属）熔合而成的具有金属特性的物质。
  • 合金的硬度一般大于各成分金属，熔点一般低于各成分金属。
  • 铝及其氧化物：Al₂O₃ 是两性氧化物，既能与酸反应又能与强碱反应。Al(OH)₃ 是两性氢氧化物。
  • 铝热反应：2Al + Fe₂O₃ →(高温) Al₂O₃ + 2Fe，可用于焊接钢轨、冶炼高熔点金属。

物质结构 元素周期律

核心 · 必考
1原子结构与元素周期表
  • 原子构成：原子序数 = 核电荷数 = 质子数 = 核外电子数。
  • 质量数（A）= 质子数（Z）+ 中子数（N）。
  • 核外电子排布规律：①各电子层最多容纳 2n² 个电子；②最外层不超过 8 个（K 层为最外层时不超过 2 个）；③次外层不超过 18 个。
  • 周期表结构：7 个周期、18 个纵列（16 个族：7 个主族、7 个副族、1 个第Ⅷ族、1 个 0 族）。
  • 周期序数 = 电子层数；主族序数 = 最外层电子数。
💡
记周期表位置的口诀：「周期看层数，主族看最外」。这是推断题最基础也最常用的一步。
2元素周期律
  • 原子半径：同周期从左到右逐渐减小；同主族从上到下逐渐增大。
  • 金属性：同周期从左到右减弱；同主族从上到下增强。
  • 非金属性：同周期从左到右增强；同主族从上到下减弱。
  • 最高价氧化物对应水化物酸性：非金属性越强，酸性越强。
  • 气态氢化物稳定性：非金属性越强，越稳定。
  • 离子半径比较：电子层结构相同的离子，核电荷数越大半径越小。
🔑
元素周期律的判断金属性/非金属性强弱是核心考点。判断依据：①与水或酸反应置换氢的难易；②最高价氧化物对应水化物的碱（酸）性强弱；③单质间的置换反应。
3化学键
  • 离子键：阴阳离子间的静电作用。含离子键的化合物是离子化合物（如 NaCl、MgO）。
  • 共价键：原子间通过共用电子对形成的相互作用。分极性共价键（不同种原子）和非极性共价键（同种原子）。
  • 化学反应的实质：旧化学键断裂、新化学键形成。
  • 注意：离子化合物中一定含离子键，可能含共价键（如 NaOH 含 O-H 共价键）。
