一、八上·三角形与全等

几何核心
11. 三角形
  • 三边关系：任意两边之和大于第三边，任意两边之差小于第三边。
  • 内角和定理：三角形内角和为 180°；外角等于与它不相邻的两个内角之和。
  • 重要线段：高、中线、角平分线。中线把三角形分成面积相等的两部分。
  • 多边形：n 边形内角和 = (n−2)×180°；任意多边形外角和 = 360°。
★
求「等腰三角形周长」必须分类讨论：已知两边为 a、b，要分别讨论 a 为腰和 b 为腰，并检验是否满足三边关系。
22. 全等三角形
  • 判定方法：SSS、SAS、ASA、AAS、HL（直角三角形专用）。
  • 注意：SSA 不能判定全等；AAA 只能判定相似，不能判定全等。
  • 性质：全等三角形的对应边相等、对应角相等、周长相等、面积相等。
  • 角平分线性质：角平分线上的点到角两边的距离相等；反之，到角两边距离相等的点在角平分线上。
  • 垂直平分线性质：线段垂直平分线上的点到线段两端点的距离相等。
⚠
证明题书写要求：必须写「在△×××和△×××中」，按 SSS/SAS/ASA/AAS 顺序列出条件，最后注明依据。书写不规范是八年级几何失分主因。
33. 轴对称
  • 轴对称图形：沿一条直线折叠，直线两旁部分能完全重合。
  • 坐标变换：点 (x, y) 关于 x 轴对称 → (x, −y)；关于 y 轴对称 → (−x, y)；关于原点对称 → (−x, −y)。
  • 等腰三角形：等边对等角；三线合一（顶角平分线、底边中线、底边高互相重合）。
  • 等边三角形：三边相等，三角均为 60°；有一个角是 60° 的等腰三角形是等边三角形。
  • 含 30° 角的直角三角形：30° 角所对的直角边等于斜边的一半。
💡
「三线合一」是八年级几何的超级工具：只要出现等腰三角形 + 一条线，就能推出另外两条性质。

二、八上·整式乘法与因式分解

代数核心
11. 幂的运算
  • 同底数幂相乘：aᵐ · aⁿ = aᵐ⁺ⁿ
  • 幂的乘方：(aᵐ)ⁿ = aᵐⁿ
  • 积的乘方：(ab)ⁿ = aⁿbⁿ
  • 同底数幂相除：aᵐ ÷ aⁿ = aᵐ⁻ⁿ（a≠0）
  • 零指数幂：a⁰ = 1（a≠0）；负整数指数幂：a⁻ⁿ = 1/aⁿ（a≠0）
💡
易混：「aᵐ · aⁿ」是指数相加（乘法变加法），「(aᵐ)ⁿ」是指数相乘。做题前先圈出符号。
22. 乘法公式与因式分解
  • 平方差公式：(a+b)(a−b) = a² − b²
  • 完全平方公式：(a±b)² = a² ± 2ab + b²
  • 因式分解三法：①提公因式；②公式法（平方差、完全平方）；③十字相乘法（拓展）。
  • 因式分解必须分解到不能再分解为止，且结果必须是乘积形式。
  • 常用变形：a² + b² = (a+b)² − 2ab = (a−b)² + 2ab。
⚠
「完全平方公式」中间项常漏掉 2 或漏符号：(a+b)² = a² + 2ab + b²，不是 a² + ab + b²。这是八年级代数第一大坑。

三、八上·分式与二次根式（八下）

代数核心
11. 分式
  • 基本性质：分子分母同乘（除）以同一个不为零的整式，分式的值不变。
  • 运算顺序：先乘除后加减，有括号先算括号；除以一个分式等于乘以它的倒数。
  • 分式方程：去分母（两边同乘最简公分母）→ 解整式方程 → 必须检验（验根）。
  • 增根：使最简公分母为零的根，必须舍去。
★
分式方程不检验必扣分。解分式方程的应用题还要注意「符合实际意义」。
22. 二次根式
  • 性质：√a ≥ 0（a≥0）；(√a)² = a；√(a²) = |a|。
  • 乘除法则：√a · √b = √(ab)；√a ÷ √b = √(a/b)（a≥0, b>0）。
  • 化简：把根号内的完全平方因数移到根号外，如 √8 = 2√2。
  • 最简二次根式：被开方数不含分母，不含能开得尽方的因数。
  • 合并：只有同类二次根式（化简后被开方数相同）才能合并。
💡
√(a²) = |a| 而不是 a。当 a 的正负未知时，必须讨论结果，这是高频失分点。

四、八下·勾股定理与四边形

几何核心
11. 勾股定理
  • 勾股定理：直角三角形中 a² + b² = c²（c 为斜边）。
  • 逆定理：若三角形三边满足 a² + b² = c²，则它是直角三角形（c 为最长边）。
  • 常用勾股数：(3,4,5)、(5,12,13)、(6,8,10)、(8,15,17)、(7,24,25)。
  • 应用：求斜边、求直角边、判断直角三角形、实际问题（梯子、航海、折叠）。
⚠
应用勾股定理必须先确认哪条边是斜边。题目没说直角在哪时，要分类讨论（最长边为斜边）。
22. 平行四边形与特殊四边形
  • 平行四边形：两组对边分别平行（定义）。性质-对边相等、对角相等、对角线互相平分。
  • 判定：①两组对边分别平行；②两组对边分别相等；③一组对边平行且相等；④对角线互相平分；⑤两组对角分别相等。
  • 矩形：四个角都是直角，对角线相等。判定：有一个角是直角的平行四边形 / 对角线相等的平行四边形 / 三个角是直角的四边形。
  • 菱形：四条边相等，对角线互相垂直且每条对角线平分一组对角。面积 = 对角线乘积的一半。
  • 正方形：既是矩形又是菱形。
★
特殊四边形判定是八年级压轴题常客。记忆口诀：「矩形看角、菱形看边、正方形全都要」。

五、八下·一次函数与数据分析

代数核心
11. 一次函数
  • 解析式：y = kx + b（k ≠ 0）。当 b = 0 时是正比例函数。
  • 图象：一条直线。k > 0 时 y 随 x 增大而增大；k < 0 时 y 随 x 增大而减小。
  • 与坐标轴交点：与 y 轴交于 (0, b)；与 x 轴交于 (−b/k, 0)。
  • 待定系数法：设 y = kx + b，代入两点坐标，解方程组求 k、b。
  • 平移规律：上加下减（对 b），左加右减（对 x）。
💡
一次函数与方程、不等式的关系是中考热点：kx + b > 0 的解集就是直线在 x 轴上方部分对应的 x 范围。
22. 数据的分析
  • 平均数：算术平均数、加权平均数（权越大影响越大）。
  • 中位数：排序后中间的数（偶数个取中间两数平均）。
  • 众数：出现次数最多的数，可能不止一个。
  • 方差：s² = [(x₁−x̄)² + ... + (xₙ−x̄)²] ÷ n，方差越小数据越稳定。
  • 极差：最大值 − 最小值。
★
平均数、中位数、众数都描述集中趋势；方差描述离散程度（波动大小）。评价「谁的成绩更稳定」用方差。
