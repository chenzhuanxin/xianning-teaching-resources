静电场

选择性必修1 · 必考
1库仑定律与电场强度
  • 库仑定律：F = kQ₁Q₂/r²（k = 9.0×10⁹ N·m²/C²），适用于真空中的点电荷。
  • 电场强度：E = F/q，是矢量，方向与正电荷受力方向相同。E 由电场本身决定，与试探电荷无关。
  • 点电荷场强：E = kQ/r²。
  • 电场线：①起于正电荷（或无穷远）止于负电荷；②不闭合、不相交；③密处场强大；④切线方向为该点场强方向。
  • 匀强电场：电场线是等间距的平行直线。E = U/d。
🔑
E = F/q 是定义式（对任何电场都适用）；E = kQ/r² 是点电荷的场强公式（只适用于点电荷）。二者的适用条件是高考常见陷阱。
2电势能与电势
  • 电势能：电荷在电场中具有的势能。电场力做正功，电势能减小；做负功，电势能增大。
  • 电势：φ = Eₚ/q，是标量，有正负。沿电场线方向电势降低。
  • 电势差：U(AB) = φ(A) - φ(B) = W(AB)/q。
  • 等势面：①等势面与电场线处处垂直；②沿等势面移动电荷电场力不做功；③等势面密处场强大。
  • 判断电势高低的技巧：顺着电场线方向，电势一定降低。
💡
电势能的正负判断口诀：「正电荷顺着电场线移动，电势能减小」。与重力做功类比：电场力做正功就像重力做正功，势能减小。
3电容器与带电粒子在电场中的运动
  • 电容：C = Q/U，单位法拉（F）。由电容器本身决定，与 Q、U 无关。
  • 平行板电容器：C = εS/(4πkd)（ε 为介电常数，S 为正对面积，d 为板间距）。
  • 动态分析两类问题：①保持接电源（U 不变）；②断开电源（Q 不变）。
  • 带电粒子在匀强电场中的加速：qU = ½mv² - ½mv₀²（动能定理）。
  • 带电粒子在匀强电场中的偏转（初速度垂直于电场）：类平抛运动。a = qE/m = qU/(md)；侧移 y = ½at² = qUL²/(2mdv₀²)。
⚠️
电容器动态分析的「谁不变」是解题关键：接电源则 U 不变，断电源则 Q 不变。判断错这一点，整道题就全错了。

恒定电流

选择性必修1 · 必考
1电流、电阻与欧姆定律
  • 电流：I = q/t = nqSv（微观表达式），单位安培（A）。
  • 电阻定律：R = ρL/S（ρ 为电阻率，L 为长度，S 为横截面积）。
  • 欧姆定律：I = U/R，适用于纯电阻电路。
  • 电阻率：与材料种类和温度有关，与 L、S 无关。金属的电阻率随温度升高而增大。
  • 半导体：电阻率随温度升高而减小。超导现象：温度降到某一临界值时电阻突然变为零。
🔑
注意区分：R = U/I 是定义式（电阻由本身决定，不由 U、I 决定）；R = ρL/S 是决定式。这是最基础的易错点。
2闭合电路欧姆定律
  • 闭合电路欧姆定律：I = E/(R+r)，或 E = U外 + U内 = IR + Ir。
  • 路端电压：U = E - Ir。R 增大，I 减小，U 增大；R 减小，I 增大，U 减小。
  • 电源的效率：η = UI/(EI) = U/E = R/(R+r)。
  • 电源输出功率最大条件：R = r 时输出功率最大，Pmax = E²/(4r)。
  • 电功与电热：纯电阻电路 W = Q；非纯电阻电路 W > Q（W = UIt，Q = I²Rt）。
💡
非纯电阻电路（如电动机、电解槽）用能量守恒分析：UIt = I²Rt + E其他。输入的电动能一部分转化为热，一部分转化为机械能或化学能。
3

磁场

选择性必修2 · 必考
1磁场与安培力
  • 磁感应强度：B = F/(IL)（L 垂直于 B 时），是矢量，单位特斯拉（T）。
  • 安培力：F = BIL（要求 L 与 B 垂直）；当 L∥B 时 F = 0。
  • 安培力方向：由左手定则判定（伸开左手，让磁感线穿入手心，四指指向电流方向，大拇指指向安培力方向）。
  • 磁通量：Φ = BS（S 为垂直于 B 的有效面积）。
  • 常见磁场：①条形磁铁（外部由 N 到 S）；②直线电流（安培定则：右手握导线，拇指指向电流，四指弯曲方向为磁场方向）；③环形电流与通电螺线管。
⚠️
左手定则判力，右手定则判电（感应电流），安培定则（右手螺旋）判磁场。三个定则容易混淆，建议用「左力右电」四个字牢固记忆。
2洛伦兹力与带电粒子在磁场中的运动
  • 洛伦兹力：f = qvB（v 垂直于 B 时），方向由左手定则判定（注意：负电荷四指指向与运动方向相反）。
  • 洛伦兹力的特点：①方向始终与速度垂直；②不做功，不改变速度大小，只改变速度方向。
  • 带电粒子在匀强磁场中的圆周运动：qvB = mv²/r ⇒ r = mv/(qB)；T = 2πm/(qB)。
  • 重要结论：周期 T 与速度 v 无关（同种粒子在同一磁场中周期相同）。
  • 质谱仪：用于测定带电粒子的质量和分析同位素。
  • 回旋加速器：利用电场加速、磁场偏转，最大动能由磁感应强度和 D 形盒半径决定。
🔑
带电粒子在磁场中运动的解题三步：①定圆心（由速度垂直半径确定）；②求半径（用几何关系或 r = mv/qB）；③算时间（用圆心角和周期）。几何关系是难点。
3电磁感应
  • 法拉第电磁感应定律：E = nΔΦ/Δt（n 为线圈匝数）。
  • 导体棒切割磁感线：E = BLv（B、L、v 两两垂直）。
  • 楞次定律：感应电流的磁场总要阻碍引起感应电流的磁通量的变化。口诀：「增反减同」。
  • 右手定则：判定导体切割磁感线产生的感应电流方向（伸开右手，让磁感线穿入手心，拇指指向导体运动方向，四指指向感应电流方向）。
  • 自感现象：通电自感（灯泡逐渐变亮）、断电自感（灯泡闪亮后熄灭）。
  • 涡流：块状金属在变化磁场中产生的感应电流。应用：电磁炉、金属探测器；防止：变压器铁芯用硅钢片叠压。
💡
楞次定律的本质是能量守恒——感应电流的磁场阻碍磁通量变化，实质是阻碍相对运动，这个过程必然要克服安培力做功，把机械能转化为电能。

交变电流与电磁波

选择性必修2
1交变电流
  • 正弦式交变电流的产生：线圈在匀强磁场中绕垂直于磁场的轴匀速转动。
  • 瞬时值：e = E₀sinωt；峰值：E₀ = nBAω。
  • 有效值：正弦式交流电的有效值 = 峰值/√2，即 U = U₀/√2。有效值是根据电流热效应定义的。
  • 理想变压器：U₁/U₂ = n₁/n₂；I₁/I₂ = n₂/n₁（只有一个副线圈时）；P₁ = P₂。
  • 变压器规律：电压由匝数比决定，电流由电压和功率决定，功率不变。
🔑
交流电「四值」的用途：①瞬时值——求某一时刻的值；②峰值——判断电容器是否击穿；③有效值——求电功、电热、电表读数；④平均值——求通过导线的电荷量。用途混淆是常见失分点。
2电磁振荡与电磁波
  • LC 振荡电路：电容器放电时电场能转化为磁场能；充电时磁场能转化为电场能。
  • 电磁波：变化的电场产生磁场，变化的磁场产生电场，交替产生形成电磁波。
  • 麦克斯韦预言电磁波的存在，赫兹用实验证实。
  • 电磁波的特点：①可在真空中传播；②是横波；③传播速度等于光速 c = 3×10⁸ m/s（真空中）。
  • 电磁波谱（波长由长到短）：无线电波、红外线、可见光、紫外线、X射线、γ射线。
