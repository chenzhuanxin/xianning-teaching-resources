内能与热机

九年级起始
01分子热运动与内能
  • 分子动理论：物质由分子组成；分子永不停息做无规则运动；分子间同时存在引力和斥力。
  • 扩散现象说明分子在运动，温度越高扩散越快。
  • 内能：物体内所有分子动能与势能的总和，任何物体在任何温度下都有内能。
  • 改变内能两种方式：做功和热传递，二者在改变内能上等效。
  • 热量 Q：热传递过程中传递能量的多少，单位焦耳（J）。
02比热容与热量计算
  • 比热容 c：单位质量物质温度升高 1℃ 吸收的热量，是物质的一种特性。
  • 水的比热容 c=4.2×10³ J/(kg·℃)，较大，故水常作冷却剂、暖气介质。
  • 吸热公式：Q吸 = cm(t−t₀)；放热公式：Q放 = cm(t₀−t)。
  • 热平衡方程：Q吸 = Q放（不计热损失）。
⚠
计算温度变化一定要用 Δt = t−t₀（高温减低温），不要把「升高了」与「升高到」混用。
03热机与热机效率
  • 四冲程汽油机：吸气 → 压缩 → 做功 → 排气；只有做功冲程对外做功，靠飞轮惯性完成其余三冲程。
  • 压缩冲程把机械能转化为内能；做功冲程把内能转化为机械能。
  • 燃料完全燃烧放热：Q放 = mq（q 为热值）。
  • 热机效率 η = W有用 / Q放 × 100%，永远小于 100%。
  • 能量守恒定律：能量既不会凭空产生，也不会凭空消失，只会从一种形式转化为另一种形式，或从一个物体转移到另一个物体，总量保持不变。
💡
能量转化类题目先问「谁对谁做功」，再判断是机械能→内能还是内能→机械能。

电流和电路

电学基石
04电荷与电路
  • 两种电荷：正电荷（丝绸摩擦玻璃棒）、负电荷（毛皮摩擦橡胶棒）；同种相斥，异种相吸。
  • 电流方向规定为正电荷定向移动的方向；金属中电流方向与自由电子移动方向相反。
  • 电路三种状态：通路、断路、短路。
  • 串联：电流处处相等 I=I₁=I₂，总电压等于各部分电压之和 U=U₁+U₂，总电阻 R=R₁+R₂。
  • 并联：干路电流等于各支路电流之和 I=I₁+I₂，各支路电压相等 U=U₁=U₂，1/R=1/R₁+1/R₂。
★
识别串联还是并联：拆掉一个元件，若另一个也不工作则是串联。这是电路题的第一步。
05电流表与电压表
  • 电流表：串联接入，量程 0—0.6A（分度 0.02A）、0—3A（分度 0.1A）；不允许直接接到电源两极。
  • 电压表：并联在被测元件两端，量程 0—3V（分度 0.1V）、0—15V（分度 0.5V）。
  • 「电流表相当于导线，电压表相当于断路」是分析电路的通法。
  • 使用前必须校零，接线柱「正进负出」。
4

欧姆定律与电阻

核心必考
06欧姆定律
  • I = U / R：导体中电流与电压成正比，与电阻成反比。
  • 变形：U = IR，R = U / I（R 由导体本身决定，与 U、I 无关）。
  • 同一性：I、U、R 必须对应同一段电路、同一时刻。
  • 伏安法测电阻：多次测量取平均值以减小误差。
07控制变量实验必考
  • 探究电流与电压关系：控制电阻不变，改变电压——结论「电阻一定时，电流与电压成正比」。
  • 探究电流与电阻关系：控制电压不变，更换定值电阻——结论「电压一定时，电流与电阻成反比」。
  • 滑动变阻器作用：①保护电路；②改变电路中的电流/调节被测电阻两端电压。
  • 连接电路时开关必须断开，滑动变阻器滑片置于阻值最大端。
⚠
「换接大电阻后，滑片应向阻值变大方向移动」——这是探究电流与电阻关系的经典考点，务必理解原理（分压增大）。
5

电功率与电热

重难点
08电功与电功率
  • 电功 W = UIt = Pt，单位焦耳（J）；1 kW·h = 3.6×10⁶ J。
  • 电功率 P = W/t = UI，单位瓦特（W）。
  • 纯电阻电路：P = UI = I²R = U²/R；W = Pt = I²Rt = U²t/R。
  • 额定功率：用电器在额定电压下的功率；实际电压不同，实际功率不同。
★
「220V 100W」的灯泡，实际电压只有 110V 时实际功率是 25W（P 与 U² 成正比），不是 50W——高频陷阱！
09焦耳定律
  • Q = I²Rt（普适）；纯电阻电路 Q = W = UIt = U²t/R。
  • 串联电路电流相同，电阻大的发热多；并联电路电压相同，电阻小的发热多。
  • 家庭电路中电流过大的原因：①短路；②用电器总功率过大。
  • 熔断器/空气开关：电流过大时自动切断电路；保险丝由电阻大、熔点低的铅锑合金制成。
10家庭电路与安全用电
  • 组成：进户线（火线与零线）→ 电能表 → 总开关 → 保险装置 → 用电器与开关（开关接火线）→ 三孔插座。
  • 用测电笔辨别火线：手接触笔尾金属体，氖管发光的是火线。
  • 三孔插座：左零右火上接地；三脚插头上面的脚接用电器金属外壳。
  • 触电事故：单线触电（人站地上碰火线）、双线触电（同时接触火线与零线）。
  • 安全原则：不接触低压带电体，不靠近高压带电体。
⚠
人触电是因为有电流通过人体；电压高不一定危险，高压不接触也可能因电弧触电。
6

磁与电磁

联系实际
11电生磁与磁生电
  • 奥斯特实验：通电导线周围存在磁场，磁场方向与电流方向有关。
  • 通电螺线管外部磁场类似条形磁体；安培定则：右手握螺线管，四指指电流方向，大拇指指 N 极。
  • 电磁铁磁性强弱：与电流大小和线圈匝数有关。
  • 电磁感应：闭合电路的一部分导体在磁场中做切割磁感线运动时产生感应电流（法拉第），发电机原理。
  • 通电导体在磁场中受力运动（电动机原理），受力方向与电流方向和磁场方向有关。
💡
口诀：「电生磁是奥斯特，磁生电是法拉第；电动机是电到动，发电机是动到电。」

信息、能源与材料

易得分
12电磁波与现代通信
  • 电磁波在真空中传播速度 c=3×10⁸ m/s；波速=波长×频率（c=λf）。
  • 移动电话既发射又接收电磁波；光纤通信利用激光在光纤中全反射传输。
  • 能源分类：可再生能源（太阳能、水能、风能、生物质能）与不可再生能源（煤、石油、天然气、核能）。
  • 核能：核裂变（原子弹、核电站）与核聚变（氢弹、太阳内部）。
13能源与可持续发展
  • 能量转化和转移具有方向性，故能量虽然守恒但仍需节约能源。
  • 新能源：太阳能、风能、地热能、潮汐能、氢能。
  • 材料：导体、绝缘体、半导体（硅、锗，用于二极管、集成电路）、超导体（零电阻，用于输电）。

力学综合复习（中考重点）

跨年复习
14压强与浮力
  • 固体压强 p = F/S；液体压强 p = ρgh。
  • 大气压：标准大气压约 1.013×10⁵ Pa；海拔越高气压越低，沸点越低。
  • 流体压强：流速大的地方压强小（机翼升力、两船并行危险）。
  • 阿基米德原理：F浮 = ρ液 g V排。
  • 浮沉条件：F浮＞G 上浮；F浮=G 悬浮/漂浮；F浮＜G 下沉。
15功、功率与机械效率
  • 功 W = Fs（力与在力方向上移动的距离）；W = Gh 为重力做功。
  • 功率 P = W/t = Fv。
  • 杠杆平衡条件：F₁L₁ = F₂L₂；省力杠杆（L₁＞L₂）、费力杠杆、等臂杠杆。
  • 滑轮组：n 段绳子承担物重，F = G总/n（不计摩擦），s = nh。
  • 机械效率 η = W有用/W总 × 100%；η 永远小于 1。
16实验探究高频题
  • 测物质密度：ρ = m/V，天平测质量、量筒测体积（注意「先测质量后测体积」或「溢出法」）。
  • 测滑轮组机械效率：弹簧测力计竖直匀速拉动。
  • 探究影响滑动摩擦力因素：弹簧测力计水平匀速拉动木块（二力平衡）。
  • 测小灯泡电功率：电路连接、滑动变阻器调节、额定电压下的读数。
  • 伏安法测电阻：多次测量求平均值。
⚠
实验题答题必须写清「控制了什么变量」「观察什么现象」「得出什么结论」三要素。
