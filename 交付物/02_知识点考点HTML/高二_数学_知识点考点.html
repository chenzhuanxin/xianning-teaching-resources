空间向量与立体几何

选择性必修1 · 必考
1空间向量及其运算
  • 空间向量基本定理：如果三个向量 a、b、c 不共面，那么对空间任一向量 p，存在唯一的有序实数组 (x,y,z)，使 p = xa + yb + zc。
  • 坐标运算：a·b = x₁x₂ + y₁y₂ + z₁z₂；|a| = √(x²+y²+z²)。
  • 共线与垂直：a∥b ⇔ a = λb；a⊥b ⇔ a·b = 0。
  • 夹角公式：cos⟨a,b⟩ = (a·b)/(|a||b|)。
🔑
空间向量的价值在于把几何证明转化为代数计算。传统方法需要「作、证、算」三步，向量法只需建系、写坐标、算结果，大幅降低思维难度。
2空间角与距离的向量求法
  • 异面直线所成角：cosθ = |cos⟨a,b⟩|（a、b 为两直线的方向向量），范围 (0°, 90°]。
  • 直线与平面所成角：sinθ = |cos⟨a,n⟩|（a 为直线方向向量，n 为平面法向量），范围 [0°, 90°]。
  • 二面角：cosθ = ±cos⟨n₁,n₂⟩（n₁、n₂ 为两平面法向量）。需结合图形判断二面角是锐角还是钝角。
  • 点到平面距离：d = |AP·n| / |n|（A 为平面内一点，P 为平面外一点，n 为平面法向量）。
  • 线面平行判定：a·n = 0（方向向量与法向量垂直）。面面平行：n₁∥n₂。
⚠️
最容易错的是线面角用 sin 而非 cos——因为线面角与方向向量和法向量的夹角是互余关系。这一步错了整道题就废了，务必牢记。

直线与圆

选择性必修1 · 必考
1直线方程与位置关系
  • 直线方程五种形式：点斜式 y-y₀=k(x-x₀)、斜截式 y=kx+b、两点式、截距式、一般式 Ax+By+C=0。
  • 斜率公式：k = (y₂-y₁)/(x₂-x₁) = tanα（α 为倾斜角，范围 [0,π)）。
  • 平行条件：A₁B₂ - A₂B₁ = 0 且不重合。垂直条件：A₁A₂ + B₁B₂ = 0。
  • 点到直线距离：d = |Ax₀+By₀+C| / √(A²+B²)。
  • 两平行线间距离：d = |C₁-C₂| / √(A²+B²)（需先化成相同系数）。
2圆的方程与位置关系
  • 圆的标准方程：(x-a)² + (y-b)² = r²，圆心 (a,b)，半径 r。
  • 圆的一般方程：x² + y² + Dx + Ey + F = 0（D²+E²-4F > 0）。
  • 直线与圆的位置关系：d > r 相离（0 个交点）；d = r 相切（1 个交点）；d < r 相交（2 个交点）。
  • 切线方程：过圆上一点 (x₀,y₀) 的切线，可用「圆心与切点连线垂直于切线」求解。
  • 弦长公式：l = 2√(r² - d²)（d 为圆心到直线的距离）。
  • 圆与圆的位置关系：外离、外切、相交、内切、内含，由圆心距与半径和差比较判断。
💡
直线与圆的综合题，「几何法」往往比「代数法」快得多。优先考虑用圆心到直线的距离 d 与半径 r 的关系，避免联立方程的繁琐计算。

圆锥曲线

选择性必修1 · 高频
1椭圆
  • 定义：|PF₁| + |PF₂| = 2a（2a > |F₁F₂| = 2c）。
  • 标准方程：x²/a² + y²/b² = 1（焦点在 x 轴）；y²/a² + x²/b² = 1（焦点在 y 轴）。
  • 关系式：a² = b² + c²（a 最大）。
  • 离心率：e = c/a ∈ (0,1)。e 越大，椭圆越扁；e 越小，越接近圆。
  • 焦点三角形：|PF₁|·|PF₂| 的最大值为 a²（当 P 在短轴端点时）。
🔑
圆锥曲线三大定义的记忆要点：椭圆「和为定值」，双曲线「差为定值」，抛物线「等于到准线距离」。抓住定义就能解决大部分基础题。
2双曲线
  • 定义：||PF₁| - |PF₂|| = 2a（0 < 2a < 2c）。
  • 标准方程：x²/a² - y²/b² = 1；y²/a² - x²/b² = 1。
  • 关系式：c² = a² + b²（c 最大，与椭圆不同！）。
  • 离心率：e = c/a > 1。
  • 渐近线：x²/a² - y²/b² = 1 的渐近线为 y = ±(b/a)x。
  • 等轴双曲线：a = b，渐近线为 y = ±x，离心率 e = √2。
⚠️
椭圆与双曲线的 a、b、c 关系恰好相反：椭圆 a²=b²+c²（a 最大）；双曲线 c²=a²+b²（c 最大）。这是最容易混淆的地方，务必区分记忆。
3抛物线
  • 定义：|PF| = d（d 为 P 到准线的距离）。
  • 标准方程四种形式：y² = 2px（开口向右）、y² = -2px（向左）、x² = 2py（向上）、x² = -2py（向下）。
  • 焦点与准线（以 y²=2px 为例）：焦点 (p/2, 0)，准线 x = -p/2。
  • 焦半径（以 y²=2px 为例）：|PF| = x₀ + p/2。
  • 通径：过焦点且垂直于对称轴的弦，长度为 2p（抛物线所有焦点弦中最短的）。
  • 抛物线中「焦点弦」是高频考点，常用性质：以焦点弦为直径的圆与准线相切。

数列

选择性必修2 · 高频
1等差数列
  • 定义：aₙ₊₁ - aₙ = d（常数）。
  • 通项公式：aₙ = a₁ + (n-1)d。
  • 前 n 项和：Sₙ = n(a₁+aₙ)/2 = na₁ + n(n-1)d/2。
  • 中项性质：2aₙ = aₙ₋₁ + aₙ₊₁。
  • 重要结论：Sₙ, S₂ₙ-Sₙ, S₃ₙ-S₂ₙ 仍成等差数列。
  • 判断方法：定义法、中项法、通项公式法（aₙ = pn+q）、前n项和法（Sₙ = An²+Bn）。
🔑
等差数列的「下标和相等则项和相等」：若 m+n = p+q，则 aₘ+aₙ = aₚ+a_q。这个性质能极大简化计算，是解题利器。
2等比数列
  • 定义：aₙ₊₁/aₙ = q（q≠0 的常数）。
  • 通项公式：aₙ = a₁q^(n-1)。
  • 前 n 项和：q≠1 时 Sₙ = a₁(1-qⁿ)/(1-q)；q=1 时 Sₙ = na₁。
  • 中项性质：aₙ² = aₙ₋₁·aₙ₊₁。
  • 重要结论：Sₙ, S₂ₙ-Sₙ, S₃ₙ-S₂ₙ 仍成等比数列（q≠-1）。
  • 注意：等比数列求和必须讨论 q=1 与 q≠1两种情况。
⚠️
等比数列求和的分类讨论是必考点，也是最常见的失分点。只要题目未明确 q≠1，就必须分两种情况讨论，否则答案不完整。
3数列求和方法与递推
  • 公式法：直接用等差、等比求和公式。
  • 错位相减法：适用于「等差×等比」型通项，如 aₙ = n·2ⁿ。
  • 裂项相消法：适用于1/[n(n+1)] 型，注意「裂项后剩余项」的规律。
  • 分组求和法：适用于通项可拆分为几部分分别求和的情况。
  • 倒序相加法：适用于满足 f(x) + f(1/x) = 常数型。
  • 常见递推：aₙ₊₁ = aₙ + f(n)（累加法）；aₙ₊₁ = aₙ·f(n)（累乘法）；aₙ₊₁ = paₙ + q（构造等比数列）。
💡
识别求和方法的关键是看通项的结构：看到「n 乘以指数」→ 错位相减；看到「分母是乘积」→ 裂项相消。通项决定方法。

导数及其应用

选择性必修2 · 压轴
1导数概念与运算
  • 导数定义：f'(x₀) = lim(Δx→0) [f(x₀+Δx) - f(x₀)]/Δx。
  • 几何意义：f'(x₀) 是曲线 y=f(x) 在点 (x₀, f(x₀)) 处切线的斜率。
  • 基本求导公式：(xⁿ)' = nxⁿ⁻¹；(sinx)' = cosx；(cosx)' = -sinx；(eˣ)' = eˣ；(aˣ)' = aˣlna；(lnx)' = 1/x；(logₐx)' = 1/(xlna)。
  • 运算法则：(u±v)' = u'±v'；(uv)' = u'v + uv'；(u/v)' = (u'v - uv')/v²；[f(g(x))]' = f'(g(x))·g'(x)。
🔑
导数的三大应用：①求切线方程；②判断单调性；③求极值与最值。这三类问题占据高考导数题 90% 以上的分值，务必熟练掌握。
2导数与函数单调性、极值
  • 单调性判定：f'(x) > 0 ⇒ 递增；f'(x) < 0 ⇒ 递减。
  • 极值判定：f'(x₀) = 0 且 f'(x) 在 x₀ 两侧变号，则 x₀ 为极值点。
  • 注意：f'(x₀) = 0 是极值点的必要不充分条件（如 y=x³ 在 x=0 处导数为 0 但非极值点）。
  • 求极值步骤：求导 → 令 f'(x)=0 求根 → 列表判断符号变化 → 确定极大（小）值。
  • 含参单调性讨论：按参数分类讨论（开口方向、判别式、根的大小关系）。
⚠️
「f'(x₀)=0」不等于「x₀ 是极值点」。必须验证导数在该点两侧是否变号。这个陷阱每年都有考生掉进去。
3导数与不等式、零点问题
  • 证明不等式 f(x) ≥ g(x)：构造 h(x) = f(x) - g(x)，证明 h(x) 的最小值 ≥ 0。
  • 恒成立问题：f(x) ≥ a 恒成立 ⇔ f(x)_min ≥ a；f(x) ≥ a 有解 ⇔ f(x)_max ≥ a。
  • 零点个数问题：转化为函数图像与 x 轴交点个数，或两函数图像交点个数。
  • 分离参数法：把参数分离到一侧，转化为求另一侧函数的最值。
  • 洛必达（超纲但实用）：处理 0/0 或 ∞/∞ 型极限，可快速求出，但正式答题须用高中方法书写。
💡
导数压轴题的三大类型：①讨论单调性（基础）；②证明不等式（中档）；③零点或参数范围（压轴）。核心思想都是「构造辅助函数」，把问题转化为求最值。

计数原理与概率统计

选择性必修3 · 必考
1排列组合与二项式定理
  • 两个基本原理：分类加法计数原理；分步乘法计数原理。
  • 排列数：A(n,m) = n!/(n-m)!；组合数：C(n,m) = n!/[m!(n-m)!]。
  • 组合数性质：C(n,m) = C(n,n-m)；C(n,m) = C(n-1,m-1) + C(n-1,m)。
  • 二项式定理：(a+b)ⁿ = ΣC(n,k)a^(n-k)b^k。
  • 通项公式：T(k+1) = C(n,k)a^(n-k)b^k（第 k+1 项）。
  • 常用技巧：特殊元素优先、相邻问题捆绑、不相邻问题插空、定序问题除法。
🔑
排列组合的四种典型模型：①相邻捆绑（把相邻元素看作一个整体）；②不相邻插空（先排其他再插空）；③定序（除以定序元素的排列数）；④分组分配（注意是否均匀分组）。
2随机变量及其分布
  • 离散型随机变量：取值可一一列举。分布列必须满足①Pᵢ ≥ 0；②ΣPᵢ = 1。
  • 期望：E(X) = Σxᵢpᵢ，反映随机变量的平均水平。
  • 方差：D(X) = Σ(xᵢ-E(X))²pᵢ = E(X²) - [E(X)]²，反映离散程度。
  • 二项分布 X~B(n,p)：P(X=k) = C(n,k)p^k(1-p)^(n-k)；E(X) = np；D(X) = np(1-p)。
  • 超几何分布：从 N 件产品（含 M 件次品）中取 n 件，次品数 X 服从超几何分布。
  • 正态分布 X~N(μ,σ²)：曲线关于 x=μ 对称；P(μ-σ<X≤μ+σ) ≈ 0.6827；P(μ-2σ<X≤μ+2σ) ≈ 0.9545。
💡
区分二项分布与超几何分布：二项分布是「有放回」抽样（每次概率相同）；超几何分布是「无放回」抽样（概率随抽取改变）。题目里的「放回」「不放回」是关键提示词。
