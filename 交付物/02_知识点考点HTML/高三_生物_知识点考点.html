1

分子与细胞

高考必考 · 约20分
1细胞的分子组成与结构
  • 水：①自由水（溶剂、运输、参与反应）；②结合水（结构组成）。自由水/结合水比值越大，代谢越旺盛。
  • 无机盐：①构成化合物（如 Fe 构成血红蛋白、Mg 构成叶绿素、P 构成 ATP 和膜）；②维持渗透压与酸碱平衡。
  • 糖类/脂质/蛋白质/核酸：①蛋白质基本单位氨基酸（约20种），由肽键连接；②核酸基本单位核苷酸（8种），DNA 含脱氧核糖、RNA 含核糖。
  • 细胞器：①线粒体（有氧呼吸主要场所，「动力车间」）；②叶绿体（光合作用场所）；③核糖体（蛋白质合成）；④内质网（加工运输）；⑤高尔基体（加工分类包装）；⑥溶酶体（「消化车间」）；⑦中心体（动物细胞有丝分裂）；⑧液泡（植物细胞）。
  • 生物膜系统：由细胞膜、核膜、细胞器膜构成，流动镶嵌模型。
🔑
「含 DNA 的结构」：细胞核、线粒体、叶绿体（植物）；「含 RNA 的结构」：细胞核、线粒体、叶绿体、核糖体。特别注意：核糖体含 rRNA，不含 DNA，这是最常见的丢分点。
2细胞代谢
  • 酶：①高效性；②专一性；③作用条件温和（最适温度、pH）。本质——绝大多数是蛋白质，少数是 RNA。
  • ATP：结构简式 A-P~P~P；远离腺苷的高能磷酸键易断裂供能；ATP ⇌ ADP + Pi + 能量。
  • 有氧呼吸三阶段：①细胞质基质——葡萄糖→丙酮酸 + [H] + 少量能量；②线粒体基质——丙酮酸 + H₂O → CO₂ + [H] + 少量能量；③线粒体内膜——[H] + O₂ → H₂O + 大量能量。
  • 无氧呼吸：①产酒精（酵母菌、植物）；②产乳酸（动物、乳酸菌、马铃薯块茎）。
  • 光合作用：①光反应（类囊体薄膜）——水的光解产生 [H] 和 O₂，ATP 生成；②暗反应（叶绿体基质）——CO₂ 固定（C₅ + CO₂ → 2C₃）与 C₃ 还原。
⚠️
光合作用与呼吸作用的「三个量」关系必背：①总光合量（真光合）= 净光合 + 呼吸消耗；②O₂ 产生量 = 总光合，O₂ 释放量 = 净光合；③CO₂ 固定量 = 总光合，CO₂ 吸收量 = 净光合。题目问的是哪个量，务必看清。
3细胞的生命历程
  • 有丝分裂：①间期（DNA 复制、蛋白质合成）；②前期（膜仁消失现两体）；③中期（染色体着丝点排列在赤道板，是观察染色体的最佳时期）；④后期（着丝点分裂，染色体数目暂时加倍）；⑤末期（膜仁重现显两体）。
  • 细胞分化：基因的选择性表达，细胞形态结构功能发生稳定性差异。
  • 细胞衰老：①水分减少，体积变小；②酶活性降低；③色素积累；④膜通透性改变。
  • 细胞凋亡：基因控制的程序性死亡（如蝌蚪尾巴消失），对生物体有利。
  • 细胞癌变：①原癌基因激活、抑癌基因失活；②特征——无限增殖、形态结构改变、膜表面糖蛋白减少（易扩散转移）。
💡
「细胞凋亡」与「细胞坏死」必须区分：凋亡是基因控制的程序性死亡（主动、有利）；坏死是外界因素导致的病理性死亡（被动、有害）。这是高频易错点，题目常拿「细胞坏死」设错。

遗传与进化

高考必考 · 约25分
1遗传的基本规律
  • 孟德尔实验方法：假说—演绎法（观察 → 提出问题 → 作出假说 → 演绎推理 → 实验验证）。
  • 分离定律：F₁ 自交后代表现型比 3:1；测交比 1:1。
  • 自由组合定律：F₁ 自交 9:3:3:1；测交 1:1:1:1（适用于非同源染色体上的非等位基因）。
  • 判断显隐性的方法：①「有中生无」为显性（父母有病、子女有正常）；②「无中生有」为隐性。
  • 概率计算：①先求配子概率，再组合；②「患病概率 = 1 − 正常概率」；③「至少一个患病 = 1 − 全部正常」。
  • 伴性遗传：①伴 X 隐性（红绿色盲、血友病）——男性患者多于女性，具有隔代交叉遗传；②伴 X 显性——女性患者多于男性；③伴 Y——只有男性。
🔑
「无中生有为隐性，有中生无为显性」是判断遗传方式的第一把钥匙。进一步：「隐性遗传看女病，女病父子必有病 → 常染色体隐性」；「显性遗传看男病，男病母女必有病 → 常染色体显性」。
2基因的本质与表达
  • DNA 结构：①双螺旋结构；②碱基互补配对（A—T、G—C）；③A+G = T+C。
  • DNA 复制：①半保留复制；②边解旋边复制；③需要模板、原料、能量、酶。
  • 转录：以 DNA 一条链为模板合成 mRNA（主要场所——细胞核）。
  • 翻译：①场所——核糖体；②模板——mRNA；③运载工具——tRNA；④密码子（64个，3个终止密码子不编码氨基酸）。
  • 中心法则：DNA → RNA → 蛋白质（复制、转录、翻译）。
  • 基因对性状的控制：①直接控制（基因通过控制蛋白质结构控制性状——如镰刀型细胞贫血症）；②间接控制（通过控制酶的合成控制代谢过程）。
  • 碱基与氨基酸数量关系：DNA 碱基数 : mRNA 碱基数 : 氨基酸数 = 6 : 3 : 1。
💡
计算题必背比例：DNA 碱基数 : mRNA 碱基数 : 氨基酸数 = 6 : 3 : 1。但要注意：实际氨基酸数要算上终止密码子不编码、以及 mRNA 上的非编码区，题目若给了明确序列则严格按序列数。
3变异、育种与进化
  • 基因突变：①DNA 碱基对的替换、增添或缺失；②产生新基因（等位基因）；③是生物变异的根本来源。
  • 基因重组：①减数第一次分裂前期（交叉互换）；②减数第一次分裂后期（非同源染色体自由组合）。
  • 染色体变异：①结构变异（缺失、重复、倒位、易位）；②数目变异（个别增减——三体；成倍增减——多倍体）。
  • 育种方法：①杂交育种（操作简单，年限长）；②诱变育种（提高突变率，有利变异少）；③单倍体育种（明显缩短年限）；④多倍体育种（器官大、营养物质含量高）；⑤基因工程育种（定向改造）。
  • 现代生物进化理论：①种群是生物进化的基本单位；②突变和基因重组产生进化的原材料；③自然选择决定进化的方向；④隔离是物种形成的必要条件。
  • 基因频率计算：p² + 2pq + q² = 1（哈迪—温伯格定律，适用理想条件）。
⚠️
「物种形成」的标志是生殖隔离，不是地理隔离。地理隔离可能导致生殖隔离，但两者不等同（如东北虎与华南虎有地理隔离但无生殖隔离，仍属同一物种）。这是选择题经典陷阱。

稳态与调节、生物与环境、生物技术

高考必考 · 约30分
1生命活动的调节
  • 内环境：由血浆、组织液、淋巴构成。理化性质（温度、pH、渗透压）保持相对稳定。
  • 血糖调节：①胰岛 B 细胞分泌胰岛素（降血糖）；②胰岛 A 细胞分泌胰高血糖素（升血糖）；③拮抗关系。
  • 体温调节：①寒冷——产热增加（骨骼肌战栗、甲状腺激素分泌增多）、散热减少（皮肤血管收缩）；②炎热——散热增加。
  • 水盐调节：①渗透压升高 → 抗利尿激素分泌增多 → 肾小管集合管重吸收水增多 → 尿量减少。
  • 神经调节：①反射弧（感受器—传入神经—神经中枢—传出神经—效应器）；②兴奋在神经纤维上以电信号（动作电位）传导（双向）；③突触处单向传递（神经递质只能由突触前膜释放，作用于突触后膜）。
  • 免疫调节：①非特异性免疫（皮肤黏膜、吞噬细胞）；②特异性免疫（体液免疫——B 细胞产生抗体；细胞免疫——T 细胞）。
🔑
「神经递质作用于突触后膜引起兴奋或抑制」——所以突触传递是单向的，且同一递质在不同部位可能产生相反效果。这是神经调节部分最常考的结论，也是判断传递方向的唯一依据。
2生物与环境、生态系统
  • 种群特征：①种群密度（最基本）；②出生率死亡率；③迁入率迁出率；④年龄组成（预测种群数量变化趋势）；⑤性别比例。
  • 种群数量增长：①「J」型增长——无环境阻力，Nt = N₀λ^t；②「S」型增长——有环境容纳量 K 值，K/2 时增长速率最大。
  • 群落：①丰富度；②空间结构（垂直分层、水平镶嵌）；③演替（初生演替、次生演替）。
  • 生态系统组成：①非生物物质和能量；②生产者（自养生物）；③消费者；④分解者。
  • 能量流动：①单向流动、逐级递减；②传递效率 10%~20%。
  • 物质循环：①碳循环（CO₂ 形式在生物群落与无机环境间循环）；②具有全球性。
  • 信息传递：①物理信息、化学信息、行为信息；②作用是调节种间关系，维持生态系统稳定。
💡
能量传递效率计算必背：10%~20%。求「至少消耗」用 20%，求「最多消耗」用 10%，方向不要搞反。另外「K/2 时种群增长速率最大」是捕捞（获取最大持续产量）的理论依据。
3生物技术实践与工程
  • 微生物培养：①培养基（选择培养基、鉴别培养基）；②无菌技术（消毒、灭菌）；③纯化方法（平板划线法、稀释涂布平板法）。
  • 发酵工程：①果酒（酵母菌，18~25℃）；②果醋（醋酸菌，30~35℃需氧）；③泡菜（乳酸菌，无氧）；④腐乳（毛霉）。
  • 基因工程：①工具——限制酶（「分子手术刀」）、DNA 连接酶（「分子缝合针」）、运载体（质粒、噬菌体）；②四步——提取目的基因 → 构建基因表达载体 → 导入受体细胞 → 目的基因的检测与鉴定。
  • 细胞工程：①植物组织培养（植物细胞全能性）；②植物体细胞杂交；③动物细胞培养；④动物细胞融合与单克隆抗体。
  • 胚胎工程：①体外受精；②胚胎移植（「借腹怀胎」）；③胚胎分割。
⚠️
基因工程的「四步流程」顺序不能颠倒，尤其「构建基因表达载体」必须在「导入受体细胞」之前。表达载体的组成：目的基因 + 启动子 + 终止子 + 标记基因，四者缺一不可，这是填空题的标准答案。
