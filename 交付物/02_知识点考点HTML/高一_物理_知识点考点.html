1

运动的描述

基础 · 必考
1质点、参考系与位移
  • 质点：用来代替物体的有质量的点，是一种理想化模型。当物体的大小和形状对所研究的问题影响可忽略时，可视为质点。
  • 参考系：描述物体运动时选作参考的物体。选择不同参考系，对同一运动的描述可能不同。
  • 位移：从初位置指向末位置的有向线段，是矢量；路程是运动轨迹的长度，是标量。
  • 位移大小 ≤ 路程（只有单向直线运动时二者相等）。
💡
判断能否视为质点，关键看研究的问题，而不是物体的绝对大小。研究地球公转时地球可视为质点，研究地球自转时则不能。
2速度与加速度
  • 平均速度：v̄ = 位移/时间，是矢量，方向与位移方向相同。
  • 瞬时速度：某一时刻（或某一位置）的速度，是矢量，方向为该点运动方向。
  • 加速度：a = Δv/Δt，描述速度变化快慢的物理量，是矢量。
  • 加速度方向与速度方向相同→加速；相反→减速。
  • 加速度大小与速度大小无必然联系：速度大加速度可以为零，速度为零加速度可以很大。
⚠️
最易错的判断：「加速度减小，速度一定减小」是错的。只要加速度与速度同向，无论加速度变大变小，速度都在增大（只是增大得慢了）。

匀变速直线运动

重点 · 必考
1三个基本公式
  • 速度公式：v = v₀ + at。
  • 位移公式：x = v₀t + ½at²。
  • 速度位移关系：v² - v₀² = 2ax（不含时间的公式，非常实用）。
  • 平均速度公式：v̄ = (v₀+v)/2（仅适用于匀变速直线运动）。
  • 中间时刻速度：v(t/2) = v̄ = (v₀+v)/2。
2重要推论
  • 连续相等时间间隔内的位移差为恒量：Δx = aT²（逐差法求加速度的依据）。
  • 初速度为零的匀加速直线运动：①1T末、2T末、3T末速度之比为 1:2:3:…；②前1T、前2T、前3T内位移之比为 1:4:9:…；③第1个T、第2个T、第3个T内位移之比为 1:3:5:…。
  • 自由落体运动：v₀=0，a=g 的匀加速直线运动。h = ½gt²，v = gt，v² = 2gh。
🔑
「逐差法求加速度」是实验题必考：a = [(x₄+x₅+x₆)-(x₁+x₂+x₃)]/(9T²)。这个公式能有效减小偶然误差。
3

相互作用——力

重点 · 必考
1三种性质力
  • 重力：G = mg，方向竖直向下，作用点为重心。重心位置与物体形状和质量分布有关。
  • 弹力：发生弹性形变的物体由于要恢复原状而对接触物产生的力。方向垂直于接触面。
  • 胡克定律：F = kx（x 为形变量，不是弹簧总长）。
  • 摩擦力：静摩擦力（0 < f ≤ fmax，方向与相对运动趋势方向相反）；滑动摩擦力（f = μN，方向与相对运动方向相反）。
  • 摩擦力方向与相对运动（趋势）方向相反，不一定与运动方向相反。
⚠️
摩擦力可以是动力！例如放在加速传送带上的物体，摩擦力方向与运动方向相同，是使物体加速的动力。
2力的合成分解与共点力平衡
  • 力的合成：平行四边形定则。合力范围：|F₁-F₂| ≤ F ≤ F₁+F₂。
  • 三个力平衡的条件：任意两个力的合力与第三个力等大反向。
  • 正交分解法：建立坐标系，把所有力分解到两坐标轴上，列平衡方程 ΣFx=0，ΣFy=0。
  • 动态平衡问题常用方法：图解法、相似三角形法、解析法。

牛顿运动定律

核心 · 必考
1牛顿三大定律
  • 牛顿第一定律（惯性定律）：一切物体总保持匀速直线运动状态或静止状态，直到有外力迫使它改变这种状态为止。惯性是物体的固有属性，只与质量有关。
  • 牛顿第二定律：F合 = ma。a 的方向与合力方向相同。
  • 牛顿第三定律：作用力与反作用力大小相等、方向相反、作用在同一条直线上、作用在不同物体上。
  • 作用力与反作用力 vs 平衡力：前者作用在两个物体上（不能抵消），后者作用在同一物体上（可以抵消）。
🔑
牛顿第二定律的瞬时性：a 与 F合 同时产生、同时变化、同时消失。绳、接触面弹力可以突变，但弹簧、橡皮绳的弹力不能突变。这是高频考点。
2超重与失重
  • 超重：加速度方向向上（加速上升或减速下降），视重 > 实重，N = m(g+a)。
  • 失重：加速度方向向下（加速下降或减速上升），视重 < 实重，N = m(g-a)。
  • 完全失重：a = g 时 N = 0。此时一切与重力有关的现象都消失（如天平失效、水不流出）。
  • 关键：超重失重看加速度方向，不看速度方向，也不看是上升还是下降。
💡
记忆口诀：「上超下失」——加速度向上为超重，向下为失重。判断时只认加速度方向。
3连接体与临界问题
  • 连接体问题：整体法求加速度，隔离法求内力。
  • 「绳、杆」类连接体：绳的拉力沿绳，轻绳两端拉力相等。
  • 传送带问题：先判断物体与传送带的速度关系，确定摩擦力方向，再分析运动。
  • 临界问题：绳恰好拉直（T=0）、物体恰好不滑动（f=fmax）、物体恰好离开面（N=0）。
