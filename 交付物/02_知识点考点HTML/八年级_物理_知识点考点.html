一、走进物理世界与物态变化

八上
11. 科学探究与测量
  • 长度测量：基本工具是刻度尺。读数要估读到分度值的下一位。
  • 误差：测量值与真实值之间的差异，不能消除，只能减小（多次测量取平均值）。误差不是错误。
  • 机械运动：一个物体相对于另一个物体位置的变化。参照物：被选作标准的物体。
  • 速度：v = s/t。国际单位 m/s，常用 km/h。1 m/s = 3.6 km/h。
  • 平均速度：v = s总 / t总（不是速度的平均值）。
⚠
「误差」与「错误」是两回事：错误可以避免，误差不能消除。判断题高频陷阱。
22. 物态变化
  • 六种物态变化：熔化（固→液）、凝固（液→固）、汽化（液→气）、液化（气→液）、升华（固→气）、凝华（气→固）。
  • 吸热/放热：熔化、汽化、升华吸热；凝固、液化、凝华放热。
  • 晶体与非晶体：晶体有固定熔点（如冰 0℃、海波 48℃），熔化过程温度不变、持续吸热；非晶体（如石蜡、玻璃）无固定熔点。
  • 沸腾条件：达到沸点 + 继续吸热。沸腾时温度不变。
  • 液化方式：降低温度、压缩体积。
★
记忆口诀：「熔化汽化升华吸热，凝固液化凝华放热」。三个吸热都是「由固/液变气方向」，三个放热相反。

二、光现象与透镜

八上核心
11. 光的传播与反射
  • 光的直线传播：同种均匀介质中沿直线传播。现象：影子、小孔成像、日食月食。
  • 光速：真空中 c = 3×10⁸ m/s。
  • 光的反射定律：三线共面、法线两侧、反射角等于入射角。
  • 镜面反射与漫反射：都遵守反射定律；漫反射使我们能从各个方向看到物体。
  • 平面镜成像特点：正立、等大、虚像；像与物到镜面距离相等，连线与镜面垂直。
⚠
「反射角等于入射角」不能反过来说「入射角等于反射角」——因果顺序固定，答题时注意。
22. 光的折射与透镜
  • 折射规律：光从空气斜射入水或玻璃，折射角小于入射角；反之折射角大于入射角。
  • 凸透镜：中间厚边缘薄，对光有会聚作用。
  • 凹透镜：中间薄边缘厚，对光有发散作用。
  • 凸透镜成像规律：
  • 　　u > 2f → 倒立缩小实像（照相机）；u = 2f → 倒立等大实像；f < u < 2f → 倒立放大实像（投影仪）；u < f → 正立放大虚像（放大镜）。
  • 口诀：一倍焦距分虚实，二倍焦距分大小；物近像远像变大。
★
凸透镜成像是八年级必考且最难的知识点。建议画光路图理解（平行光线过焦点、过光心不变向）。

三、质量和密度

八上｜计算
11. 质量与密度
  • 质量：物体所含物质的多少，不随位置、形状、状态、温度改变。单位 kg，天平测量。
  • 密度：ρ = m/V。单位 kg/m³、g/cm³。1 g/cm³ = 1000 kg/m³。
  • 密度是物质的一种特性：同种物质密度相同（温度、状态一定时），与质量、体积无关。
  • 水的密度：1.0×10³ kg/m³（4℃时最大）。
💡
密度计算题常见套路：①求密度判断物质；②求质量（m = ρV）；③求体积（V = m/ρ）；④空心实心判断；⑤等体积/等质量问题。
22. 测量密度的实验
  • 测固体密度：用天平测质量 m；用量筒排水法测体积 V；ρ = m/V。
  • 测液体密度：先测烧杯+液体总质量 m₁；倒出一部分入量筒测体积 V；再测剩余总质量 m₂；ρ = (m₁−m₂)/V。
  • 注意：测液体密度必须先测总质量，再倒出，最后测剩余——顺序颠倒会导致误差偏大。
⚠
排水法测体积：物体要完全浸没且不接触容器壁；若物体漂浮需用针压法或沉锤法。

四、力与运动（八下）

八下核心｜力学
11. 力
  • 力的作用效果：改变物体的形状；改变物体的运动状态。
  • 三要素：大小、方向、作用点。力的示意图用带箭头的线段表示。
  • 重力：G = mg（g 取 9.8 N/kg，通常取 10 N/kg）。方向竖直向下，作用点为重心。
  • 弹力：弹簧测力计原理——弹性限度内，弹簧伸长量与所受拉力成正比。
  • 摩擦力：滑动摩擦力与压力大小和接触面粗糙程度有关，与接触面积、速度无关。
★
增大摩擦：增大压力、使接触面变粗糙；减小摩擦：减小压力、使接触面光滑、变滚动为滑动、使接触面分离（气垫、磁悬浮）。
22. 牛顿第一定律与二力平衡
  • 牛顿第一定律：一切物体在没有受到力的作用时，总保持静止状态或匀速直线运动状态。（通过实验推理得出，不能用实验直接验证）
  • 惯性：物体保持原来运动状态不变的性质。惯性大小只与质量有关，与速度无关。
  • 二力平衡条件：同物、等大、反向、共线。
  • 平衡力 vs 相互作用力：平衡力作用在同一物体上；相互作用力作用在两个物体上。
⚠
常错：「惯性是一种力」——错，惯性是性质不是力，不能说「受到惯性」。
33. 压强与浮力（八下）
  • 压强：p = F/S。单位 Pa。增大压强：增大压力或减小受力面积。
  • 液体压强：p = ρgh，与液体密度和深度有关，与容器形状无关。
  • 大气压：标准大气压约 1.013×10⁵ Pa。海拔越高气压越低，沸点越低。
  • 流体压强：流速越大，压强越小（机翼升力的原理）。
  • 阿基米德原理：F浮 = G排 = ρ液 g V排。
  • 浮沉条件：F浮 > G 上浮；F浮 = G 悬浮/漂浮；F浮 < G 下沉。
  • 称重法：F浮 = G − F示。
★
浮力计算三法：①原理法 F浮 = ρ液 g V排；②称重法 F浮 = G − F示；③平衡法（漂浮/悬浮时 F浮 = G物）。考试要先判断物体状态再选方法。
