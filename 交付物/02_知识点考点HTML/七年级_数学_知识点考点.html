一、有理数

七上｜基础
11. 有理数的概念与分类
  • 有理数：整数和分数统称有理数。可分为正有理数、0、负有理数。
  • 数轴：规定了原点、正方向、单位长度的直线。任何一个有理数都可用数轴上的点表示。
  • 相反数：只有符号不同的两个数。a 的相反数是 −a，0 的相反数是 0。
  • 绝对值：数轴上表示数 a 的点与原点的距离，记作 |a|。|a| ≥ 0，且 |a| = |−a|。
  • 倒数：乘积为 1 的两个数互为倒数（0 没有倒数）。
★
比较大小：正数>0>负数；两个负数比较，绝对值大的反而小。
22. 有理数的运算
  • 加法法则：同号相加取相同符号，绝对值相加；异号相加取绝对值较大的加数符号，并用较大的绝对值减去较小的绝对值。
  • 减法法则：减去一个数等于加上这个数的相反数。a − b = a + (−b)
  • 乘法法则：两数相乘，同号得正，异号得负；任何数乘 0 都得 0。
  • 除法法则：除以一个不为 0 的数，等于乘这个数的倒数。
  • 乘方：aⁿ 表示 n 个 a 相乘。负数的偶次幂为正，奇次幂为负。
  • 混合运算顺序：先乘方 → 再乘除 → 后加减 → 有括号先算括号内。
  • 运算律：加法交换律/结合律、乘法交换律/结合律/分配律。
✍
易错：−2² = −4，而 (−2)² = 4；|−3| = 3，但 −|−3| = −3。
33. 科学记数法与近似数
  • 科学记数法：a × 10ⁿ（1 ≤ |a| < 10，n 为整数）。如 6 500 000 = 6.5×10⁶。
  • 精确度：精确到哪一位或保留几位小数。
  • 有效数字：一个近似数中，从左边第一个非 0 数字起到末位数字止的所有数字。

二、整式的加减

七上｜重点
11. 单项式与多项式
  • 单项式：数或字母的乘积。单独一个数或一个字母也是单项式。
  • 单项式的系数：单项式中的数字因数；次数：所有字母的指数之和。
  • 多项式：几个单项式的和。多项式的项是每个单项式，次数是最高次项的次数。
  • 整式：单项式和多项式统称整式。
22. 合并同类项与去括号
  • 同类项：所含字母相同，且相同字母的指数也相同。与系数无关。
  • 合并同类项：字母和指数不变，系数相加。
  • 去括号法则：括号前是「+」，去括号各项符号不变；括号前是「−」，去括号各项符号都改变。
  • a + (b − c) = a + b − c　　a − (b − c) = a − b + c
✍
去括号是失分重灾区，特别是「−」号后面。建议先写「不动的项」，再逐项变号。
33. 整式的加减运算
  • 步骤：去括号 → 合并同类项。
  • 化简求值：先去括号、合并同类项化成最简，再代入数值。
  • 规律探究：观察数列/图形规律，用含 n 的式子表示第 n 项。

三、一元一次方程

七上｜核心
11. 方程与解方程
  • 一元一次方程：只含一个未知数，未知数的次数是 1，等号两边都是整式。
  • 等式的性质：①两边加（减）同一个数（式），结果仍相等；②两边乘同一个数（或除以同一个不为 0 的数），结果仍相等。
  • 解一元一次方程步骤：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1。
  • 移项要变号！如 x + 3 = 5 → x = 5 − 3。
★
去分母时，方程两边每一项都要乘各分母的最小公倍数，不要漏乘不含分母的项。
22. 实际问题与一元一次方程
  • 行程问题：路程 = 速度 × 时间；相遇（速度和）、追及（速度差）
  • 工程问题：工作总量 = 工作效率 × 工作时间（常设总量为 1）
  • 销售问题：利润 = 售价 − 进价；利润率 = 利润/进价 × 100%；打折：售价 = 标价 × 折扣
  • 配套问题：找等量关系（如 1 个螺栓配 2 个螺母）
  • 数字问题：两位数 = 十位数字×10 + 个位数字
  • 年龄问题：抓住「年龄差不变」
  • 解题步骤：审题 → 设未知数 → 找等量关系 → 列方程 → 解方程 → 检验作答

四、几何图形初步

七上｜几何入门
11. 几何图形与直线、射线、线段
  • 立体图形：棱柱、棱锥、圆柱、圆锥、球。平面图形：三角形、四边形、圆等。
  • 直线：两点确定一条直线；射线：有一个端点；线段：有两个端点。
  • 线段公理：两点之间，线段最短。两点间的距离：连接两点的线段的长度。
  • 线段中点：把线段分成两条相等线段的点。
  • 两点间距离与«线段最短»常考几何证明与计算。
22. 角
  • 角的度量：1° = 60′，1′ = 60″（60进制）
  • 角的分类：锐角（<90°）、直角（90°）、钝角（>90°且<180°）、平角（180°）、周角（360°）
  • 角平分线：把角分成两个相等的角。
  • 余角：两角和为 90°；补角：两角和为 180°。
  • 性质：同角（等角）的余角相等；同角（等角）的补角相等。
★
方位角是高频考点：北偏东 30°、南偏西 60° 等，注意「先南北后东西」。

五、相交线与平行线

七下｜重点
11. 相交线与垂线
  • 对顶角：两直线相交，对顶角相等。
  • 邻补角：互补（和为 180°）。
  • 垂线：两直线相交成直角。垂线段最短。
  • 点到直线的距离：直线外一点到这条直线的垂线段的长度。
22. 平行线的判定与性质
  • 三线八角：同位角（F型）、内错角（Z型）、同旁内角（U型）。
  • 判定：同位角相等 → 两直线平行；内错角相等 → 两直线平行；同旁内角互补 → 两直线平行。
  • 性质：两直线平行 → 同位角相等；内错角相等；同旁内角互补。
  • 平行公理：过直线外一点，有且只有一条直线与已知直线平行。
  • 平行线间的距离处处相等。
✍
判定是「由角推平行」，性质是「由平行推角」，切勿混用。
33. 平移
  • 平移不改变图形的形状和大小，只改变位置。
  • 平移后：对应线段平行（或共线）且相等；对应角相等；对应点连线平行且相等。

六、实数

七下｜核心
11. 平方根与立方根
  • 算术平方根：正数 a 的正的平方根，记作 √a（a ≥ 0）。
  • 平方根：一个正数有两个平方根，互为相反数，记作 ±√a；0 的平方根是 0；负数没有平方根。
  • 立方根：任何数都有立方根，正数立方根为正，负数立方根为负，记作 ∛a。
  • 重要公式：(√a)² = a（a≥0）；√(a²) = |a|；∛(a³) = a；∛(−a) = −∛a
★
易混：√16 = 4（算术平方根），16 的平方根 = ±4，16 的立方根 = ∛16。
22. 实数的概念与运算
  • 无理数：无限不循环小数（如 √2、π、0.1010010001…）。
  • 实数：有理数和无理数统称实数。实数与数轴上的点一一对应。
  • 实数的性质：相反数、绝对值、倒数的定义与有理数一致。
  • 估算：用「夹逼法」估算无理数大小，如 2 < √5 < 3。
  • 运算：实数的加减乘除、乘方、开方（开不尽的保留根号）。

七、平面直角坐标系

七下｜基础
11. 坐标系与点的坐标
  • 有序数对 (a, b)：a 是横坐标，b 是纵坐标。
  • 象限：第一象限 (+,+)｜第二象限 (−,+)｜第三象限 (−,−)｜第四象限 (+,−)。坐标轴上的点不属于任何象限。
  • x 轴上的点纵坐标为 0；y 轴上的点横坐标为 0。
  • 对称点：关于 x 轴对称（x 不变，y 变号）；关于 y 轴对称（y 不变，x 变号）；关于原点对称（x、y 都变号）。
22. 坐标与平移
  • 平移规律：向右（左）平移 a 个单位，横坐标加（减）a；向上（下）平移 b 个单位，纵坐标加（减）b。
  • 简记：左减右加，下减上加。

八、二元一次方程组与不等式

七下｜重点
11. 二元一次方程组
  • 解法：代入消元法、加减消元法。核心思想：消元（二元→一元）。
  • 实际应用：和差倍分、配套、行程、销售、方案设计等。
  • 列方程组步骤：审题→设未知数→找等量关系→列方程组→解→检验。
22. 不等式与不等式组
  • 不等式性质：①两边加（减）同一个数，不等号方向不变；②两边乘（除）同一个正数，方向不变；③两边乘（除）同一个负数，方向改变。
  • 解集在数轴上表示：实心点「≥、≤」，空心圈「>、<」。
  • 一元一次不等式组：取各解集的公共部分。口诀：大大取大，小小取小，大小小大中间找，大大小小无解了。
✍
不等式两边乘除负数，一定要变号！这是七年级最高频失分点。
