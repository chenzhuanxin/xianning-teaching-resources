中考语文试卷结构与分值（咸宁卷）

命题依据
考点试卷格局总览
  • 全卷满分 120 分，考试时间 150 分钟。
  • 第一大题 积累与运用（约 26 分）：字音字形、词语运用、病句辨析、标点、文学文化常识、名著阅读、古诗文默写、综合性学习。
  • 第二大题 阅读理解（约 44 分）：古诗文阅读（约 17 分）＋ 现代文阅读（约 27 分，含记叙文、说明文/议论文）。
  • 第三大题 写作（50 分）：命题作文、半命题作文或材料作文。
  • 名句默写与名著阅读为保分题，写作与阅读为拉分题。
★
默写与名著属确定考点，务必 100% 拿满；写作要练到「限时成篇、卷面工整」。

积累与运用：字音字形

基础保分
01易错字音字形清单
  • 多音字：埋（mái 埋没 / mán 埋怨）、血（xuè 血液 / xiě 血淋淋口语）、载（zài 载重 / zǎi 记载）、供（gōng 供给 / gòng 供电）、横（héng 横竖 / hèng 蛮横）。
  • 易读错：名副其实（fù）、锲而不舍（qiè）、恪尽职守（kè）、鳞次栉比（zhì）、觥筹交错（gōng）。
  • 易写错：再接再厉、变本加厉、迫不及待、川流不息、走投无路、再接再厉、黯然失色、铤而走险。
  • 形近字：报酬 / 抱负、泻千里 / 倾泻 / 宣泄。
💡
把三年课本「读读写写」整理成错题本，每天听写 20 个，是最高性价比的提分方式。
3

积累与运用：词语、病句、标点

高频考点
02词语运用
  • 辨析角度：词义轻重、感情色彩（褒/贬/中性）、适用对象、搭配习惯、语体色彩（口语/书面）。
  • 常见误用：炙手可热（贬义，指气焰盛）、首当其冲（最先受到攻击）、差强人意（大体令人满意）、不刊之论（不可修改的言论）、万人空巷（形容盛大场面）。
03病句六种类型
  • 搭配不当：主谓、动宾、修饰语与中心语、一面与两面不搭配。
  • 成分残缺：缺主语、缺谓语、缺宾语中心语。
  • 语序不当：多层定语/状语顺序、关联词位置、并列成分逻辑顺序。
  • 结构混乱：句式杂糅（「原因是……造成的」）。
  • 表意不明：指代不清、歧义。
  • 不合逻辑：自相矛盾、否定不当、主客颠倒。
⚠
「防止不发生」这类多重否定要数清否定词个数；「通过……使……」必查主语残缺。
04标点符号
  • 顿号用于并列词语之间；并列短语作谓语或补语时用逗号。
  • 引号内是完整引用且独立成句，句末点号放在引号内；否则放引号外。
  • 书名号与引号不可混用；破折号、省略号不与「等」连用。
⚠
概数之间不用顿号：「三四十人」不写成「三、四十人」。

文学文化常识与名著阅读

确定考点
05必背常识
  • 《诗经》是我国最早诗歌总集，分风、雅、颂，手法赋、比、兴。
  • 「唐宋八大家」：韩愈、柳宗元、欧阳修、苏洵、苏轼、苏辙、王安石、曾巩。
  • 古代年龄称：垂髫（儿童）、加冠（20 岁）、而立（30）、不惑（40）、知天命（50）、花甲（60）、古稀（70）。
  • 「四书」：《大学》《中庸》《论语》《孟子》；「五经」：《诗》《书》《礼》《易》《春秋》。
  • 谦敬词：家父（谦）、令郎（敬）、舍弟（谦）、贤弟（敬）、拙作（谦）、惠赠（敬）。
06中考名著必考六部
  • 《西游记》：孙悟空形象、三打白骨精、真假美猴王；主题与讽刺意味。
  • 《水浒传》：人物绰号（及时雨宋江、豹子头林冲、行者武松）、鲁提辖拳打镇关西、林教头风雪山神庙。
  • 《朝花夕拾》：《从百草园到三味书屋》《藤野先生》《阿长与〈山海经〉》，温馨回忆与理性批判并存。
  • 《骆驼祥子》：祥子三次买车三次失去，揭示旧社会对劳动者的摧残。
  • 《钢铁是怎样炼成的》：保尔·柯察金，生命意义名言，钢铁意志的形成。
  • 《简·爱》：追求人格独立与平等爱情，女性意识觉醒。
💡
名著题常考「人物＋情节＋性格＋启示」四要素，答题要成句，不要只写关键词。

古诗文默写（必考篇目）

背默满分
07九年级及中考高频名句
  • 《行路难》：长风破浪会有时，直挂云帆济沧海。
  • 《岳阳楼记》：先天下之忧而忧，后天下之乐而乐。「不以物喜，不以己悲。」
  • 《醉翁亭记》：醉翁之意不在酒，在乎山水之间也。
  • 《茅屋为秋风所破歌》：安得广厦千万间，大庇天下寒士俱欢颜！
  • 《水调歌头》：但愿人长久，千里共婵娟。
  • 《渔家傲·秋思》：浊酒一杯家万里，燕然未勒归无计。
  • 《破阵子》：了却君王天下事，赢得生前身后名。
  • 《过零丁洋》：人生自古谁无死？留取丹心照汗青。
  • 《出师表》：亲贤臣，远小人，此先汉所以兴隆也。「受任于败军之际，奉命于危难之间。」
  • 《送东阳马生序》：以中有足乐者，不知口体之奉不若人也。
  • 《爱莲说》：出淤泥而不染，濯清涟而不妖。
  • 《陋室铭》：斯是陋室，惟吾德馨。
⚠
默写只考「上下句＋理解性默写」，错一字即全句不得分，务必书写规范（「婵娟」「燕然未勒」「汗青」易错）。

古诗文阅读答题模板

方法套路
08文言实词与虚词
  • 重点实词：故（所以/旧的）、或（有人/或许）、自（从/亲自）、属（类/嘱托）、间（暗中/参与）、谢（道歉/辞别）。
  • 高频虚词：之（的/主谓之间/代词/提宾标志/动词「到」）；而（并列/承接/转折/修饰）；以（因为/用/凭借/来）；于（在/比/向/被）；其（他的/那/难道/大概）。
  • 词类活用：名作动、名作状、形作动、使动、意动。
  • 特殊句式：判断句、被动句、省略句、倒装句（宾语前置、状语后置、定语后置）。
09句子翻译六字法
  • 留（人名地名官名年号照录）、删（发语词、结构助词）、替（古今异义换今词）、调（倒装还原）、补（补出省略成分）、贯（语意通顺）。
★
翻译采分点必落：关键词实词、虚词用法、特殊句式，三者都要体现。
10诗歌鉴赏四大题型
  • 炼字题：释字义 → 描画面 → 点效果（生动/传神）→ 表情感。
  • 画面题：找意象 → 加修饰 → 成画面 → 概括氛围（恬静/雄浑/凄清）。
  • 情感题：抓关键词＋知人论世＋意象色彩，答「表达了……之情」。
  • 手法题：点明手法（借景抒情/虚实结合/用典/对比/衬托）→ 结合诗句分析 → 说明效果与情感。

现代文阅读答题模板

拉分关键
11记叙文（小说/散文）
  • 概括情节：人物＋事件（起因→经过→结果），用「谁在什么情况下做了什么，结果怎样」。
  • 词句赏析：修辞/描写方法 → 写出了什么内容 → 表达了什么情感；比喻要指出本体喻体，拟人要指出赋予人的特征。
  • 人物形象：从事件、言行、他人评价中概括，用「他是一个……的人」句式，分点作答。
  • 标题作用：概括内容、点明主旨、线索贯穿、设置悬念、象征意义、激发兴趣。
  • 环境描写作用：交代时间地点背景、渲染气氛、烘托心情、推动情节、深化主题。
  • 结尾作用：卒章显志、呼应开头、戛然而止引发思考、出人意料又在情理之中。
12说明文
  • 说明方法及作用：举例子（具体真切）、列数字（准确）、作比较（突出）、打比方（生动形象）、分类别（条理清晰）、下定义（科学准确）、摹状貌（具体形象）。
  • 说明顺序：时间顺序、空间顺序、逻辑顺序。
  • 语言特点：准确性（「约」「左右」「大约」不可删）、科学性、严密性。
13议论文
  • 找中心论点：看标题、开头、结尾，注意「我认为」「由此可见」「因此」等标志词。
  • 论证方法：举例论证（具体有力）、道理论证（权威有力）、对比论证（鲜明突出）、比喻论证（通俗易懂）。
  • 论证思路：首先提出……观点，然后通过……论证，最后得出……结论。
  • 开头作用：提出论点、引出论题、以事例/名言/设问激发兴趣。
⚠
答题必须「术语＋文中具体内容」，只写术语不给分。
8

综合性学习与实践

5分题
14常考题型
  • 拟写标语/广告语：紧扣主题、对仗押韵、简洁有力、富有感染力。
  • 口语交际：称呼得体 → 说明来意 → 陈述理由 → 语气委婉（劝说类要「委婉而不失立场」）。
  • 材料探究：逐则提炼 → 找共性/联系 → 用一句话概括结论。
  • 活动设计：活动名称＋活动目的＋活动步骤，命名如「诵读经典·涵养心灵」。
💡
开放性题务必写满，分点作答，语言得体有文采是加分项。

写作 50 分 高分指南

核心大头
15评分要点
  • 一类文（45—50）：立意深刻、中心突出、材料新颖、结构清晰、语言有文采、卷面工整。
  • 二类文（38—44）：中心明确、内容具体、结构完整、语言通顺。
  • 三类文（30—37）：中心基本明确、内容较空、语言基本通顺。
  • 字数不足、卷面潦草、无标题均要扣分。
16结构模板（五段式最稳）
  • ①开篇点题：名言/场景/比喻入题，100 字内亮出中心。
  • ②分论点一＋事例＋分析（150—200 字）。
  • ③分论点二＋事例＋分析（150—200 字），与上一段形成递进或对照。
  • ④联系现实/自我，深化立意（120 字左右）。
  • ⑤结尾升华：呼应开头、引用收束、发出号召（80—100 字）。
★
首尾段必须出现题目关键词，中间每段首句是分论点——阅卷老师 40 秒内要看懂你的框架。
