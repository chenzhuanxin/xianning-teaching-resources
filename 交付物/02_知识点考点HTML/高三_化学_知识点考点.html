化学基本概念与基本理论

高考必考 · 约30分
1物质的量
  • 物质的量：n = m/M = N/N_A = V/Vm（气体）= c·V（溶液）。
  • 阿伏加德罗常数：N_A = 6.02×10²³ mol⁻¹。
  • 气体摩尔体积：标准状况下 Vm = 22.4 L/mol（仅适用于气体，且必须强调标准状况）。
  • 物质的量浓度：c = n/V。稀释公式：c₁V₁ = c₂V₂。
  • 阿伏加德罗定律：同温同压下，体积之比 = 物质的量之比 = 分子数之比。
  • 配制一定浓度溶液：计算 → 称量/量取 → 溶解/稀释 → 冷却 → 转移 → 洗涤 → 定容 → 摇匀 → 装瓶。
⚠️
N_A 判断题的七大陷阱：①标准状况下非气体（如 H₂O、CCl₄、SO₃）；②是否标准状况（如常温常压）；③是否水解/电离（如氯化铁溶液）；④氧化还原中电子转移数；⑤化学键数目（如 1 mol 金刚石含 2 mol C-C 键）；⑥溶液体积是否已知；⑦是否可逆反应。
2离子反应与氧化还原
  • 离子方程式书写：①写（正确书写化学方程式）；②拆（强酸、强碱、可溶盐拆；单质、氧化物、难溶物、弱电解质、气体不拆）；③删（删去不参与反应的离子）；④查（原子守恒、电荷守恒）。
  • 离子共存判断：①是否生成沉淀；②是否生成气体；③是否生成弱电解质（水、弱酸、弱碱）；④是否发生氧化还原；⑤溶液颜色与酸碱性条件（隐含条件如「无色」「pH=1」）。
  • 氧化还原：①化合价升高——失电子——被氧化——作还原剂；②化合价降低——得电子——被还原——作氧化剂。
  • 口诀：「升失氧、降得还，剂性相反」。
  • 配平方法：电子守恒法（标价态 → 列变化 → 定系数 → 配平其他）。
🔑
氧化还原口诀「升失氧、降得还，剂性相反」：化合价升高→失电子→被氧化→是还原剂（具有还原性）。这 12 个字能解决 80% 的氧化还原基础题，务必背熟。
3化学平衡与反应速率
  • 反应速率：v = Δc/Δt。影响因素：浓度、温度、压强（有气体参与）、催化剂、表面积。
  • 化学平衡状态判断标志：①v正 = v逆 ≠ 0；②各组分的浓度、百分含量保持不变；③有颜色变化的体系颜色不变。
  • 勒夏特列原理：改变影响平衡的一个条件，平衡向减弱这种改变的方向移动。
  • 平衡常数：K = 生成物浓度幂之积 / 反应物浓度幂之积（纯固体液体不写入）。
  • 转化率：α = 已转化量 / 起始量 × 100%。
  • 等效平衡：①恒温恒容——按化学计量数换算到同一边，量相同则等效；②恒温恒压——换算到同一边，量成比例则等效。
💡
判断一个可逆反应是否达到平衡，看的是「变量不变」：若某物理量在反应过程中会变（如颜色、密度、平均相对分子质量、压强），它不变时即达到平衡；若恒为定值（如恒容容器中密度始终不变），则不能作为判断依据。

元素化学与无机综合

高考必考 · 约25分
1金属元素及其化合物
  • 钠：①Na₂O₂（淡黄色，与水/CO₂反应放出 O₂）；②Na₂CO₃（纯碱）与 NaHCO₃（小苏打）的鉴别与转化；③Na 与水反应「浮、熔、游、响、红」。
  • 铝：①Al 与 Al₂O₃、Al(OH)₃ 都既能与强酸又能与强碱反应（两性）；②铝热反应；③Al³⁺ 与 AlO₂⁻ 双水解。
  • 铁：①Fe²⁺（浅绿色）与 Fe³⁺（棕黄色）的检验与转化；②KSCN 检验 Fe³⁺（变血红色）；③铁三角转化关系。
  • 铜：①Cu 与浓硝酸、稀硝酸的反应（浓硝酸放 NO₂，稀硝酸放 NO）；②CuSO₄·5H₂O（蓝色晶体）。
🔑
「铁三角」转化必背：Fe →（弱氧化剂如 HCl）→ Fe²⁺ →（强氧化剂如 Cl₂）→ Fe³⁺ →（还原剂如 Fe、Cu）→ Fe²⁺。检验 Fe³⁺ 用 KSCN 变血红，检验 Fe²⁺ 先加 KSCN 不变色、再加氯水变血红。
2非金属元素及其化合物
  • 氯：①Cl₂ 与 NaOH 反应制漂白液、与 Ca(OH)₂ 制漂白粉；②Cl₂ 的实验室制法（MnO₂ + 浓盐酸加热）；③Cl⁻ 检验用 AgNO₃ 与稀硝酸。
  • 硫：①SO₂（刺激性气味，漂白性——与品红结合生成不稳定无色物质、加热复原）；②浓硫酸的三大特性（吸水性、脱水性、强氧化性）；③SO₄²⁻ 检验。
  • 氮：①NH₃（碱性气体，能使湿润红色石蕊试纸变蓝；喷泉实验）；②HNO₃ 的强氧化性（与 Cu 反应）；③NO 与 NO₂ 的性质与转化；④铵盐受热分解。
  • 硅：①SiO₂（酸性氧化物，与 HF 反应；与 NaOH 反应）；②硅酸盐；③硅酸的制备。
⚠️
SO₂ 的漂白性与 Cl₂、HClO 的漂白性有本质区别：SO₂ 是与有色物质结合生成不稳定的无色物质（加热可复原）；Cl₂/HClO 是把有色物质氧化破坏（不可复原）。两者同时使用时，漂白性会因氧化还原反应而相互减弱。

有机化学基础（选择性必修3）

高考必考 · 约25分
1有机物的结构与命名
  • 官能团：①碳碳双键 C=C；②碳碳三键 C≡C；③羟基 -OH；④醛基 -CHO；⑤羧基 -COOH；⑥酯基 -COO-；⑦氨基 -NH₂；⑧卤素原子 -X。
  • 同系物：结构相似、分子组成相差一个或多个 CH₂ 原子团。
  • 同分异构体：①碳链异构；②位置异构；③官能团异构（类别异构）。
  • 系统命名：①选最长碳链为主链；②编号从离支链最近的一端开始；③支链位次最小、名称最简。
  • 共线共面判断：①甲烷中最多3原子共面；②乙烯6原子共面；③乙炔4原子共线；④苯12原子共面。
🔑
共线共面四大母体必背：甲烷（正四面体，最多3原子共面）、乙烯（平面，6原子共面）、乙炔（直线，4原子共线）、苯（平面正六边形，12原子共面）。以此为骨架拼接，就能判断复杂分子的共面原子数。
2烃及烃的衍生物
  • 烷烃：取代反应（光照下与 Cl₂）。烯烃：①加成（与 H₂、X₂、HX、H₂O）；②加聚；③氧化（酸性 KMnO₄ 褪色）。
  • 芳香烃：①苯——取代（卤代、硝化、磺化）、加成（与 H₂）；②甲苯——苯环侧链氧化使酸性 KMnO₄ 褪色。
  • 醇：①与 Na 反应放 H₂；②消去反应（浓硫酸加热，β-H 消除）；③氧化（催化氧化成醛/酮）；④酯化。
  • 醛：①银镜反应（与银氨溶液，水浴加热）；②与新制 Cu(OH)₂ 反应（加热生成砖红色沉淀）。
  • 羧酸：①酸性；②酯化反应（酸脱羟基醇脱氢）。酯：水解（酸性水解可逆、碱性水解完全）。
💡
酯化反应「酸脱羟基、醇脱氢」是必考机理，可用同位素 ¹⁸O 标记法验证：用 CH₃CO¹⁸OH 与乙醇反应，¹⁸O 进入酯中。这个细节常出现在有机推断题中。
3有机推断与合成
  • 推断突破口：①特征反应（银镜反应、KMnO₄ 褪色、Br₂ 水褪色、FeCl₃ 显紫色）；②分子式与不饱和度（Ω = C + 1 − H/2 + N/2）；③转化关系图。
  • 常见转化链：醇 → 醛 → 酸 → 酯；卤代烃 → 醇；烯烃 → 卤代烃/醇。
  • 合成路线设计：①正向（原料→目标）；②逆向（目标→原料）；③双向结合。
  • 保护官能团：如合成中先保护羟基再氧化，避免羟基被氧化。
  • 同分异构体书写：①按类别异构分（酯、酸、羟基醛等）；②按碳链分；③按位置分；④逐一检验（不重不漏）。
⚠️
同分异构体书写「不重不漏」是评分关键。推荐顺序：先判断是否含苯环/是否含多个官能团 → 按官能团类别分类 → 每类内按碳链骨架变化 → 最后核对总数。数量题几乎每年必考，写少一个就丢一半分。

实验化学与化工流程

高考必考 · 约35分
1化学实验基础
  • 常用仪器：①计量仪器（量筒、容量瓶、滴定管、天平）；②加热仪器（酒精灯、酒精喷灯）；③分离仪器（漏斗、分液漏斗、蒸馏装置）。
  • 分离提纯：①过滤（固液分离）；②蒸发结晶（溶解度随温度变化小）；③冷却结晶（溶解度随温度变化大）；④蒸馏（沸点差异大）；⑤萃取分液（溶解度差异）；⑥洗气（气体除杂）。
  • 气体制备：①发生装置（固液不加热、固固加热等）；②净化（除杂）；③干燥；④收集（向上排空气、向下排空气、排水法）；⑤尾气处理。
  • 实验安全：①浓硫酸稀释——酸入水，沿器壁缓缓加入并搅拌；②闻气体气味——手扇动；③点燃可燃性气体前验纯。
🔑
选择结晶方式的口诀：「溶解度受温度影响大 → 冷却结晶（如 KNO₃）；影响小 → 蒸发结晶（如 NaCl）」。若两种溶质共存，还要考虑「趁热过滤」避免目标物析出。这是化工流程题的必考点。
2化工流程题解题模型
  • 三大主线：①原料预处理（粉碎、焙烧、酸浸、碱浸）；②核心反应与分离提纯；③产品获得（蒸发浓缩、冷却结晶、过滤、洗涤、干燥）。
  • 常见设问：①提高浸出率的措施（粉碎、升温、搅拌、增大浓度）；②为什么要加某试剂（除杂、调 pH、防止水解）；③为什么要控制温度（防止分解/挥发/副反应）；④洗涤方式（冷水洗、乙醇洗、热水洗）；⑤产率计算。
  • 调 pH 的作用：使某些金属离子水解生成氢氧化物沉淀而除去（如除去 Fe³⁺、Al³⁺）。
  • 绿色化学：①原子经济性；②循环利用（母液回收）；③减少三废。
💡
流程题中「用乙醇洗涤」的原因须背三条：①减少晶体溶解损失（乙醇中溶解度小）；②乙醇易挥发，便于干燥；③防止晶体结晶水合物脱水或水解。这是每年都会出现的标准答案。
3电化学与溶液中的平衡
  • 原电池：①负极（较活泼金属）失电子氧化；②正极得电子还原；③电子由负极经外电路流向正极；④离子移动——阳离子向正极、阴离子向负极。
  • 电解池：①阴极（接电源负极）得电子还原；②阳极（接电源正极）失电子氧化；③阳极若为活性电极（如 Cu），则电极本身溶解。
  • 水的电离与 pH：①Kw = c(H⁺)·c(OH⁻) = 1×10⁻¹⁴（25℃）；②pH = −lg c(H⁺)；③酸性越强 pH 越小。
  • 盐类水解：①规律——「谁弱谁水解，谁强显谁性」；②升温促进水解；③浓度稀释促进水解；④加酸抑制阳离子水解。
  • 沉淀溶解平衡：①Ksp = c(M^n+)·c(A^m−)；②Q > Ksp 生成沉淀；③沉淀转化（Ksp 大的转化为 Ksp 小的）。
  • 中和滴定：①关键——锥形瓶中待测液，滴定管中标准液；②终点判断（半分钟内不褪色）。
⚠️
盐类水解「越稀越水解、越热越水解」，但水解程度通常很小。比较离子浓度大小时，先看电离（主要），再看水解（次要）。如 Na₂CO₃ 溶液中 c(Na⁺) > c(CO₃²⁻) > c(OH⁻) > c(HCO₃⁻)。
