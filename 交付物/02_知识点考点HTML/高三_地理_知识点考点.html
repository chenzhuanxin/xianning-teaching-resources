1

自然地理主干

高考必考 · 约35分
1地球运动与大气
  • 时区计算：①每15°一个时区；②东加西减；③国际日期变更线自西向东越过减一天。
  • 太阳直射点：夏至（6月22日前后）23°26′N；冬至（12月22日前后）23°26′S；春秋分赤道。
  • 正午太阳高度：H = 90° − |当地纬度 − 直射点纬度|。
  • 大气受热过程：太阳辐射（短波）→ 地面吸收 → 地面辐射（长波）→ 大气吸收 → 大气逆辐射（保温作用）。
  • 热力环流：受热上升（近地面低压）、冷却下沉（近地面高压）。
  • 三圈环流与气压带风带：七个气压带 + 六个风带。随太阳直射点南北移动。
  • 气候类型判断：①以温定带（最冷月均温：>15℃热带，0~15℃亚热带/温带海洋，<0℃温带）；②以水定型（年雨型、夏雨型、冬雨型、少雨型）。
🔑
气候判断「以温定带、以水定型」两步法是必杀技。先看最冷月气温定温度带，再看降水季节分配定类型。例如「最冷月 5℃、夏季少雨冬季多雨」→ 地中海气候。这个方法能解决几乎所有气候判断题。
2水文、地貌与整体性差异性
  • 河流补给：①雨水补给（东部季风区最主）；②冰雪融水补给（西北内陆，夏季为汛期）；③地下水补给。
  • 河流水文特征：流量、汛期、含沙量、结冰期、水位变化、水能。
  • 洋流：①中低纬——北顺南逆；②中高纬（北半球）——逆时针；③影响（气候、渔场、航行、污染）。
  • 四大渔场：纽芬兰、北海道、北海（寒暖流交汇）；秘鲁（上升补偿流）。
  • 内外力作用：①内力——地壳运动、岩浆活动、变质作用；②外力——风化、侵蚀、搬运、堆积。
  • 地质构造：背斜（岩层向上拱起，储油储气、隧道选址）；向斜（向下弯曲，储水、找水）；断层（泉水出露、工程建设避开）。
  • 地域分异规律：①纬度地带性（热量）；②经度地带性（水分）；③垂直地带性（水热）；④非地带性。
💡
背斜与向斜的「实践应用」必背：背斜——储存石油天然气（油、气轻，向上聚集）、隧道选址（拱形结构稳固、不易积水）；向斜——储存地下水（水重，向下聚集、找水打井）。工程地质题常考。
2

人文地理与区域发展

高考必考 · 约30分
1人口、城市与产业
  • 人口增长模式：①原始型（高出生、高死亡、低增长）；②传统型（高出生、低死亡、高增长）；③现代型（低出生、低死亡、低增长）。
  • 人口迁移：①影响因素——经济（主）、政治、社会文化、生态环境；②影响——对迁出地（缓解人地矛盾、人才流失）；对迁入地（提供劳动力、增加压力）。
  • 人口容量：①资源是首要制约因素；②科技水平、消费水平影响人口合理容量。
  • 城市空间结构：①同心圆模式；②扇形模式；③多核心模式。功能区——商业区（市中心）、住宅区（面积最大）、工业区（城市外围、交通便利、下风向）。
  • 城市化：①标志——城市人口占总人口比重上升；②问题——交通拥堵、住房紧张、环境污染、就业困难；③对策——建卫星城、发展公共交通、合理规划。
  • 农业区位：①自然——气候、地形、土壤、水源；②社会经济——市场、交通、政策、劳动力、科技。
  • 工业区位：①原料导向型；②市场导向型；③动力导向型；④劳动力导向型；⑤技术导向型。
🔑
工业区位选择「五导向」的判断：看「运费与加工成本」谁占主导——原料易腐、失重大 → 原料导向；产品易碎、不便运输 → 市场导向；耗能巨大 → 动力导向；需大量廉价劳动力 → 劳动力导向；技术要求高 → 技术导向。
2区域可持续发展与国土整治
  • 区域生态环境问题：①荒漠化（西北——过度樵采、过度放牧、过度开垦）；②水土流失（黄土高原——土质疏松、暴雨集中、植被破坏）；③石漠化（西南喀斯特）；④湿地萎缩。
  • 流域综合开发：①上游——水源涵养、水土保持；②中游——防洪、蓄水；③下游——航运、污染防治。
  • 资源枯竭型城市转型：①延长产业链；②培育新兴产业；③发展第三产业；④改善生态环境。
  • 产业转移：①推力（发达地区：地价、劳动力成本上升、环境压力）；②拉力（欠发达地区：劳动力廉价、地价低、政策优惠、市场潜力）。
  • 资源跨区域调配：南水北调、西气东输、西电东送——对输出地（资源优势转经济优势、带动就业）与输入地（缓解资源紧张、改善能源结构）的双向影响。
  • 我国重大区域战略：京津冀协同发展、长江经济带、粤港澳大湾区、黄河流域生态保护与高质量发展、成渝双城经济圈。
⚠️
产业转移影响必须「双向作答」：对迁出地（利：产业结构升级、环境改善；弊：就业机会减少、产业空心化）；对迁入地（利：促进经济发展、增加就业；弊：资源消耗、环境污染）。只答一方必然丢分。
3

区域地理与地理实践

高考必考 · 约35分
1中国地理重点区域
  • 北方地区：①东北——商品谷物农业（地广人稀、机械化）；②华北——旱涝盐碱、水资源短缺（南水北调）。
  • 南方地区：①长江三角洲——城市群、外向型经济；②珠江三角洲——轻工业、外向型、产业转移。
  • 西北地区：①气候干旱、光照充足；②畜牧业与灌溉农业（绿洲农业）；③荒漠化治理；④西气东输起点（塔里木盆地）。
  • 青藏地区：①高寒——河谷农业（雅鲁藏布江谷地、湟水谷地）；②三江源自然保护区；③太阳能、地热能丰富。
  • 长江经济带：「共抓大保护、不搞大开发」，生态优先、绿色发展。
💡
「青藏高原发展河谷农业」的原因必背：①海拔相对较低（河谷），热量条件较好；②水源充足；③土壤较肥沃；④地形平坦。高寒地区一切农业生产的核心制约都是「热量」，答题先写热量。
2世界地理重点区域
  • 亚洲：①东亚（季风气候显著）；②南亚（热带季风、西南季风带来降水）；③西亚（石油资源、干旱气候、两河文明）。
  • 欧洲：①温带海洋性气候（西风带 + 北大西洋暖流）；②乳畜业发达；③欧盟。
  • 非洲：①「热带大陆」「高原大陆」；②撒哈拉以南——单一商品经济、人口粮食环境问题。
  • 北美：①美国——商品谷物农业、高度机械化、专业化；②五大湖工业区、硅谷。
  • 南美：①亚马孙雨林（「地球之肺」，破坏与保护）；②秘鲁渔场；③巴西——咖啡、大豆。
  • 大洋洲与极地：①澳大利亚——骑在羊背上、坐在矿车上（混合农业、墨累—达令盆地）；②南极——科学考察、淡水资源、企鹅。
⚠️
「澳大利亚墨累—达令盆地」的农业问题必背：①位于大分水岭背风坡，降水少 → 需东水西调；②灌溉不当导致土地盐碱化；③为混合农业（小麦—牧羊），可灵活应对市场波动。这是区域农业的经典案例。
3地理实践与答题规范
  • 地理图表判读：①等值线（等高线、等温线、等压线）——看数值、疏密、弯曲方向；②统计图——看坐标、单位、变化趋势；③区域图——定位（经纬度、海陆轮廓、典型地物）。
  • 区域定位方法：①经纬度定位；②海陆轮廓定位；③重要地理事物定位（山脉、河流、城市）；④相对位置定位。
  • 综合题答题模板：①自然地理——地形、气候、水文、生物、土壤；②人文地理——市场、交通、政策、劳动力、技术、资源；③区位分析——有利与不利两方面；④影响评价——有利与不利两方面。
  • 答题要求：①分点作答，序号清晰；②术语规范（「降水丰沛」不用「雨很多」）；③结合材料，有针对性；④先主要后次要。
🔑
地理综合题「要素分析法」是万能钥匙：分析自然原因 → 地形 + 气候 + 水文 + 生物 + 土壤；分析人文原因 → 市场 + 交通 + 政策 + 劳动力 + 技术 + 资源。把要素列全，再逐一判断，答案自然就完整了，不会漏点。
