1．单选 C
【解析】质点是一种理想化模型，判断标准是物体的大小形状对所研究的问题是否有影响，与物体体积、质量大小及运动形式无关。
2．单选 B
【解析】加速度是描述速度变化快慢的物理量。加速度大表示速度变化快；加速度与速度同向时物体加速，反向时减速，二者大小变化无必然联系。
3．单选 B
【解析】v=gt=10×2=20 m/s。
4．单选 C
【解析】牛顿第一定律说明力是改变运动状态的原因，不是维持运动的原因；一切物体都有惯性，惯性大小只由质量决定。
5．单选 D
【解析】合力范围 |F₁−F₂| ≤ F ≤ F₁+F₂，即 1 N ≤ F ≤ 7 N，故 8 N 不可能。
6．单选 B
【解析】由 G=mg 得 m=G/g=10/10=1 kg。
7．单选 C
【解析】a=F/m=2/1=2 m/s²。
8．单选 D
【解析】矢量既有大小又有方向。速度是矢量；路程、时间、质量都是标量。
9．多选 ABD
【解析】作用力与反作用力分别作用在两个不同物体上，不能相互抵消，C 错误；其余均正确。
10．多选 ABC
【解析】动能不变时机械能可能改变（如物体沿斜面匀速下滑，动能不变而重力势能减少，机械能不守恒），D 错误。
11．填空 5
【解析】t=v/a=20/4=5 s。
12．填空 2
【解析】a=F/m=6/3=2 m/s²。
13．填空 20
【解析】G=mg=2×10=20 N。
14．填空 32
【解析】W=Fl=8×4=32 J。
15．计算 （1）v=v₀+at=0+2×5=10 m/s （2）s=v₀t+½at²=0+½×2×25=25 m
【解析】匀加速直线运动公式的直接应用。注意初速度为零。
16．计算 （1）f=μN=μmg=0.2×2×10=4 N （2）由牛顿第二定律 F−f=ma 得 a=(10−4)/2=3 m/s² （3）v=at=3×3=9 m/s
【解析】先受力分析求合力，再由牛顿第二定律求加速度，最后用运动学公式求速度。
17．计算 （1）由 v²=2gh 得 v=√(2×10×5)=10 m/s （2）Ek=½mv²=½×1×100=50 J （3）由机械能守恒，上升高度 h′=Ek/(mg)=50/(1×10)=5 m
【解析】自由落体与竖直上抛均可由机械能守恒求解，注意能量守恒的对称性。
