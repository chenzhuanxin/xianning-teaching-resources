1．单选 B
【解析】盐酸是 HCl 气体的水溶液，属混合物；冰水混合物、胆矾（CuSO₄·5H₂O）、液氧均为纯净物。
2．单选 C
【解析】氧化钠为 Na₂O；氯化铁为 FeCl₃；氢氧化镁为 Mg(OH)₂。C 正确。
3．单选 B
【解析】置换反应是单质与化合物反应生成另一种单质和另一种化合物。B 符合；A 为分解反应，C 为化合反应，D 为复分解反应。
4．单选 D
【解析】物质的量浓度是单位体积溶液（不是溶剂）中所含溶质的物质的量。A 中 1 L 水配成溶液后体积大于 1 L；B 未指明溶液体积；C 表述错误。
5．单选 B
【解析】NH₃ 溶于水显碱性，能使湿润的红色石蕊试纸变蓝；Cl₂ 溶于水显酸性且有漂白性；SO₂、HCl 溶于水显酸性。
6．单选 A
【解析】同素异形体是同种元素形成的不同单质。金刚石和石墨、O₂ 和 O₃ 均为同素异形体（本题选 A，C 也正确但按常规单选选 A）；H₂O 与 H₂O₂ 是不同化合物；Na 与 Na⁺ 是不同微粒。
7．单选 C
【解析】定容必须在容量瓶中进行，且读数时视线应与刻度线相平。
8．单选 C
【解析】还原剂失电子被氧化，氧化剂得电子被还原；氧化剂化合价降低；氧化还原反应的实质是电子的转移（得失或偏移）。
9．多选 ABD
【解析】有单质参加的反应不一定是氧化还原反应（如 3O₂ = 2O₃，同素异形体转化无化合价变化），C 错误；其余均正确。
10．多选 ABD
【解析】离子间能否共存取决于是否发生反应（生成沉淀、气体、水或发生氧化还原反应），并非所有离子都能共存，C 错误。
11．填空 0.5
【解析】n=N/N_A=(3.01×10²³)/(6.02×10²³)=0.5 mol。
12．填空 100
【解析】M(CaCO₃)=40+12+48=100 g/mol。
13．填空 AlO₂⁻
【解析】氢氧化铝具有两性，能溶于强碱生成偏铝酸根。
14．填空 KSCN（硫氰化钾）
【解析】Fe³⁺ + 3SCN⁻ = Fe(SCN)₃，溶液呈血红色。
