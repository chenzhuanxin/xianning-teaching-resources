1． C
【解析】内能与温度、质量、状态有关；热量是过程量，不能说「含有」。
2． B
【解析】比热容是物质的特性，与质量、热量、温度变化无关。
3． C
【解析】压缩冲程机械能→内能，做功冲程内能→机械能。
4． B
【解析】规定正电荷定向移动的方向为电流方向。
5． C
【解析】电阻由导体本身决定，与 U、I 无关。
6． B
【解析】开关接火线，断开时灯不带电，更安全。
7． C
【解析】P = UI = 220 × 5 = 1100 W。
8． B
【解析】电磁感应现象由法拉第发现，是发电机的原理。

【解析】串联电路中电流处处相等。
