1．单选 B
【解析】铁生锈生成新物质氧化铁，属化学变化；其余三项均为物理变化。
2．单选 A
【解析】标准状况下气体摩尔体积约为 22.4 L/mol，只适用于气体；若不指明标准状况，则 22.4 L 不一定是 1 mol；气体摩尔体积随温度、压强变化。
3．单选 B
【解析】铁与氯气反应生成 FeCl₃ 而非 FeCl₂，故 FeCl₂ 不能由单质直接化合制得。
4．单选 B
【解析】2Na₂O₂ + 2H₂O = 4NaOH + O₂↑，故产物为 NaOH 和 O₂。
5．单选 A
【解析】HCl 是强酸完全电离；HClO 是弱酸部分电离；纯水中 c(H⁺)=10⁻⁷ mol/L；NaCl 溶液近中性。故 A 最大。
6．单选 B
【解析】n=m/M=23/23=1 mol。
7．单选 A
【解析】A 中水中 H 由+1→0，得电子被还原，水作氧化剂；B、C 是非氧化还原反应；D 中水既作氧化剂又作还原剂。
8．单选 C
【解析】氯气是黄绿色有刺激性气味的气体；其密度比空气大，应用向上排空气法收集；Cl₂ + H₂O = HCl + HClO；干燥氯气无漂白性，起漂白作用的是 HClO。
9．多选 ABD
【解析】有单质参加的反应不一定是氧化还原反应（如 3O₂ = 2O₃，同素异形体转化无化合价变化），C 错误；其余均正确。
10．多选 ABD
【解析】离子间能否共存取决于是否发生反应（生成沉淀、气体、水或发生氧化还原反应），并非所有离子都能共存，C 错误。
11．填空 16
【解析】m=nM=0.5×32=16 g。
12．填空 2
【解析】n=V/Vm=44.8/22.4=2 mol。
13．填空 纯碱（苏打）
【解析】Na₂CO₃ 俗称纯碱或苏打，NaHCO₃ 俗称小苏打。
14．填空 HClO
【解析】生成盐酸和次氯酸，次氯酸具有漂白性。
15．简答 （1）n=cV=0.4×0.25=0.1 mol，m=nM=0.1×58.5=5.85 g，需称取 5.85 g NaCl。 （2）计算 → 称量 → 溶解（并冷却至室温）→ 转移（至 250 mL 容量瓶）→ 洗涤（烧杯和玻璃棒 2~3 次）→ 定容（加水至刻度线，视线平视）→ 摇匀 → 装瓶贴标签。
【解析】注意：①容量瓶规格要与所配溶液体积一致；②转移前必须冷却；③定容时视线必须与刻度线相平。
16．计算 （1）Fe + 2HCl = FeCl₂ + H₂↑ （2）n(Fe)=m/M=5.6/56=0.1 mol （3）由方程式可知 n(H₂)=n(Fe)=0.1 mol，V(H₂)=nVm=0.1×22.4=2.24 L
【解析】铁与稀盐酸反应生成 Fe²⁺，物质的量之比为 1∶1。
17．计算 （1）2Na₂O₂ + 2H₂O = 4NaOH + O₂↑ （2）n(O₂)=V/Vm=2.24/22.4=0.1 mol （3）由方程式可知 n(Na₂O₂)=2n(O₂)=0.2 mol，m(Na₂O₂)=nM=0.2×78=15.6 g
【解析】化学计量数与物质的量成正比关系是解题关键。
