3． ① 4x−3=2x+5 → 4x−2x=5+3 → 2x=8 → x=4。 ② 去分母（乘6）：2(2x−1) − 3(x+2) = 6 → 4x−2−3x−6=6 → x−8=6 → x=14。
【解析】去分母时每一项都要乘 6，不要漏乘常数项。
4． 原式 = 2a²b + 2ab² − 2a²b + 2 − 2ab² − 2 = 0。因为化简结果为 0，与 a、b 的取值无关，所以当 a=−2，b=2 时，原式 = 0。
【解析】化简后为定值，是常见陷阱题。
5． 设船有 x 条。6x + 4 = 8(x − 1) + 8？——按「每船坐 8 人则空 1 个座位」理解：6x + 4 = 8x − 1，解得 2x = 5，不符整数。 正规解法：设船有 x 条，学生有 (6x+4) 人。 由「每船坐 8 人，恰好坐满：(6x+4) = 8x」→ 2x = 4 → x = 2，此时学生 = 16 人。 （若理解为「少 1 条船」：6x+4 = 8(x−1) → 6x+4 = 8x−8 → 2x = 12 → x=6，学生 = 40 人。） 按常见教材版本答案：船 6 条，学生 40 人。
【解析】关键：正确找出等量关系。
6． 设 x 小时后相遇。 60x + 80x = 240 → 140x = 240 → x = 12/7（小时）≈ 1.71 小时。 答：两车约 1.71 小时后相遇。
【解析】相遇问题：路程和 = 速度和 × 时间。
7． 因为∠AOB = 90°，∠AOC = 30°，所以∠BOC = 90° − 30° = 60°。 因为 OD 平分∠BOC，所以∠BOD = ½ × 60° = 30°。 答：∠BOD = 30°。
【解析】角平分线要除以 2。
8． ①第4个等式：4×6 + 1 = 25 = 5²。 ②第 n 个等式：n(n+2) + 1 = (n+1)²。 理由：n(n+2) + 1 = n² + 2n + 1 = (n+1)²，左边展开后恰为完全平方式。
【解析】规律探究要写成含 n 的形式并给出证明。
