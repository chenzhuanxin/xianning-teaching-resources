1． B
【解析】由第②段「情与景的交融、意与象的统一」可知B项正确。A项「只是技巧」曲解文意；C项「只要……就一定」绝对化；D项与第④段「读者并非被动接受」矛盾。
2． D
【解析】文章第①段指出意境「并非单纯指景物描写」，但从未否定外在景物的作用，D项无中生有。
3． C
【解析】第④段明确肯定读者的「再创造」，C项「属于误读，应予纠正」与原文相悖。
4． B
【解析】文末「细节是通往人物内心的窄门」，故「窄门」喻指通往人物内心的细节。
5． ①以极简的动作描写，生动刻画了林黛玉初入贾府时小心谨慎、敏感多思的性格；②为后文表现其寄人篱下的处境作铺垫；③作为例证，支撑了「好的细节是性格的外化」这一观点。
6． ①细节不是事实的罗列，而应服务于人物性格的塑造；②好的细节能让读者在不知不觉中完成对人物的理解，具有以少胜多的效果；③如林黛玉「不肯多说一句话」的细节，胜过千言万语的介绍；④写小说、读小说都应在细节处用力与停留。
7． C
【解析】时间的物理长度不随年龄而变，变化的是人对时间的主观感受，C项表述错误。
8． ①人对时间的感受随年龄变化，少年觉得漫长，成年觉得飞快；②原因在于「时间比率」不同——同样一年在生命中所占比例随年龄增长而减小；③这是心理感受而非时间本身的变化。
9． ①从主观感受看，童年的每一天因占比大而显得漫长珍贵，成年的每一天因占比小而显得仓促；②这提示我们要意识到时间的相对价值；③正因为生命两端每一天的分量不同，更应珍惜当下、不虚度光阴。
10． C
【解析】「彰」在此处意为「清楚、明显」，「而闻者彰」是说听的人听得更清楚，不是「表彰」。
11． D
【解析】A项前「于」为「从」，后「于」为「比」；B项前「而」表递进，后「而」表转折；C项前「之」为代词，后「之」为助词；D项两个「者」均为代词，指「……的人」，用法相同。
12． （1）君子广泛地学习并且每天检验反省自己，就能智慧明达而行为没有过错了。（关键词：博学、日、参省、知明） （2）君子的天性同一般人没有差别，只是善于借助外物罢了。（关键词：生、异、假、于物）
13． 示例一：用「青，取之于蓝，而青于蓝」比喻学习可以提高自己，说明学习不可停止。示例二：用「木受绳则直，金就砺则利」比喻人经过学习与自省才能成为有用之才。作用：以常见事物设喻，使抽象的道理具体形象、通俗易懂，增强了说服力。
14． B
【解析】「怅」在此并非惆怅失落，而是由眼前壮景引发深思的慨叹，与下文的发问相呼应，表现的是诗人对国家命运的关切与思考，B项理解有误。
15． ①「击」字写出雄鹰振翅遒劲有力地拍击长空的矫健姿态；②「翔」字本用于鸟，此处写鱼在清澈江水中自由轻快游动，化静为动，意境开阔；③二字分别突出鹰与鱼的动态特征，表现了万物竞自由的蓬勃生机，寄托了作者昂扬向上的革命豪情。
16． 见对应套卷默写答案（按原文填写作答，注意「跬」「镂」「跂」「舆」等字书写正确）。
17． A
【解析】①「泰然自若」形容遇事镇定，「置若罔闻」指不加理睬，与「从容不迫」搭配应为「泰然自若」；②与「结构」搭配应为「严谨」；③「锲而不舍」强调坚持不懈，符合「钻研二十年」的语境。
18． C
【解析】A项滥用介词导致主语残缺；B项两面对一面；D项否定不当，「防止……不再发生」应删去「不」。
19． ①若只读书而不求其意（读而不思）　②若读而能思、能悟其意（思而能悟）
【解析】①处与「则如入宝山而空手归」对应，应填「只读不思」之意；②处与「则能举一反三」对应，应填「读而能思」之意。注意字数限制。
20． 咸宁某中学组织高一学生开展博物馆研学活动，学生参观、听讲座并完成研究报告，该校将常态化开展此类活动。
【解析】须保留「谁」「做了什么」「结果」等关键信息，不得遗漏「常态化」这一要点。
21． 示例：梦想是一盏灯，燃着信念，在长夜里照出前行的方向。
【解析】要求句式一致（「…是一…，…着…，在…里…」）、使用比喻、语意连贯。
