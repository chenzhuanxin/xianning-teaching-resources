1． C
【解析】等腰三角形是轴对称图形，对称轴是顶角平分线（底边中线）所在直线。
2． C
【解析】三角形任意两边之和大于第三边。3+4=7>5，满足；A项1+2=3不满足；B项2+3=5<6不满足；D项4+5=9<10不满足。
3． A
【解析】同底数幂相乘，底数不变，指数相加：a³·a² = a⁵。
4． B
【解析】分式的分母中必须含有字母。2/x 的分母含字母 x，是分式；其余选项分母不含字母。
5． A
【解析】关于 x 轴对称，横坐标不变，纵坐标互为相反数：(2, −3) → (2, 3)。
6． C
【解析】(n−2)×180° = 720°，n−2 = 4，n = 6。
7． B
【解析】(a−b)² = a² − 2ab + b²。A项漏掉了2ab；C项应为 a² − b²；D项(2a)² = 4a²。
8． D
【解析】△ABD 与△ACD 已具备 AD = AD（公共边）、∠1 = ∠2（夹角）。A项 AB=AC，满足SAS；B项∠B=∠C，满足AAS；C项 BD=CD，满足SSS；D项添加∠ADB=∠ADC实际上会导致 $\angle ADB + \angle ADC = 180°$ 与三角形内角矛盾（会使B、D、C三点共线），不是有效条件。故选D。
9． C
【解析】(2x+2y)/(2x·2y) = 2(x+y)/(4xy) = (x+y)/(2xy)，是原式的 1/2。
10． C
【解析】AB = AC，∠B = ∠C = (180° − 40°) ÷ 2 = 70°。
11． −8a⁶b³
【解析】(−2)³ = −8，(a²)³ = a⁶，b³ = b³，故结果为 −8a⁶b³。
12． 1
【解析】分式的值为0，则分子为0且分母不为0：x − 1 = 0，x = 1，此时 x + 2 = 3 ≠ 0，符合。
13． (x+3)(x−3)
【解析】平方差公式 a² − b² = (a+b)(a−b)。
14． 80°或20°
【解析】外角为100°，则相邻内角为80°。若80°是顶角，则顶角为80°；若80°是底角，则顶角为180°−80°×2 = 20°。故顶角为80°或20°。
15． 5
【解析】关于 y 轴对称，纵坐标不变，横坐标互为相反数：a = 2，b = 3，a + b = 5。
16． 90°
【解析】设三角分别为 x、2x、3x，x + 2x + 3x = 180°，x = 30°，∠C = 3x = 90°。
17． 13
【解析】x² + y² = (x+y)² − 2xy = 25 − 12 = 13。
18． 3
【解析】角平分线上的点到角两边的距离相等，故点 D 到 AB 的距离等于 CD = 3。
19． （1）3a² − 12 = 3(a² − 4) = 3(a+2)(a−2) （2）x³ − 2x² + x = x(x² − 2x + 1) = x(x−1)²
【解析】评分：每题4分，提取公因式2分，彻底分解2分。
20． （1）(2x+3y)(2x−3y) = (2x)² − (3y)² = 4x² − 9y² （2）(a+2b)² − a(a+4b) = a² + 4ab + 4b² − a² − 4ab = 4b²
【解析】评分：每题4分。
21． 方程两边同乘 x(x−2)：2x = 3(x−2) 解得 2x = 3x − 6，x = 6 检验：当 x = 6 时，x(x−2) = 6×4 = 24 ≠ 0 所以 x = 6 是原方程的解。
【解析】评分：去分母3分，求解3分，检验2分。
22． 原式 = a/(a−1) ÷ a/[(a+1)(a−1)] = a/(a−1) × [(a+1)(a−1)]/a = a + 1 当 a = 3 时，原式 = 3 + 1 = 4。
【解析】评分：化简5分，求值3分。
23． 因为 BE = CF，所以 BE + EC = CF + EC，即 BC = EF。 在△ABC 和△DEF 中， AB = DE（已知），AC = DF（已知），BC = EF（已证）， 所以△ABC ≌ △DEF（SSS）。
【解析】评分：证 BC = EF 得4分，全等判定6分。
24． （1）因为 DE ⊥ AB，DF ⊥ AC，所以∠DEB = ∠DFC = 90°。 又 AB = AC，所以∠B = ∠C。 在△BDE 和△CDF 中，∠DEB = ∠DFC，∠B = ∠C，DE = DF， 所以△BDE ≌ △CDF（AAS），所以 BD = CD。 （2）因为 BD = CD，AB = AC，AD = AD， 所以△ABD ≌ △ACD（SSS），所以∠BAD = ∠CAD， 即 AD 平分∠BAC。
【解析】评分：第（1）问6分，第（2）问6分，证法合理即可。
25． 设第一次购进文具的单价为 x 元，则第一次购进数量为 2400/x 个。 第二次单价为 (x + 5) 元，数量为 2400/(x+5) 个。 根据题意：2400/x − 2400/(x+5) = 20 解得：2400(x+5) − 2400x = 20x(x+5) 12000 = 20x² + 100x x² + 5x − 600 = 0 (x + 25)(x − 24) = 0，x = 24 或 x = −25（舍去） 经检验 x = 24 符合题意。 答：第一次购进文具的单价为24元。
【解析】评分：设未知数2分，列方程4分，求解3分，检验作答3分。
