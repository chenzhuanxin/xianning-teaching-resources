1． 原式 = −8 ÷ 4 − (1/4) × 8 = −2 − 2 = −4。
【解析】注意 (−1/2)² = 1/4。
2． 原式 = 3x² − 2x + 4x² − 3x = 7x² − 5x。 当 x = −1 时，7×(−1)² − 5×(−1) = 7 + 5 = 12。
【解析】去括号注意变号（括号前是负号）。
3． ① 2x + 6 = 5x − 3 → 2x − 5x = −3 − 6 → −3x = −9 → x = 3。 ② 去分母（乘12）：4(2x−1) = 3(x+2) − 12 → 8x − 4 = 3x + 6 − 12 → 8x − 3x = −6 + 4 → 5x = −2 → x = −2/5。
【解析】去分母时每一项都要乘最小公倍数，注意常数 1 要乘。
4． 3x + 2y = 12 ①，2x − 3y = −5 ②。 ①×3：9x + 6y = 36 ③；②×2：4x − 6y = −10 ④。 ③+④：13x = 26 → x = 2，代入①：6 + 2y = 12 → y = 3。 所以 x = 2, y = 3。
【解析】加减消元要选择系数的最小公倍数。
5． 由 2x − 1 > 3 得 x > 2；由 x − 2 ≤ 3 得 x ≤ 5。 所以解集为 2 < x ≤ 5。数轴上 2 处空心圈、5 处实心点。
【解析】「大大取大，小小取小」不适用时取公共部分。
6． 设 x 秒后甲第一次追上乙。 甲比乙多跑一圈：6x − 4x = 400 → 2x = 400 → x = 200。 答：200 秒后甲第一次追上乙。
【解析】同向追及：路程差 = 一圈。
7． 因为 OD 平分∠AOB，OE 平分∠BOC， 所以 ∠DOB = ½∠AOB，∠BOE = ½∠BOC。 ∠DOE = ∠DOB + ∠BOE = ½(∠AOB + ∠BOC) = ½∠AOC = ½ × 90° = 45°。 答：∠DOE = 45°。
【解析】注意 ∠DOE = ½∠AOC 的推导。
8． 设原计划租用 45 座客车 x 辆，则学生人数为 45x + 15。 租用 60 座客车时多出一辆，即用 (x − 1) 辆恰好坐满：60(x − 1) = 45x + 15。 60x − 60 = 45x + 15 → 15x = 75 → x = 5。 学生人数 = 45×5 + 15 = 240（人）。 答：学生 240 人，原计划租用 45 座客车 5 辆。
【解析】两种方案下学生人数不变是等量关系。
