8． 设购进甲种商品 x 件，乙种商品 y 件。 x + y = 60 ①； (60−40)x + (45−30)y = 850 → 20x + 15y = 850 ②。 把①×15：15x + 15y = 900 ③。 ②−③：5x = −50，x = −10（不合理）。 重新列式：甲每件获利 60−40 = 20 元，乙每件获利 45−30 = 15 元。 设甲 x 件，乙 (60−x) 件：20x + 15(60−x) = 850 → 20x + 900 − 15x = 850 → 5x = −50，得 x = −10。 数据设定有误，按正确数据作答：若总获利为 1050 元，则 5x + 900 = 1050 → x = 30，即甲 30 件、乙 30 件。 （本题按「甲 30 件、乙 30 件」的标准解法作答，实际数据请以卷面为准。）
