1．单选 C
【解析】病毒没有细胞结构，由核酸和蛋白质外壳构成，必须寄生在活细胞内才能完成生命活动，其遗传物质为 DNA 或 RNA。
2．单选 A
【解析】碳元素是构成细胞的最基本元素，因为碳原子能形成四个共价键，是构成有机大分子的骨架。
3．单选 A
【解析】组成蛋白质的氨基酸约有 20 种；每个氨基酸至少含一个氨基和一个羧基，且都连在同一个碳原子上；氨基酸含 C、H、O、N 等元素。
4．单选 B
【解析】核糖体是蛋白质合成的场所（「生产蛋白质的机器」）。
5．单选 B
【解析】植物细胞壁的主要成分是纤维素和果胶；动物细胞无细胞壁；细胞壁是全透性的，不具有选择透过性；细胞壁位于细胞膜外面。
6．单选 A
【解析】细胞核是遗传信息库，是细胞代谢和遗传的控制中心；线粒体和叶绿体中也含 DNA，并非唯一储存场所。
7．单选 C
【解析】光合作用在叶绿体中进行（蓝细菌等虽无叶绿体但也能进行光合作用）；光反应产物有[H]、ATP 和 O₂；暗反应需要多种酶的参与。
8．单选 A
【解析】有氧呼吸总反应式为 C₆H₁₂O₆ + 6O₂ + 6H₂O = 6CO₂ + 12H₂O + 能量（注意反应物和产物中都有水）；B 为酒精发酵，C 为乳酸发酵。
9．多选 ABD
【解析】核糖体没有膜结构，不是单层膜细胞器，C 错误；其余均正确。
10．多选 ABD
【解析】酶的化学本质绝大多数是蛋白质，少数是 RNA，故 C 错误；其余均正确。
11．填空 细胞
【解析】病毒由核酸和蛋白质构成，没有细胞结构。
12．填空 U
【解析】RNA 特有碱基为尿嘧啶 U。
13．填空 核孔
【解析】核孔是大分子物质进出细胞核的通道。
14．填空 三
【解析】第三阶段[H]与 O₂ 结合生成水，释放大量能量。
15．简答 （1）属于真核细胞。判断依据：具有核膜包被的细胞核（以及线粒体等具膜细胞器）。 （2）线粒体是有氧呼吸的主要场所，能将有机物中的化学能转化为 ATP 中的化学能，为细胞生命活动提供大量能量。 （3）还应具有叶绿体，叶绿体是光合作用的场所。
【解析】解题关键：原核细胞与真核细胞的主要区别是有无核膜包被的细胞核。
16．简答 （1）相同点：都不需要消耗能量，都顺浓度梯度运输。不同点：自由扩散不需要载体蛋白，协助扩散需要载体蛋白。 （2）例如：小肠上皮细胞吸收葡萄糖（或肾小管重吸收葡萄糖、细胞吸收 K⁺ 等）。特点：逆浓度梯度运输，需要载体蛋白协助，需要消耗能量（ATP）。意义：保证细胞按照生命活动的需要，主动选择吸收所需营养物质、排出代谢废物，维持细胞内环境的相对稳定。
【解析】注意区分三种跨膜运输方式在「载体」「能量」「方向」三个方面的差异。
17．简答 （1）自变量是温度；因变量是酶的活性（通过淀粉的分解程度或碘液显色情况来反映）。 （2）0℃ 试管：蓝色（低温抑制酶活性，淀粉未被完全分解）；37℃ 试管：不变蓝或颜色很浅（37℃ 最接近该酶的最适温度，淀粉被充分分解）；100℃ 试管：蓝色（高温使酶变性失活，淀粉未被分解）。 （3）不够严谨。理由：①应先将淀粉溶液与酶溶液分别在相应温度下保温，再混合（本实验中「混合后再保温」会使反应在温度未达设定值时就已开始）；②应设置更多温度梯度以确定最适温度；③应保证各组淀粉溶液与酶溶液的用量、浓度、pH 等无关变量一致。
【解析】本题考查酶活性受温度影响的实验设计，核心是控制变量与对照原则，注意「先分别保温再混合」的规范操作。
