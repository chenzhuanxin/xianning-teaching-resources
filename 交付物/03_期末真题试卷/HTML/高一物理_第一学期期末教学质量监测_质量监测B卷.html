1．单选 C
【解析】位移是矢量、路程是标量；位移大小是首末位置间的直线距离，路程是实际路径长度，故位移大小不可能大于路程。
2．单选 C
【解析】速度是矢量，平均速度等于位移除以时间；瞬时速度方向即该时刻运动方向；速率是速度的大小，不会「大于」速度。
3．单选 C
【解析】v=v₀+at=0+2×3=6 m/s。
4．单选 C
【解析】摩擦力可以是动力（如传送带上加速的物体）；滑动摩擦力方向与相对运动方向相反，不一定与运动方向相反；静止物体也可能受静摩擦力。
5．单选 C
【解析】匀速圆周运动中速度方向时刻改变、加速度大小不变且方向始终指向圆心，合外力提供向心力，不为零，不是匀速运动。
6．单选 C
【解析】万有引力定律适用于任何两质点之间；引力与距离平方成反比、与质量乘积成正比；引力常量 G 由卡文迪什通过扭秤实验测出。
7．单选 C
【解析】ΔEk=½mv²−0=½×2×16=16 J。
8．单选 B
【解析】压力与重力性质不同、施力物体不同；物体所受重力与支持力作用于同一物体、大小相等方向相反，是一对平衡力；压力与支持力是作用力与反作用力；压力由物体形变产生。
9．多选 ABD
【解析】作用力与反作用力分别作用在两个不同物体上，不能相互抵消，C 错误；其余均正确。
10．多选 ABC
【解析】动能不变时机械能可能改变（如物体沿斜面匀速下滑，动能不变而重力势能减少，机械能不守恒），D 错误。
11．填空 45
【解析】h=½gt²=½×10×9=45 m。
12．填空 50
【解析】ΔEk=½mv²=½×4×25=50 J。
13．填空 6√2
【解析】F合=√(6²+6²)=6√2 N。
14．填空 5
【解析】匀速运动合力为零，f=F=5 N。
15．计算 （1）v=v₀+at=0+2×5=10 m/s （2）s=v₀t+½at²=0+½×2×25=25 m
【解析】匀加速直线运动公式的直接应用。注意初速度为零。
16．计算 （1）f=μN=μmg=0.2×2×10=4 N （2）由牛顿第二定律 F−f=ma 得 a=(10−4)/2=3 m/s² （3）v=at=3×3=9 m/s
【解析】先受力分析求合力，再由牛顿第二定律求加速度，最后用运动学公式求速度。
17．计算 （1）由 v²=2gh 得 v=√(2×10×5)=10 m/s （2）Ek=½mv²=½×1×100=50 J （3）由机械能守恒，上升高度 h′=Ek/(mg)=50/(1×10)=5 m
【解析】自由落体与竖直上抛均可由机械能守恒求解，注意能量守恒的对称性。
