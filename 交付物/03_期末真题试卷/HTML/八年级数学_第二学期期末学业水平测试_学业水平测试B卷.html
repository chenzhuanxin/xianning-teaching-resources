2． B
【解析】3² + 4² = 9 + 16 = 25 = 5²，能构成直角三角形。
3． B
【解析】k = −2 < 0，图象下降；b = 3 > 0，与 y 轴交于正半轴，故经过第一、二、四象限。
4． B
【解析】平行四边形对角相等，∠C = ∠A = 60°。
5． A
【解析】排序后为 2，3，3，5，7，中位数为3；3出现2次，次数最多，众数为3。
6． B
【解析】菱形面积 = 对角线乘积的一半 = 6×8÷2 = 24。
7． B
【解析】k < 0 时，y 随 x 的增大而减小。
8． C
【解析】对角线互相垂直且平分的四边形是菱形。
9． C
【解析】√(a²) = |a|，所以√(a−2)² = |a−2|。
10． A
【解析】方差越小，成绩越稳定。0.4 < 1.2，所以甲的成绩更稳定。
11． x ≥ 3
【解析】二次根式的被开方数非负：x − 3 ≥ 0，x ≥ 3。
12． √2

20． （1）设 y = kx + b。将 A(1,3)、B(−1,−1) 代入： k + b = 3，−k + b = −1。解得 k = 2，b = 1。 所以 y = 2x + 1。 （2）当 x = 2 时，y = 2×2 + 1 = 5，所以点 C(2,5) 在该函数图象上。
【解析】评分：（1）6分；（2）2分。
21． AB = √(AC² + BC²) = √(9 + 16) = 5。 因为 S△ABC = 1/2 AC·BC = 1/2 AB·CD， 所以 3×4 = 5×CD，CD = 2.4。 答：AB = 5，CD = 2.4。
【解析】评分：求AB得4分，求CD得4分。
22． 因为四边形 ABCD 是平行四边形，所以 AD ∥ BC，AD = BC。 又 AE = CF，所以 AD − AE = BC − CF，即 ED = BF。 因为 ED ∥ BF 且 ED = BF， 所以四边形 BEDF 是平行四边形（一组对边平行且相等的四边形是平行四边形）。
【解析】评分：得出 ED = BF 得5分，判定得5分。
23． （1）20个数据总和 = 3750，平均数 = 3750 ÷ 20 = 187.5（cm）。 排序后第10、11个数据均为190，中位数 = 190（cm）。 190出现7次，次数最多，众数 = 190（cm）。 （2）成绩在190cm及以上的有 7 + 2 = 9 人，占 9/20 = 45%。 估计全校人数为 400 × 45% = 180（人）。 答：估计约有180名学生成绩在190cm及以上。
【解析】评分：（1）每个统计量2分；（2）4分。
24． 因为 AD 是 BC 边上的中线，所以 BD = CD。 又 AD = BD，所以 AD = BD = CD。 在△ABD中，因为 AD = BD，所以∠B = ∠BAD。 在△ACD中，因为 AD = CD，所以∠C = ∠CAD。 因为∠B + ∠C + ∠BAC = 180°， 所以 ∠BAD + ∠CAD + ∠BAC = 180°， 即 2∠BAC = 180°，∠BAC = 90°。 所以△ABC 是直角三角形。
【解析】评分：推出 AD = BD = CD 得4分，利用等腰三角形性质得4分，得出结论3分。
25． （1）日销量 y = 200 − 10(x − 40) = 600 − 10x（40 ≤ x ≤ 60）。 （2）依题意利润 = (x − 30)(600 − 10x) = 2240。 整理得：(x − 30)(60 − x) = 224， 即 −x² + 90x − 1800 = 224， x² − 90x + 2024 = 0， (x − 44)(x − 46) = 0，解得 x = 44 或 x = 46。 检验知二者均满足 40 ≤ x ≤ 60。 答：售价应定为44元或46元。
【解析】评分：（1）4分；（2）列式3分、求解3分、作答1分。
