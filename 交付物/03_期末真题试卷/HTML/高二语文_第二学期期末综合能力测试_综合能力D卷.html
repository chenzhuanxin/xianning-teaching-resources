1． B
【解析】由第③段「经典的另一特征是其『可争议性』」可知 B 正确；A 与第②段矛盾；C 表述绝对；D 与第④段相悖。
2． C
【解析】文章第④段恰恰强调「在这个信息爆炸的时代，阅读经典的意义或许更加凸显」，C 项与原文相悖。
3． D
【解析】第④段指出信息爆炸时代经典「意义或许更加凸显」，D 项结论与之相反。
4． B
【解析】第③段父亲的沉默，更多体现的是他不愿辩解、只想让儿子亲口尝一尝的心情，而非「无奈」，B 项理解不当。
5． ①以「酸得厉害、不如菜市场的好吃」写实，看似否定，实则为下文「笑得开心」作铺垫；②形成反差，突出父亲种菜的目的不在「好吃」，而在被需要、被认可；③为末段点明主旨蓄势，使情感转折更有力量。
6． ①父亲退休后失去了工作的角色，通过种菜重新获得了被需要的价值感；②「种菜」是父亲重新确认自身意义的方式；③这句话既表达了儿子的理解与体恤，也寄托了对父亲晚年情感需求的关注；④深化主旨，由物及人，由事及情。
7． D
【解析】借景是借园外景物入园以扩境界，并非把景物真的移入园中，D 项理解有误。
8． ①讲究「虽由人作，宛自天开」，追求自然与变化，不追求对称规整；②景物之间相互生发，构成整体；③善于借景，使有限空间获得无限感；④以与自然相融而非征服自然为根本思想。
9． ①在城市建设中应尊重自然、顺应自然，保留自然肌理与生态廊道；②在资源开发中应避免掠夺式索取，讲求可持续；③在生活方式上倡导节制与和谐，追求人与自然共生共荣；④这一思想与当今生态文明理念高度契合。
10． C
【解析】「彰」在此意为「清楚、明显」，「而闻者彰」指听的人听得更清楚，非「表彰」。
11． D
【解析】A 项前「于」为「从」，后「于」为「比」；B 项前「而」表递进，后「而」表转折；C 项前「之」为代词，后「之」为助词；D 项两个「者」均为代词，用法相同。
12． （1）所以不积累每一小步，就没有办法到达千里之外；不汇集细小的水流，就没有办法形成江海。（关键词：跬步、无以、至） （2）雕刻一下就放弃，即使朽木也不会折断；不停地雕刻下去，金石也能雕出花纹。（关键词：锲、舍、镂）
13． 示例一：以「青，取之于蓝，而青于蓝」比喻学习可以使人超越原有水平；示例二：以「锲而不舍，金石可镂」比喻坚持不懈必能成功。作用：将抽象的道理寄寓在具体可感的事物中，使论证生动形象、深入浅出，增强了说服力与感染力。
14． D
【解析】「潦倒新停浊酒杯」是因穷困潦倒、身患疾病而不得不停下酒杯，并非「彻底戒酒、心情愉悦」，反而更显悲苦，D 项理解错误。
15． ①「无边」「不尽」分别从空间与时间的维度落笔，境界极其阔大；②「萧萧」「滚滚」为叠词，摹声摹态，使落叶与江水的形象更加真切可感；③落木萧条象征生命衰颓，长江奔涌象征时间永恒，二者对照，寄寓了诗人深沉的身世之感与忧国之情；④对仗工整，气势磅礴，为全诗名句。
16． 见对应套卷默写答案（按原文填写作答，注意「跬」「镂」「驽」「锲」等字书写正确）。
17． C
【解析】①「浅尝辄止」指略微尝试就停止，与「不求甚解，终无所获」相合；②「不以为意」指不把它放在心上，符合「坚持自己判断」的语境（「不以为然」是不认为对，语气过重）；③「同舟共济」比喻同心协力共渡难关，符合「共同完成著作」的语境。
18． C
【解析】A 项滥用介词致主语残缺；B 项两面对一面；D 项否定不当，应删「不」。
19． ①只有沉下心来（慢慢读）　②只有反复阅读（多次重读）
【解析】①处承接「需要一种『慢』的心态」，应填「沉下心来慢慢读」之意；②处承接「在反复阅读中不断获得新的理解」，应填「反复重读」之意。注意字数限制。
20． 某中学举办为期两周的经典诵读活动，学生诵读经典篇目并参与读书分享、情景剧表演等，广受好评。
【解析】须保留「谁」「做什么」「持续多久」「形式」「反响」等关键信息。
21． 示例：阅读是一盏灯，越往深处走，越能照亮之前看不见的角落。
【解析】要求句式一致（「…是一…，越…，越…」）、使用比喻、语意连贯。
22． 【立意参考】 ①在快时代保持慢的能力，是一种清醒与定力；②积累是成长的必经之路，快与慢应当辩证统一；③青年应拒绝浮躁，沉心沉淀，厚积薄发；④把个人成长置于国家发展的宏大叙事中思考。 【评分要点】一等（52—60）：立意深刻，结构严谨，材料丰富，语言有文采；二等（42—51）：中心明确，结构完整，语言通顺；三等（30—41）：中心基本明确，内容较单薄；四等（29分以下）：偏离题意或文体不明。 【提醒】须自拟标题，不少于800字，不得套作抄袭。
