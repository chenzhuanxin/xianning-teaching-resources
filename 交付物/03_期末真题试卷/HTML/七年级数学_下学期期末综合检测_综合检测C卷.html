1． 因为 1 < √2，所以 |1 − √2| = √2 − 1。 原式 = (√2 − 1) + 2 + (−3) = √2 − 1 + 2 − 3 = √2 − 2。
【解析】绝对值的化简要判断正负。
2． ① x + 2y = 7 ①，2x − y = 4 ②。 由①得 x = 7 − 2y ③，代入②：2(7−2y) − y = 4 → 14 − 4y − y = 4 → −5y = −10 → y = 2，则 x = 3。 所以 x = 3, y = 2。 ② y = 2x − 1 ①，3x + 2y = 12 ②。 把①代入②：3x + 2(2x−1) = 12 → 3x + 4x − 2 = 12 → 7x = 14 → x = 2，则 y = 3。 所以 x = 2, y = 3。
【解析】消元法解题要写清步骤。
3． ① 3x − 5 < x + 1 → 3x − x < 1 + 5 → 2x < 6 → x < 3。数轴上 3 处画空心圈，向左画。 ② 由 x − 1 > 0 得 x > 1；由 2x + 1 ≤ 7 得 x ≤ 3。所以解集为 1 < x ≤ 3。数轴上 1 处空心圈、3 处实心点，中间部分。
【解析】不等式两边乘除负数要变号。
4． 因为 AB∥CD，所以 ∠1 = ∠2（两直线平行，内错角相等）？ 按同位角关系：∠1 与 ∠3 是同位角，∠1 = ∠3 = 70°。 ∠1 与 ∠2 是同旁内角，∠2 = 180° − 70° = 110°。 ∠2 与 ∠4 是对顶角，∠4 = ∠2 = 110°。 答：∠2 = 110°，∠3 = 70°，∠4 = 110°。
【解析】要根据图中角的位置关系判断（同位角、内错角、同旁内角）。
5． ①按坐标描点连线，画出△ABC。 ②向右平移 3 个单位、再向下平移 2 个单位：横坐标加 3，纵坐标减 2。 A(1,2) → A′(4, 0)；B(−2,1) → B′(1, −1)；C(0,−1) → C′(3, −3)。 画出△A′B′C′（形状大小与△ABC 相同）。
【解析】平移规律：右加左减横坐标，上加下减纵坐标。
6． 设购买甲种奖品 x 件，乙种奖品 y 件。 x + y = 30，15x + 10y = 380。 由①得 y = 30 − x，代入②：15x + 10(30−x) = 380 → 15x + 300 − 10x = 380 → 5x = 80 → x = 16，则 y = 14。 答：甲种奖品 16 件，乙种奖品 14 件。
【解析】注意「件数」与「金额」两个等量关系。
7． ①篮球：20÷50×100% = 40%；足球：15÷50×100% = 30%；乒乓球：10÷50×100% = 20%；其他：5÷50×100% = 10%。（合计 100%） ②400 × 40% = 160（人）。 答：估计该校七年级喜欢篮球的约有 160 人。
【解析】用样本估计总体。
8． 证明：因为 CD⊥AB，EF⊥AB，所以 ∠CDB = ∠EFB = 90°， 所以 CD∥EF（同位角相等，两直线平行）。 所以 ∠2 = ∠BCD（两直线平行，同位角相等）。 又因为 ∠1 = ∠2，所以 ∠1 = ∠BCD， 所以 DG∥BC（内错角相等，两直线平行）。 所以 ∠AGD = ∠ACB（两直线平行，同位角相等）。 证毕。
【解析】几何证明要写清每一步的依据。
