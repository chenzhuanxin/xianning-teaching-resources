1． C
【解析】A项 a²·a³ = a⁵；B项 (a²)³ = a⁶；D项 (ab)² = a²b²；C项正确，a⁶ ÷ a² = a⁴。
2． D
【解析】7 − 3 = 4 < 第三边 < 7 + 3 = 10，故第三边长在4到10之间（不含端值），6符合。
3． C
【解析】(x+y)(−x−y) = −(x+y)²，是完全平方，不能用平方差公式。B项 (−x+y)(x+y) = (y−x)(y+x) = y² − x²，可以用。
4． C
【解析】x² + mx + 9 = x² + mx + 3²，是完全平方式则 m = ±2×3 = ±6。
5． C
【解析】两个锐角对应相等，只能说明两三角形相似，不能判定全等。A、B、D均能判定全等。
6． B
【解析】分子为0且分母不为0：|x| − 2 = 0 得 x = ±2，又 x − 2 ≠ 0 得 x ≠ 2，故 x = −2。
7． A
【解析】点 P(−1, 2) 到直线 x = 1 的距离为2，对称点在直线另一侧且距离为2，横坐标为 1 + 2 = 3，纵坐标不变，故对称点为 (3, 2)。
8． C
【解析】∠OBC + ∠OCB = 1/2(∠ABC + ∠ACB) = 1/2(180° − 80°) = 50°， ∠BOC = 180° − 50° = 130°。
9． A
【解析】(x+2)(x−3) = x² − x − 6，故 p = −1，q = −6。
10． A
【解析】延长 AD 到点 E 使 DE = AD，连接 BE，可证△ADC ≌ △EDB，得 BE = AC = 3。 在△ABE中，AB = 5，BE = 3，AE = 2AD。 由三边关系：5 − 3 < 2AD < 5 + 3，即 2 < 2AD < 8，得 1 < AD < 4。
11． x² − 9
【解析】平方差公式。
12． 2(a+2b)(a−2b)
【解析】先提取2，再用平方差公式。
13． 6
【解析】a^(m+n) = aᵐ · aⁿ = 2 × 3 = 6。
14． 80°
【解析】AB = AC，∠B = ∠C = 50°，∠A = 180° − 50° × 2 = 80°。
15． m = 3
【解析】增根是使分母为0的值，即 x = 3。去分母得 x = 2(x−3) + m，代入 x = 3：3 = 0 + m，m = 3。
16． 8
【解析】a² − b² = (a+b)(a−b) = 4 × 2 = 8。
17． x = 2
【解析】A、B 两点纵坐标相同，垂直平分线垂直于 AB 且过中点 (2, 2)，故为直线 x = 2。
18． 30°
【解析】等边三角形 ABC 中∠ABC = 60°，BD 是∠ABC 的平分线（三线合一），故∠ABD = 30°。

22． 因为∠BAC = ∠DAE，所以∠BAC − ∠DAC = ∠DAE − ∠DAC，即∠BAD = ∠CAE。 在△ABD 和△ACE 中， AB = AC，∠BAD = ∠CAE，AD = AE， 所以△ABD ≌ △ACE（SAS），所以 BD = CE。
【解析】评分：证角相等4分，全等判定4分，结论2分。
23． 因为 AD 平分∠BAC，∠C = 90°，DE ⊥ AB， 所以 DE = DC（角平分线上的点到角两边距离相等）。 因为 BC = 8，BD = 5，所以 DC = BC − BD = 8 − 5 = 3。 所以 DE = 3。

24． （1）因为 AB = AC，所以∠B = ∠C。 因为 DE ⊥ AB，DF ⊥ AC，所以∠DEB = ∠DFC = 90°。 因为 D 是 BC 的中点，所以 BD = CD。 在△BDE 和△CDF 中，∠DEB = ∠DFC，∠B = ∠C，BD = CD， 所以△BDE ≌ △CDF（AAS），所以 DE = DF。 （2）因为∠A = 60°，AB = AC，所以△ABC 是等边三角形。 在 Rt△BDE 中，∠B = 60°，∠DEB = 90°，DE = 2， 所以 BD = DE ÷ sin60° = 2 ÷ (√3/2) = 4√3/3。 所以 BC = 2BD = 8√3/3。 S△ABC = 1/2 × BC × AD，因为等边三角形的高 AD = (√3/2)BC = (√3/2)×(8√3/3) = 4。 所以 S△ABC = 1/2 × (8√3/3) × 4 = 16√3/3。
【解析】评分：（1）5分；（2）6分。
25． （1）生产A产品 x 件，则B产品 (100 − x) 件。 W = 200x + 150(100 − x) = 50x + 15000。 （2）依题意：x ≥ 1/3(100 − x) 且 x ≤ 60。 由 x ≥ 1/3(100 − x) 得 3x ≥ 100 − x，4x ≥ 100，x ≥ 25。 所以 25 ≤ x ≤ 60。 因为 W = 50x + 15000 中 k = 50 > 0，W 随 x 增大而增大， 所以当 x = 60 时，W 最大 = 50 × 60 + 15000 = 18000。 答：最大总利润为18000元。
【解析】评分：（1）4分；（2）取值范围4分、最大值3分。
