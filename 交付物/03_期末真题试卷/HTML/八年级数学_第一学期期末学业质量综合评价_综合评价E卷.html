2． B
【解析】腰长只能是5（若腰为2，则2+2=4<5不符合三边关系），周长 = 5+5+2 = 12。
3． B
【解析】(−x³)² = (−1)²(x³)² = x⁶。
4． B
【解析】因式分解是把一个多项式化为几个整式的积。A项是整式乘法，C项中 x(1 + 1/x) 不是整式积，D项结果不是积的形式。
5． A
【解析】分母不为零，x − 3 ≠ 0，即 x ≠ 3。
6． B
【解析】∠C = 180° − 50° − 60° = 70°，∠C 的外角 = 180° − 70° = 110°。
7． B
【解析】关于 x 轴对称，横坐标不变、纵坐标互为相反数：a = 3，b = 2，a + b = 5。
8． A
【解析】100°的角只能是顶角（底角为100°则两底角之和200°>180°不符合），底角 = (180° − 100°) ÷ 2 = 40°。
9． C
【解析】x² − kx + 16 = x² − kx + 4²，则 k = ±2×4 = ±8。
10． B
【解析】涨价后为 1.1a，再降价10%得 1.1a × 0.9 = 0.99a。
11． −6a³b³
【解析】(−3)×2 = −6，a²·a = a³，b·b² = b³。
12． a(a+2)(a−2)
【解析】先提取a，再用平方差公式。
13． 2
【解析】分子为0且分母不为0：x − 2 = 0，x = 2，此时 x + 1 = 3 ≠ 0。
14． 60°
【解析】∠B + ∠C = 180° − 80° = 100°，又∠B − ∠C = 20°，故∠B = (100° + 20°) ÷ 2 = 60°。
15． 45
【解析】3^(x+2) = 3ˣ × 3² = 5 × 9 = 45。
16． 6
【解析】若腰为4，则两腰和为8，底为8，4+4=8不满足三边关系，故腰长不能为4；若底为4，则两腰和 = 12，腰长 = 6，6+6>4满足。故腰长为6。
17． 4
【解析】x² − y² = (x+y)(x−y) = 12，又 x − y = 3，所以 x + y = 4。
18． 2
【解析】因为 DE 垂直平分 AB，所以 DA = DB = 4。 在 Rt△ABC 中，∠A = 30°，∠C = 90°，所以∠B = 60°。 在△ABD 中，DA = DB，∠A = 30°，则∠ABD = 30°，所以∠DBC = 60° − 30° = 30°。 在 Rt△BCD 中，∠DBC = 30°，DB = 4，所以 CD = 1/2 DB = 2。
