1．单选 D
【解析】氧化物是由两种元素组成且其中一种是氧元素的化合物。Fe₂O₃ 符合；O₂ 是单质；KClO₃、H₂SO₄ 含多种元素。
2．单选 B
【解析】摩尔质量单位是 g/mol；水的摩尔质量为 18 g/mol；1 mol O₂ 质量为 32 g；摩尔质量是物质的固有属性，与物质的量无关。
3．单选 A
【解析】A 既是化合反应（多种变一种）又是氧化还原反应（H、O 化合价变化）；B 是分解反应；C 是复分解反应；D 是置换反应。
4．单选 B
【解析】Na₂CO₃ 俗称纯碱或苏打，NaHCO₃ 俗称小苏打；2NaHCO₃ = Na₂CO₃ + H₂O + CO₂↑；NaHCO₃ 能与 NaOH 反应而 Na₂CO₃ 不能；相同浓度下 Na₂CO₃ 溶液碱性更强。
5．单选 B
【解析】Al(OH)₃ 是两性氢氧化物，既能与强酸反应又能与强碱反应；NaCl、CuSO₄ 与二者均不都反应；H₂SO₄ 只与碱反应。
6．单选 B
【解析】n=V/Vm=2.24/22.4=0.1 mol。
7．单选 C
【解析】H₂SO₄ 与 Ba(OH)₂ 反应同时生成 BaSO₄ 沉淀和水，应写完整的离子方程式，C 正确。
8．单选 C
【解析】Fe³⁺ 溶液呈棕黄色，Fe²⁺ 呈浅绿色；Fe³⁺ 遇 KSCN 变血红色，Fe²⁺ 不变色；Fe(OH)₂ 白色，在空气中被氧化为红褐色 Fe(OH)₃；Fe₂O₃ 是红棕色固体。
9．多选 ABD
【解析】有单质参加的反应不一定是氧化还原反应（如 3O₂ = 2O₃，同素异形体转化无化合价变化），C 错误；其余均正确。
10．多选 ABD
【解析】离子间能否共存取决于是否发生反应（生成沉淀、气体、水或发生氧化还原反应），并非所有离子都能共存，C 错误。
11．填空 6.02
【解析】N=nN_A=1×6.02×10²³。
12．填空 98
【解析】M(H₂SO₄)=2+32+64=98 g/mol。
13．填空 O₂
【解析】过氧化钠与水反应放出氧气。
14．填空 4
【解析】n=0.2×0.5=0.1 mol，m=0.1×40=4 g。

【解析】注意：①容量瓶规格要与所配溶液体积一致；②转移前必须冷却；③定容时视线必须与刻度线相平。

【解析】铁与稀盐酸反应生成 Fe²⁺，物质的量之比为 1∶1。
