【解析】B项「振耳欲聋」应为「震耳欲聋」；C项「无动于忠」应为「无动于衷」；D项「深恶痛急」应为「深恶痛疾」。
3． A
【解析】先总说「从神话传说到现实生活」（②），再举例「夸父逐日、精卫填海」（③），然后概括其精神实质（①），最后说精神传承（④），逻辑顺畅。
4． C
【解析】A项缺主语，删去「通过」或「使」；B项两面对一面；D项「不仅……而且……」是递进关系，此处搭配无误，但选项D本身无语病，C更规范。正确答案C。
5． C
【解析】郦道元是北魏地理学家，不是北宋。
