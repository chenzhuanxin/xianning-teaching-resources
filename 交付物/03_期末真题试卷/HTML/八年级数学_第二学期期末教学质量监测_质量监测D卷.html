22． 因为 AB = AC，AD ⊥ BC， 所以 AD 是 BC 边上的中线，D 是 BC 的中点。 在 Rt△ABD 中，E 是斜边 AB 的中点，所以 DE = 1/2 AB。 在 Rt△ACD 中，F 是斜边 AC 的中点，所以 DF = 1/2 AC。 因为 AB = AC，所以 DE = DF。
【解析】评分：得出 DE = 1/2 AB 得4分，DF = 1/2 AC 得4分，结论2分。
23． （1）甲平均数 = (10+12+13+12+13)÷5 = 60÷5 = 12（台）。 乙平均数 = (8+14+12+15+11)÷5 = 60÷5 = 12（台）。 （2）甲方差 = [(10−12)²+(12−12)²+(13−12)²+(12−12)²+(13−12)²]÷5 = (4+0+1+0+1)÷5 = 1.2。 乙方差 = [(8−12)²+(14−12)²+(12−12)²+(15−12)²+(11−12)²]÷5 = (16+4+0+9+1)÷5 = 6。 因为 1.2 < 6，所以甲品牌销售情况更稳定。
【解析】评分：（1）4分；（2）方差4分、判断2分。
24． 因为四边形 ABCD 是平行四边形， 所以 AD ∥ BC，OA = OC。 所以∠EAO = ∠FCO，∠AEO = ∠CFO。 在△AOE 和△COF 中， ∠EAO = ∠FCO，∠AEO = ∠CFO，OA = OC， 所以△AOE ≌ △COF（AAS），所以 OE = OF。
【解析】评分：得出 OA = OC、AD ∥ BC 得4分，全等证明4分，结论2分。
