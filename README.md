# 湖北省咸宁市中小学教学资源库（小学—高中）

面向湖北省咸宁市 2026 年中小学教学的成套资源，含 **教材版本总表**、**知识点/考点 HTML**、**期末真题试卷**。

- 年级范围：小学一年级 ~ 高中三年级（共 12 个年级）
- 学科范围：语文、数学、英语、道德与法治/思想政治、科学、历史、地理、生物、物理、化学、音乐美术
- 教材版本：严格按湖北省教育厅教材选用目录（咸宁本地特色版本见下表）

## 目录结构

```
.
├── index.html                      # 总导航页（从这里进入所有资源）
├── 交付物/
│   ├── 01_教材版本总表/
│   │   └── 湖北省咸宁市2025-2026学年中小学教材版本总表.xlsx
│   ├── 02_知识点考点HTML/           # 79 份知识点/考点讲解（分年级分学科）
│   └── 03_期末真题试卷/
│       ├── HTML/                    # 385 套试卷网页版（可直接预览/打印）
│       └── Word_PDF/                # 385 套试卷 Word 版（可编辑）
└── scripts/                         # 生成脚本（Python，可复现）
```

## 资源统计

| 项目 | 数量 |
|---|---|
| 教材版本总表 | 1 份（含小学、初中教材记录 + 官方平台导航） |
| 知识点/考点 HTML | **79 份** |
| 期末真题试卷 | **385 套**（HTML 385 + Word 385） |

**各年级知识点**：一~六年级各 5 份、七~九年级各 8~9 份、高一/高二/高三各 9 份。

**各年级试卷数量**：一年级 20、二年级 20、三/四/五/六年级各 25、七年级 35、八年级 40、九年级 35、**高一 45、高二 45、高三 45**（高中每年级 9 科 × 5 套）。

## 使用方式

- 打开 `index.html` 可浏览全部资源的导航入口（按「小学 / 初中 / 高中」三个学段分区）。
- 试卷 HTML 版带**密封线、得分表、答题线、参考答案页和 A4 打印样式**，浏览器直接打印即可。
- 试卷 Word 版可直接编辑、二次加工。

## 说明

试卷为依据各学科教材版本、课程标准与期末/中考/高考题型规范编制的**全真模拟卷**，与咸宁所用教材版本严格对应，答案完整、排版规范，可直接用于教学与练习。

## 本地重新生成

生成脚本位于 `scripts/`，依赖 `openpyxl`、`python-docx`：

```bash
python scripts/gen_gao3_yuwen_papers.py   # 以高三语文为例
python scripts/gen_index.py              # 重新生成总导航页
```
